代数式

“1 只青蛙 1 张嘴，2 只青蛙 2 张嘴……”这首儿歌永远唱不完；可只要用字母 n，一句话就能说完：n 只青蛙 n 张嘴。字母就这样把“无穷多”变成“一个式子”。这一节我们从用字母表示数出发，认识代数式，学会把文字语言翻译成符号语言，并会求代数式的值。

学习目标

  • 理解用字母表示数的意义，会用字母表示运算律、公式和简单的数量关系，知道字母的取值要受实际意义限制。
  • 理解代数式的概念，会判断一个式子是不是代数式，能按规范书写代数式。
  • 会把文字语言翻译成符号语言，用代数式表示行程、价格、几何量、增长率等数量关系，也能说出代数式的实际意义。
  • 会求代数式的值，掌握“先代入、后计算”的步骤，知道负数与分数代入时要加括号。
  • 体会整体代入的思想，能用代数式解决简单的实际问题。

课时 1用字母表示数

一、为什么要把数写成字母

先看一组等式：

3 + 5 = 5 + 3，7 + 2 = 2 + 7，(−4) + 6 = 6 + (−4)，0.5 + 1.2 = 1.2 + 0.5……

这样的等式写得完吗？写不完。每写一个，只能说明“这一对数相加，交换位置和不变”，却说明不了“任意两个数相加都如此”。如果换成字母：设 a、b 表示任意两个有理数，写成

a + b = b + a，

一句话就把所有情况都包括了。这就是字母的力量：它把“一个一个的数”变成了“一类数”，把“举不完的例子”变成了“一个式子”。

再看儿歌：“1 只青蛙 1 张嘴，2 只眼睛 4 条腿；2 只青蛙 2 张嘴，4 只眼睛 8 条腿……”如果一直唱下去，要唱到天亮。用字母 n 表示青蛙的只数，就可以写成“n 只青蛙 n 张嘴，2n 只眼睛 4n 条腿”，一句话概括了全部。字母表示数，既简洁，又一般，这是它最大的好处。

要点：用字母表示数，可以把数量关系简明地表示出来，使我们更容易看清问题的一般规律；用字母表示数以后，字母可以像数一样参与运算，这就为研究“一类问题”提供了工具。

二、字母可以表示什么

字母能表示的东西比我们想象的多。归纳起来，常见的有下面几类。

1. 表示任意数。如 a + b = b + a 中的 a、b 表示任意有理数；a 与 −a 互为相反数，对任意有理数 a 都成立。

2. 表示一定范围内的数。如“第 n 个图形”中的 n 只能取正整数 1，2，3，…；“某班有 x 人”中的 x 只能取正整数。字母的取值不是随心所欲的，它要符合实际意义。

3. 表示数量关系。如苹果每千克 m 元，买 3 kg 需要 3m 元；汽车每小时行驶 v km，t h 行驶 vt km。这里 m、v、t 都是字母，3m、vt 就把“单价、数量、总价”之间的关系写了出来。

4. 表示运算律。加法交换律、乘法分配律等，用字母写出来最清楚，也最省事。

5. 表示公式。长方形面积 S = ab，圆面积 S = πr2，这些都是用字母表示的公式。有了公式，只要知道字母的值，就能算出结果。

6. 表示规律。奇数可以写成 2n − 1（n 为正整数），三个连续整数可以写成 n − 1，n，n + 1。把规律写成式子，规律就“看得见”了。

提示：同一个字母在同一个问题中表示同一个数；不同的量要用不同的字母表示。例如长方形的长用 a、宽用 b，不要长和宽都用 a，否则就分不清了。

三、用字母表示运算律与公式

小学里学过的运算律，用字母写出来是这样的：

  • 加法交换律：a + b = b + a；
  • 加法结合律：(a + b) + c = a + (b + c)；
  • 乘法交换律：ab = ba；
  • 乘法结合律：(ab)c = a(bc)；
  • 乘法分配律：a(b + c) = ab + ac。

常用的公式也不少：长方形周长 C = 2(a + b)，面积 S = ab；三角形面积 S = ah/2；梯形面积 S = (a + b)h/2；圆周长 C = 2πr，面积 S = πr2；正方体表面积 S = 6a2，体积 V = a3；长方体体积 V = abc。把它们整理成表 1。

四、字母的取值范围

字母可以表示数，但它表示的数要合乎情理。看几个例子：

  • 用 n 表示“第 n 个图形”，n 只能取正整数，取 1.5 就说不通了；
  • 用 a 表示正方形的边长，必须 a > 0，边长不能是负数，也不能是 0；
  • 用 x 表示某班的人数，x 只能取正整数；
  • 用 t 表示汽车行驶的时间，t ≥ 0；
  • 在式子 1/(x − 2) 中，除数不能为 0，所以 x ≠ 2。

所以，字母的取值往往有两方面的限制：一是实际意义的限制（人数、个数、长度、时间不能乱取），二是运算本身的限制（分母不能为 0）。做题时如果题目给了条件，就按条件来；没给条件，也要想一想“这样取合不合理”。

易错：①认为“字母可以表示任何数”，忽略了实际意义的限制；②在 1/x 中取 x = 0，这是不允许的，因为 0 不能作除数；③把 π 当成字母；④同一个问题中，用同一个字母表示了两个不同的量。

五、书写规范

用字母表示数，写出来的式子要符合大家的“约定”，否则别人看不懂。常用的规范有五条：

  • 乘号省略：a × b 写作 ab，2 × a 写作 2a，a × b × c 写作 abc；数与字母、字母与字母相乘，乘号都可以省略，也可以写成“·”。
  • 数字写在字母前面：写 3a，不写 a3；写 5xy，不写 xy5。
  • 系数是 1 或 −1 时，1 省略：1 × a 写作 a，不写 1a；(−1) × a 写作 −a，不写 −1a。
  • 除法写成分数：a ÷ b 写作 a/b（b ≠ 0），(x + y) ÷ 3 写作 (x + y)/3。分子是多项式时，必须加括号。
  • 带分数化成假分数：2½ × a 不能写成 2½a（容易误读成 2 + ½a），要写成 (5/2)a。
书写规范的几条约定
a × b = ab；　1 × a = a；　(−1) × a = −a；　a ÷ b = a/b（b ≠ 0）；　2½a = (5/2)a

还有一条常被忽略：当式子表示“和”或“差”，后面又带单位时，要把整个式子加上括号再写单位。例如“a 与 b 的和，单位是元”，要写成 (a + b) 元，不能写成 a + b 元（那样容易被误读成“a 加上 b 元”）。

例 1 用字母表示运算律和公式

用字母表示：（1）乘法交换律；（2）乘法分配律；（3）长方形的周长和面积（长 a，宽 b）；（4）圆的周长和面积（半径 r）；（5）正方体的表面积和体积（棱长 a）。

解

（1）乘法交换律：ab = ba。两个数相乘，交换因数的位置，积不变。

（2）乘法分配律：a(b + c) = ab + ac。注意括号不能漏，否则意思就变了。

（3）长方形周长 C = 2(a + b)，面积 S = ab。周长是四条边的和，即 a + b + a + b，也就是 2(a + b)。

（4）圆的周长 C = 2πr，面积 S = πr2。这里的 π 是圆周率，是一个常数。

（5）正方体有 6 个全等的正方形面，每个面的面积是 a2，所以表面积 S = 6a2；体积 V = a3。

变式：用字母表示三角形的面积公式与梯形的面积公式（三角形的底为 a、高为 h；梯形的上底为 a、下底为 b、高为 h）。

三角形面积 S = ah/2；梯形面积 S = (a + b)h/2。注意后者的分子是 (a + b)，括号不能省，否则就成了 a + bh/2，意义完全不同。

例 2 用字母表示数量关系

用含字母的式子表示：（1）比 a 的 3 倍小 5 的数；（2）a、b 两数的平均数；（3）某商品原价 x 元，打八折后的价格；（4）一个两位数，十位上的数字是 m，个位上的数字是 n。

解

（1）a 的 3 倍是 3a，“小 5”就是减去 5，所以这个数是 3a − 5。注意“小 5”不能说成“5 − 3a”。

（2）平均数 = 总和 ÷ 个数 = (a + b) ÷ 2，写作 (a + b)/2。分子是和，必须加括号。

（3）打八折就是按原价的 80% 出售，所以现价是 0.8x 元（也可以写成 80%x 元）。

（4）十位上的数字 m 表示 m 个十，即 10m；个位上的数字 n 表示 n 个一。所以这个两位数是 10m + n。

答：所求的式子依次是 3a − 5，(a + b)/2，0.8x，10m + n。

方法归纳：用字母表示数量关系，可以按“先读、后拆、再写”三步走。先读题，弄清楚是“和、差、积、商”中的哪一种；再把句子拆成几层，找出每一层的关键词（倍、几分之几、多、少、大、小）；最后按顺序写出式子，注意括号和单位。写完后可以代一个具体的数检验一下，看是否合情合理。
例 3 书写规范与字母的取值范围

（1）把下列写法改写成规范形式：a × 4；1 × m；(x + y) ÷ 3；3½ × n；b × a；(−1) × y。

（2）指出下列各式中字母的取值范围：① 1/(x − 3)；② 用 a 表示正方形的边长；③ 用 n 表示第 n 个数。

解

（1）a × 4 = 4a（数字写在字母前面）；1 × m = m（系数 1 省略）；(x + y) ÷ 3 = (x + y)/3（除法写成分数，分子加括号）；3½ × n = (7/2)n（带分数化假分数）；b × a = ab（字母相乘，乘号省略，通常按字母顺序写）；(−1) × y = −y（系数 −1 省略 1）。

（2）① 因为除数不能为 0，所以 x − 3 ≠ 0，即 x ≠ 3；② 边长必须大于 0，所以 a > 0；③ 序号只能是正整数，所以 n = 1，2，3，…。

练习（课时 1）

1 【基础】用含字母的式子表示：（1）x 的 2 倍与 3 的和；（2）a 与 b 的差的平方；（3）m 的 40%；（4）n 的倒数（n ≠ 0）。
答案与解析

（1）2x + 3。“x 的 2 倍”是 2x，再与 3 相加。

（2）(a − b)2。先求差，再平方，所以差要加括号；若写成 a − b2，就变成“a 减去 b 的平方”了。

（3）0.4m（也可写成 40%m）。

（4）1/n。注意条件 n ≠ 0，因为 0 没有倒数。

2 【基础】用字母表示：（1）乘法交换律；（2）加法结合律；（3）三角形的面积（底 a，高 h）；（4）梯形的面积（上底 a，下底 b，高 h）；（5）路程、速度、时间的关系。
答案与解析

（1）ab = ba。

（2）(a + b) + c = a + (b + c)。

（3）S = ah/2。

（4）S = (a + b)h/2。分子是 (a + b)，括号必须写出来。

（5）s = vt，其中 s 表示路程，v 表示速度，t 表示时间。

3 【提升】下列写法规范吗？不规范的请改正：（1）x × 6；（2）1 · a；（3）m ÷ (n + 1)；（4）1¼ · y；（5）a × b × c。
答案与解析

（1）不规范，应写成 6x（数字写在字母前面）。

（2）不规范，应写成 a（系数 1 省略不写）。

（3）不规范，应写成 m/(n + 1)（除法写成分数形式）。

（4）不规范，应写成 (5/4)y（带分数要化成假分数，避免与“1 + ¼y”混淆）。

（5）规范，也可写成 abc。字母与字母相乘，乘号可以不写。

4 【提升】用含 n 的式子表示：（1）第 n 个偶数（n 为正整数）；（2）第 n 个奇数；（3）三个连续整数（中间一个为 n）。
答案与解析

（1）2n。当 n = 1，2，3 时，依次得 2，4，6，符合偶数的规律。

（2）2n − 1。当 n = 1，2，3 时，依次得 1，3，5，符合奇数的规律。也可以写成 2n + 1（此时 n 取 0，1，2，…）。

（3）n − 1，n，n + 1。相邻两个整数相差 1，所以中间一个为 n 时，前一个是 n − 1，后一个是 n + 1。

5 【拓展】一个正方形的边长为 a。若把它的边长扩大到原来的 2 倍，那么它的周长、面积分别是原来的几倍？请用式子说明理由。
答案与解析

原正方形的周长为 4a，面积为 a2。

边长扩大到原来的 2 倍后，新边长为 2a。

新周长 = 4 × (2a) = 8a，而 8a ÷ 4a = 2，所以周长是原来的 2 倍。

新面积 = (2a)2 = (2a) × (2a) = 4a2，而 4a2 ÷ a2 = 4，所以面积是原来的 4 倍。

答：周长是原来的 2 倍，面积是原来的 4 倍。这说明边长扩大 k 倍时，周长扩大 k 倍，面积扩大 k2 倍。

课时 2代数式

一、从“式子”到“代数式”

上一课时我们写了不少式子：3a − 5，(a + b)/2，0.8x，10m + n，ab，πr2……它们有一个共同的特点：都是用加、减、乘、除、乘方这些运算符号，把数或表示数的字母连接起来的。

一般地，用运算符号把数或表示数的字母连接而成的式子，叫做代数式。单独的一个数或一个字母，也是代数式，例如 5，−3，0，a，x 都是代数式。

理解这个定义，要抓住两点：

  • 连接的方式：只能用运算符号（+、−、×、÷、乘方）连接，不能含有等号“=”、不等号“>”“<”“≠”；
  • 连接的对象：数或表示数的字母。单独一个数、单独一个字母，也算“没有用运算符号连接”的代数式。

所以，a > b 不是代数式（它含不等号，是一个不等式）；3 + 4 = 7 不是代数式（它含等号，是一个等式）；s = vt 也不是代数式（它是等式，表示一种关系）。而 s、vt、s − vt 都是代数式。

要点：判断一个式子是不是代数式，只看两点：①式子里有没有等号或不等号？有，就不是代数式；②是不是由数、字母用运算符号连接而成？是，就是代数式。特别记住：单独一个数或一个字母也是代数式，但含“=”“>”“<”的式子不是。
易错：①把“3 + 4 = 7”当成代数式，它含等号，是等式；②把“a > 0”当成代数式，它含不等号，是不等式；③认为“单独一个字母不算代数式”，其实算；④把带单位的“3 km”当成代数式，代数式里不含单位，单位是写在式子外面的。

提示：括号是代数式的“标点符号”。同样几个数，加不加括号，意思可能完全不同：(a + b)2 是“和的平方”，而 a2 + b2 是“平方的和”；(a − b)/2 是“差的一半”，而 a − b/2 是“a 减去 b 的一半”。

三、列代数式的基本方法

把文字叙述的数量关系写成代数式，叫做列代数式。这是本章最重要的基本功。列代数式，说到底是做一次“翻译”：把日常语言翻译成符号语言。

翻译时，先要抓住关键词：

  • “和”“加上”“多”“大”通常对应“+”；
  • “差”“减去”“少”“小”通常对应“−”；
  • “积”“倍”“乘以”通常对应“×”；
  • “商”“除以”“几分之几”通常对应“÷”；
  • “平方”“立方”对应乘方。

但光认关键词还不够，还要看清运算顺序和谁在修饰谁。比较下面两组说法：

  • “a 与 b 的和的平方”——先求和，再平方，写成 (a + b)2；
  • “a 与 b 的平方的和”——先分别平方，再求和，写成 a2 + b2。

两句话只差一个“的”字的位置，式子却完全不同。可见列代数式时，断句非常关键：先弄清楚句子的层次，再一层一层地写。

方法归纳：列代数式可以按四步走：①找主语——这个式子在算谁；②断层次——最后一步运算是什么，就把它作为“最外层”；③逐层写——先写里层，再套外层，该加括号就加括号；④查规范——数字是否在前、乘号是否省略、单位是否加了括号。最后代一个具体数检验，看结果是否符合题意。

四、用代数式表示几何量

几何图形中的周长、面积、体积，是列代数式最常见的素材。看图 1，长方形的长是 a，宽是 b，那么它的周长是 2(a + b)，面积是 ab。这两个式子里，a、b 都是字母，但它们表示的是长度，所以必须大于 0。

例 1 判断哪些式子是代数式

下列各式中，哪些是代数式？哪些不是？说明理由。

0，x，x + 2y，a ≠ b，2 + 3 = 5，πr2，(a + b)/2，3x − 1 > 0，s = vt。

解

是代数式的有：0，x，x + 2y，πr2，(a + b)/2。

理由：0 是单独一个数，x 是单独一个字母，它们都是代数式；x + 2y 由数、字母用加号连接；πr2 由数与字母用乘方、乘法连接（π 是常数）；(a + b)/2 由字母用加法、除法连接。

不是代数式的有：a ≠ b（含不等号），2 + 3 = 5（含等号，是等式），3x − 1 > 0（含不等号，是不等式），s = vt（含等号，是等式）。

变式：在 5a，a < 5，a + 5，a ÷ 5，a = 5 中，哪几个是代数式？

5a、a + 5、a ÷ 5 是代数式（a ÷ 5 通常写作 a/5）；a < 5 含不等号，a = 5 含等号，都不是代数式。

例 2 列代数式并注意括号与单位

一个长方形的长是 a cm，宽比长少 3 cm。

（1）用代数式表示它的宽、周长和面积；

（2）当 a = 10 时，求它的周长和面积。

解

（1）宽比长少 3 cm，所以宽是 (a − 3) cm。

周长 = 2 × (长 + 宽) = 2[a + (a − 3)] = 2(2a − 3) cm。括号要一层一层加，不能写成 2a + a − 3。

面积 = 长 × 宽 = a(a − 3) cm2。因为宽是一个式子，所以相乘时要把 (a − 3) 括起来。

（2）当 a = 10 时，宽为 10 − 3 = 7（cm）。

周长 = 2 × (10 + 7) = 2 × 17 = 34（cm）；面积 = 10 × 7 = 70（cm2）。

答：宽为 (a − 3) cm，周长为 2(2a − 3) cm，面积为 a(a − 3) cm2；当 a = 10 时，周长为 34 cm，面积为 70 cm2。

易错：①“宽比长少 3”写成 3 − a，方向反了；②周长写成 2a + a − 3，漏掉了括号，把“2 倍”只乘到了第一项；③面积写成 a × a − 3，把 (a − 3) 的括号丢了；④单位写成“a − 3 cm”，正确写法是“(a − 3) cm”，式子要加括号。
例 3 列代数式解决分段计费问题

某市出租车的收费标准是：起步价 8 元（行驶路程不超过 3 km 都付 8 元）；超过 3 km 的部分，每千米另付 2.4 元。

（1）用代数式表示行驶 x km（x > 3）应付的车费；

（2）当 x = 8 时，应付多少元？

解

（1）车费由两部分组成：起步价 8 元，加上超过部分的费用。

超过 3 km 的路程是 (x − 3) km，这部分每千米 2.4 元，所以费用是 2.4(x − 3) 元。

因此应付车费为 8 + 2.4(x − 3) 元（x > 3）。

（2）当 x = 8 时，超过部分为 8 − 3 = 5（km），车费 = 8 + 2.4 × 5 = 8 + 12 = 20（元）。

答：车费为 8 + 2.4(x − 3) 元；当 x = 8 时，应付 20 元。

变式：若收费标准改为“起步价 8 元（不超过 3 km），超过部分每千米 2.4 元，另加燃油附加费 1 元”，车费的代数式怎样写？

车费为 8 + 2.4(x − 3) + 1 元（x > 3）。附加费与路程无关，是一个固定的数，直接加上即可。

1 【基础】下列各式中，哪些是代数式？0，x，x + 2y，a ≠ b，2 + 3 = 5，πr2，(a + b)/2，3x − 1 > 0。
答案与解析

代数式有：0，x，x + 2y，πr2，(a + b)/2。

不是代数式的有：a ≠ b（含不等号，是不等式），2 + 3 = 5（含等号，是等式），3x − 1 > 0（含不等号，是不等式）。

提醒：0 和 x 虽然“没有运算符号”，但单独一个数或一个字母也是代数式。

2 【基础】用代数式表示：（1）a、b 两数的和与这两数的差的积；（2）x 的平方与 y 的 3 倍的差；（3）m 与 n 的和的 2 倍；（4）a 的 1/3 与 b 的和。
答案与解析

（1）(a + b)(a − b)。两个和差都要加括号，再相乘。

（2）x2 − 3y。先分别写出“x 的平方”与“y 的 3 倍”，再相减。

（3）2(m + n)。是“和的 2 倍”，不是“m 的 2 倍与 n”，所以括号不能省。

（4）a/3 + b。a 的 1/3 就是 a ÷ 3，写作 a/3。

3 【提升】某商品原价 a 元，先提价 10%，再降价 10%。（1）用代数式表示现价；（2）现价比原价高还是低？为什么？
答案与解析

（1）提价 10% 后，价格变为 a(1 + 10%)；再降价 10%，是在提价后的价格基础上降，所以现价为 a(1 + 10%)(1 − 10%) = 0.99a（元）。

（2）现价比原价低。因为 0.99a < a（a > 0）。原因是两次变化的“基数”不同：提价时以 a 为基数，降价时以 1.1a 为基数，后者的 10% 更大，所以降得更多。

答：现价为 0.99a 元，比原价低。

4 【提升】说出代数式 5a + 3b 的一个实际意义（写出一种情境即可）。
答案与解析

参考答案示例：钢笔每支 a 元，笔记本每本 b 元，买 5 支钢笔和 3 本笔记本共需 (5a + 3b) 元。

也可以说：甲种糖果每千克 a 元，乙种糖果每千克 b 元，买 5 kg 甲种糖果和 3 kg 乙种糖果共需 (5a + 3b) 元。

说明：只要情境中“5 个单价为 a 的物品”与“3 个单价为 b 的物品”的总价相加，都符合这个式子的意义。解释代数式的意义时，要说出每个字母代表什么、系数表示什么、整体表示什么。

5 【拓展】观察下列等式：1 × 3 + 1 = 4 = 22，2 × 4 + 1 = 9 = 32，3 × 5 + 1 = 16 = 42，…（1）用含 n 的代数式表示第 n 个等式；（2）验证 n = 4 时等式成立。
答案与解析

（1）观察规律：第 n 个等式的左边是两个相差 2 的数的积再加 1，这两个数分别是 n 与 n + 2；右边是 (n + 1)2。

所以第 n 个等式为 n(n + 2) + 1 = (n + 1)2。

（2）当 n = 4 时，左边 = 4 × (4 + 2) + 1 = 4 × 6 + 1 = 25，右边 = (4 + 1)2 = 52 = 25，左边 = 右边，等式成立。

说明：用字母表示规律后，可以用 n = 1，2，3，4 逐一代入检验，确认式子与规律相符。

课时 3列代数式表示数量关系

一、把“关系”写成式子

生活中到处是数量关系：走得越久，路程越远；买得越多，总价越高；边长越长，面积越大。这些关系用一句句话来说，又长又啰嗦；一旦写成代数式，就变得简洁、精确，还能拿来计算。这一课时，我们集中练习“列代数式”，也就是把文字语言翻译成符号语言。

列代数式之前，先要弄清题目中的基本量和它们之间的基本关系。常见的基本关系并不多，掌握几个典型模型，大多数问题都能迎刃而解。

二、行程问题：s = vt

一辆汽车以每小时 v km 的速度行驶了 t h，它走过的路程是多少？

因为“路程 = 速度 × 时间”，所以路程 s = vt（km）。这个式子还可以变形：已知路程和时间，速度 v = s/t；已知路程和速度，时间 t = s/v。

这三个式子其实说的是同一件事，只是“求的量”不同。列代数式时，题目要求什么，就把哪个量单独放在等号左边，其余的量放到右边。

三、价格问题：总价 = 单价 × 数量

苹果每千克 m 元，买 n kg，总价是 mn 元。这个关系也可以变形：单价 = 总价 ÷ 数量，数量 = 总价 ÷ 单价。

实际问题中常常还要考虑折扣与附加费用：

  • 打八折：现价 = 原价 × 0.8，即 0.8a 元；
  • 打 x 折：现价 = 原价 × (x/10)，即 (x/10)a 元；
  • 买 a 件商品，单价 p 元，另付包装费 5 元：共需 (ap + 5) 元。

四、几何量：周长、面积、体积

几何图形中的量，也常用代数式表示。设长方形的长为 a、宽为 b，则周长 C = 2(a + b)，面积 S = ab；设长方体的长、宽、高分别为 a、b、c，则体积 V = abc，表面积 S = 2(ab + bc + ca)。

遇到组合图形，可以“先拆后合”：把图形拆成几个基本图形，分别写出它们的面积，再把结果相加或相减。例如一个边长为 a 的正方形，中间挖去一个半径为 r 的圆，剩下的面积就是 a2 − πr2。

提示：几何量都是有单位的。写答案时，面积单位是“平方”，体积单位是“立方”，不要漏写；而代数式本身不带单位，单位写在括号外面。

五、增长率问题

某工厂去年的产量是 a 吨，今年的产量比去年增长 20%，那么今年的产量是 a + 20%a，也就是 a(1 + 20%) = 1.2a（吨）。

“增长 20%”的意思是：增长的部分是去年的 20%，所以今年的产量是去年的 1.2 倍。这里的“1 + 20%”中的“1”代表“去年的产量本身”，不能丢。

如果连续两年都按同样的增长率 x 增长，那么第一年后是 a(1 + x)，第二年后是 a(1 + x)(1 + x)，即 a(1 + x)2。

类似地，“降低 15%”就是原来的 (1 − 15%) = 85%，即 0.85a；“降低到原来的 15%”才是 0.15a。注意“降低了”与“降低到”的区别。

易错：①把“增长 20%”写成 0.2a，漏掉了原来的 a，正确是 a(1 + 20%)；②把“降低了 15%”与“降低到 15%”混为一谈；③连续增长时把两年的增长率简单相加，写成 a(1 + 2x)，实际上应是 a(1 + x)2；④增长率的基数搞错，第二年的基数应是第一年的产量，而不是最初的 a。

六、连续整数、连续奇数与连续偶数

用字母表示一“串”数，是代数式的拿手好戏：

  • 三个连续整数（中间一个为 n）：n − 1，n，n + 1；
  • 第 n 个偶数：2n（n 为正整数）；
  • 第 n 个奇数：2n − 1（n 为正整数）；
  • 三个连续奇数（中间一个为 2n + 1）：2n − 1，2n + 1，2n + 3；
  • 三个连续偶数（中间一个为 2n）：2n − 2，2n，2n + 2。

为什么奇数要写成 2n − 1 或 2n + 1？因为任何奇数除以 2 都余 1，所以奇数总可以写成“2 的倍数加 1”或“2 的倍数减 1”。用 2n 表示偶数、用 2n + 1 表示奇数，这是最常用的表示方法。

七、图形中的数量关系

看下面的问题：用火柴棒按下图的方式摆正方形，摆 1 个正方形需要 4 根，摆 2 个需要 7 根，摆 3 个需要 10 根……摆 n 个正方形需要多少根？

数一数就会发现：每多摆一个正方形，只需要再加 3 根（因为有一条边是共用的）。所以第 n 个图形比第 1 个多用了 3(n − 1) 根，总数是 4 + 3(n − 1)。也可以这样想：n 个正方形各有 3 根“属于自己的”边（上、下、右），共 3n 根，再加上最左边那 1 根，得 3n + 1 根。两种想法结果相同：4 + 3(n − 1) = 3n + 1。

例 1 行程与价格中的代数式

（1）甲、乙两地相距 s km，汽车以 v km/h 的速度从甲地开往乙地，需要多少小时？

（2）某商品每件 a 元，买 b 件需要多少元？若商店打九折，需要多少元？

（3）当 s = 240，v = 80 时，求（1）中的时间；当 a = 25，b = 12 时，求（2）中打折后的钱数。

解

（1）由 s = vt 得 t = s/v，所以需要 s/v 小时（v > 0）。

（2）总价 = 单价 × 数量 = ab 元；打九折后为 0.9ab 元。

（3）当 s = 240，v = 80 时，t = 240/80 = 3（小时）。

当 a = 25，b = 12 时，ab = 25 × 12 = 300（元），打折后为 0.9 × 300 = 270（元）。

答：需要 s/v 小时；买 b 件需 ab 元，打九折需 0.9ab 元；当 s = 240，v = 80 时需 3 小时，当 a = 25，b = 12 时打折后需 270 元。

例 2 几何量中的代数式

一个长方体的长、宽、高分别为 a cm、b cm、c cm。

（1）用代数式表示它的体积和表面积；

（2）一个正方形的边长是 x cm，若在它的四个角各剪去一个边长为 y cm 的小正方形，剩下的面积是多少？

解

（1）体积 = 长 × 宽 × 高 = abc（cm3）。

表面积是 6 个面的面积之和：上下两个面各 ab，前后两个面各 ac，左右两个面各 bc，所以表面积 = 2ab + 2ac + 2bc，也可以写成 2(ab + bc + ca)（cm2）。

（2）原正方形的面积是 x2 cm2；每个小正方形的面积是 y2 cm2，四个小正方形的总面积是 4y2 cm2。

所以剩下的面积是 x2 − 4y2（cm2）。这里要求 x > 2y，否则四个角剪不下。

答：体积为 abc cm3，表面积为 2(ab + bc + ca) cm2；剩下的面积为 (x2 − 4y2) cm2。

变式：把第（2）问改成“沿虚线折成一个无盖的长方体盒子”，这个盒子的容积是多少？

剪去四个角后，底面是边长为 (x − 2y) cm 的正方形，盒子的高是 y cm，所以容积为 (x − 2y)2y cm3。括号不能漏，否则就成了 x − 2y2y，意义完全不同。

例 3 增长率与连续整数

（1）某工厂去年的产量是 a 吨，今年的产量比去年增长 20%，明年的产量又比今年增长 20%。用代数式表示今年和明年的产量。

（2）三个连续奇数，中间一个为 2n + 1（n 为正整数），用代数式表示另外两个奇数。

解

（1）今年的产量 = 去年的产量 × (1 + 20%) = a(1 + 20%) = 1.2a（吨）。

明年的产量 = 今年的产量 × (1 + 20%) = 1.2a × (1 + 20%) = 1.44a（吨）。

注意：明年的增长率是以“今年的产量”为基数，不是以“去年的产量”为基数，所以不能写成 a(1 + 40%)。

（2）相邻两个奇数相差 2，所以中间一个为 2n + 1 时，前一个是 2n + 1 − 2 = 2n − 1，后一个是 2n + 1 + 2 = 2n + 3。

答：今年的产量为 1.2a 吨，明年的产量为 1.44a 吨；另外两个奇数是 2n − 1 和 2n + 3。

拓展：代数式不仅能“翻译”文字，还能“反过来”说出意义。例如 3x + 2y 可以解释为“买 3 个单价 x 元的物品和 2 个单价 y 元的物品的总价”；也可以解释为“一个长方形由两个小长方形拼成，面积分别是 3x 与 2y，总面积为 3x + 2y”。同一个代数式可以有很多种实际背景，解释时只要说得通、讲得清即可。

课时 4代数式的值

一、把字母换成数

列代数式，是把“关系”写成式子；求代数式的值，则是把式子“算出来”。

用具体的数值代替代数式里的字母，按照代数式中的运算关系计算出的结果，叫做代数式的值。例如，代数式 3x + 2，当 x = 1 时，它的值是 3 × 1 + 2 = 5；当 x = −2 时，它的值是 3 × (−2) + 2 = −6 + 2 = −4。

同一个代数式，字母取不同的值，算出的结果一般也不同。所以，说“代数式的值”时，一定要说清楚“当字母取什么值时”。

要点：求代数式的值分两步：代入——把字母换成指定的数；计算——按代数式中原来的运算顺序算出结果。代入时，原来省略的乘号要恢复，负数与分数要加括号。

二、求值的步骤

求代数式的值，可以按图 4 的流程来做。

具体来说：

  • 第一步，代入：把字母换成题目给的数。原来省略的乘号要恢复，例如 3x 写成 3 × (−2)；负数、分数要加括号。
  • 第二步，计算：按“先乘方，再乘除，最后加减；有括号先算括号里”的顺序进行。
  • 第三步，检查：看符号有没有错、括号有没有漏、结果是否合理。
易错：①当 a = −3 时，把 a2 算成 −32 = −9，正确应是 (−3)2 = 9；②当 x = 1/2 时，把 x2 算成 1/22，正确应是 (1/2)2 = 1/4；③3a 代入 a = 2 时写成 32，忘了恢复乘号；④同一个代数式中有两个相同的字母，代入了不同的数。
代入的规范写法
a = −3 时，a2 = (−3)2 = 9；　x = 1/2 时，x2 = (1/2)2 = 1/4；　a = 2 时，3a = 3 × 2 = 6
例 1 直接代入求值

当 a = −2，b = 3 时，求下列代数式的值：（1）2a + b；（2）a2 − 2b；（3）(a + b)/(a − b)。

解

（1）把 a = −2，b = 3 代入：

2a + b = 2 × (−2) + 3 = −4 + 3 = −1。

（2）a2 − 2b = (−2)2 − 2 × 3 = 4 − 6 = −2。注意 (−2)2 = 4，不是 −4。

（3）a + b = −2 + 3 = 1，a − b = −2 − 3 = −5，

所以 (a + b)/(a − b) = 1/(−5) = −1/5。

答：所求的值依次是 −1，−2，−1/5。

变式：当 x = −1/2，y = 4 时，求 x2 + y/2 的值。

x2 = (−1/2)2 = 1/4，y/2 = 4/2 = 2，所以 x2 + y/2 = 1/4 + 2 = 9/4。分数代入必须加括号，否则 (−1/2)2 容易被误算成 −1/4。

三、整体代入

有些题目，字母的值并不知道，只知道“几个字母的某种组合”的值，例如已知 a + b = 3。这时不必（也往往不能）求出 a、b 各自是多少，而是把这个“组合”整体看成一个数，直接代入。

例如：已知 a + b = 3，求 2(a + b) − 5 的值。

把 (a + b) 整体看成 3，则 2(a + b) − 5 = 2 × 3 − 5 = 6 − 5 = 1。

这种“把式子的一部分整体代入”的方法，叫做整体代入。它体现的是“整体思想”：不纠缠局部，而从整体上把握。

整体代入的关键，是把要求的式子“凑”成已知式子的样子。例如已知 a − 2b = 3，要求 2a − 4b + 1，可以先把前两项提出 2：2a − 4b = 2(a − 2b)，于是原式 = 2 × 3 + 1 = 7。

提示：整体代入时，括号要“包住”整个组合。已知 a + b = 3，写 2(a + b) − 5 时，若漏掉括号写成 2a + b − 5，就无法整体代入了。所以“凑”的时候，一定用括号把已知的组合括起来。
例 2 整体代入求值

（1）已知 x + y = 4，求 2(x + y)2 − (x + y) + 1 的值；

（2）已知 a − 2b = 3，求 2a − 4b + 1 的值。

解

（1）把 (x + y) 整体看成 4，则

原式 = 2 × 42 − 4 + 1 = 2 × 16 − 4 + 1 = 32 − 4 + 1 = 29。

（2）先“凑”出已知的组合：2a − 4b = 2(a − 2b)。

所以原式 = 2(a − 2b) + 1 = 2 × 3 + 1 = 6 + 1 = 7。

答：（1）29；（2）7。

变式：已知 m2 + m = 5，求 3m2 + 3m − 4 的值。

3m2 + 3m = 3(m2 + m)，把 (m2 + m) 整体看成 5，原式 = 3 × 5 − 4 = 15 − 4 = 11。

四、用求值解决实际问题

很多实际问题，可以先列出代数式，再代入具体数据求出答案。这样做的好处是：式子列对一次，换一组数据就能反复计算。

例 3 用代数式的值解决实际问题

某商店销售一种商品，每件售价 p 元，每件成本 c 元，一天卖出 n 件。

（1）用代数式表示这一天销售这种商品的利润；

（2）当 p = 45，c = 32，n = 120 时，求这一天的利润；

（3）若该商店一个月的营业天数为 26 天，且每天的销售情况都相同，求这个月的总利润。

解

（1）每件的利润是 (p − c) 元，卖出 n 件，所以总利润为 n(p − c) 元。

（2）当 p = 45，c = 32，n = 120 时，

p − c = 45 − 32 = 13（元），

总利润 = 120 × 13 = 1560（元）。

（3）一个月的总利润 = 每天的利润 × 天数 = 1560 × 26 = 40560（元）。

答：总利润为 n(p − c) 元；当 p = 45，c = 32，n = 120 时，这一天的利润是 1560 元；这个月的总利润是 40560 元。

方法归纳：求代数式的值，要记住“三查”：一查代入——负数、分数有没有加括号，乘号有没有恢复；二查顺序——是不是先乘方、再乘除、后加减；三查整体——能不能把已知的组合整体代入。至于“先化简再求值”，要到下一节学了整式的加减才能用；本节只需按原式直接代入计算。
拓展：代数式的值随字母取值的变化而变化，这种“变化”本身就是函数思想的萌芽。例如 3x + 2，x 每增加 1，值就增加 3；x2 则增长得越来越快。以后学习函数时，会系统地研究这种对应关系。

课时 1单项式

上一节我们用字母表示数，得到了很多代数式：边长为 a 的正方形的周长是 4a，面积是 a2；长为 a、宽为 b 的长方形的面积是 ab；一辆汽车以 v 千米/时的速度行驶 t 小时，行驶的路程是 vt；半径为 r 的圆的面积是 πr2。

把这些式子摆在一起看：4a 是 4 与 a 的积，a2 是 a 与 a 的积，ab 是 a 与 b 的积，vt 是 v 与 t 的积，πr2 是 π 与 r、r 的积。它们的共同点是：整个式子里只有乘法，是“数”与“字母”相乘得到的积。这一课时就来研究这类最简单的代数式。

1. 单项式的意义

由数与字母的积组成的代数式叫做单项式。理解这个定义，要抓住三点：

  • 只含乘法。式子里不能出现加号、减号，也不能出现字母作除数。像 a + b、x − 3 这样的式子含有加减运算，不是单项式。
  • 单独一个数或一个字母也是单项式。例如 5、−7、0、a、x 都是单项式。可以把它们看成“数与字母的积”的特殊情形：5 是 5 与“没有字母”的积，a 是 1 与 a 的积。
  • 数可以是整数、分数、小数，也可以是 π。π 是一个确定的常数，可以充当“数”的角色。

按这个定义，4a、a2、ab、vt、πr2、3x、−5a2b、−7 都是单项式；而 a + b 是两项的和，2/x 的分母中含有字母，它们都不是单项式。

要点：判断一个代数式是不是单项式，只看它是不是“数与字母的积”，或者是不是单独的一个数、一个字母。含加减运算的不是单项式；分母（或除式）中含字母的也不是单项式。判断时不要被“看起来简单”迷惑：x/2 是单项式，2/x 不是。

2. 单项式的系数

单项式中的数字因数叫做这个单项式的系数。例如：

  • 3x 的系数是 3；
  • ab 的系数是 1（ab 就是 1·ab，系数 1 通常省略不写）；
  • −a 的系数是 −1（−a 就是 −1·a）；
  • −3x2y 的系数是 −3，不是 3。

最关键的一条是：系数要带符号。求系数时，先把单项式写成“数字因数 × 字母部分”的形式，数字因数连同它前面的符号一起就是系数。−3x2y 写成 (−3)·x2y，所以系数是 −3；−5a2b 写成 (−5)·a2b，所以系数是 −5。

提示：有三类系数最容易写错，要特别留意。第一类是字母前面“看不见的 1”，如 ab、m2n 的系数都是 1；第二类是“看不见的 −1”，如 −xy、−x3 的系数都是 −1；第三类是 π，如 πr2 的系数是 π，2πr 的系数是 2π。因为 π 表示圆周率，是一个具体的数（约等于 3.14），不是字母，所以它要算进系数里。

3. 单项式的次数

一个单项式中，所有字母的指数的和叫做这个单项式的次数。

例如 −3x2y 中，x 的指数是 2，y 的指数是 1（y 就是 y1，指数 1 省略不写），所有字母的指数和是 2 + 1 = 3，所以它的次数是 3。

再如：5a2b3c 的次数是 2 + 3 + 1 = 6；−mn 的次数是 1 + 1 = 2；7x 的次数是 1；a2b 的次数是 2 + 1 = 3。

单独一个非零的数，如 5、−7、π，可以看成“不含字母”，所有字母的指数和为 0，所以规定：非零常数的次数是 0。0 也是单项式，但通常不讨论它的次数。

还要注意：次数只与字母的指数有关，与系数无关。3x2y 与 −100x2y 的系数相差很大，次数却都是 3。同样，πr2 的次数是 2，不是 3，因为 π 不是字母。

4. 几种需要区分的情形

初学时，下面几种情形最容易混淆，逐一辨清：

  • x/2 是单项式。它等于 (1/2)·x，系数是 1/2，次数是 1。因为除以 2 就是乘 1/2，整个式子仍然是“数与字母的积”。
  • 2/x 不是单项式。它的分母中含有字母 x，不是“数与字母的积”。凡是分母含字母的式子，都不属于单项式。
  • (x + y)/2 不是单项式。它等于 x/2 + y/2，是两项相加，属于下一课时要学的多项式。
  • −x2y/3 是单项式。它等于 −(1/3)·x2y，系数是 −1/3，次数是 3。
  • 5 是单项式。系数是 5，次数是 0，因为式子里没有字母。

最后还要提醒一句书写规范。单项式里数字要写在字母的前面：3 × a 写作 3a，a × 3 也写作 3a；1 × a 写作 a，−1 × a 写作 −a；系数是带分数时要化成假分数，例如 1 又 1/2 与 a 的积要写成 (3/2)a，不能写成 1 又 1/2 a。规范的写法不仅看着整齐，更重要的是方便我们一眼看出系数和次数，也为后面的合并同类项打好基础。

易错：① 把 −3x2y 的系数写成 3，漏掉负号；② 把 ab 的系数写成 0（以为“没有数字”），正确是 1；③ 把 πr2 的次数算成 3（把 π 当成字母），正确是 2；④ 把 x/2 与 2/x 混为一谈，前者是单项式，后者不是；⑤ 求次数时把系数也乘进去，例如把 3x2y 的次数算成 3 × 3 = 9。

例 1 判断单项式并指出系数、次数

下列代数式中，哪些是单项式？是单项式的，写出它的系数和次数。

(1) 3x；(2) a + b；(3) −5ab2；(4) x/2；(5) 2/x；(6) −7；(7) πr2；(8) (x + y)/2。

解

(1) 3x 是 3 与 x 的积，是单项式，系数是 3，次数是 1。

(2) a + b 含有加法，是两项的和，不是单项式。

(3) −5ab2 是 −5 与 a、b、b 的积，是单项式，系数是 −5，次数是 1 + 2 = 3。

(4) x/2 = (1/2)x，是单项式，系数是 1/2，次数是 1。

(5) 2/x 的分母中含有字母 x，不是数与字母的积，不是单项式。

(6) −7 是单独一个数，是单项式，系数是 −7，次数是 0。

(7) πr2 是 π 与 r、r 的积，是单项式。π 是常数，所以系数是 π，次数是 2。

(8) (x + y)/2 = x/2 + y/2，是两项的和，不是单项式。

所以单项式是 (1)(3)(4)(6)(7)。

变式：判断 −x2y/3 与 3/(xy) 是不是单项式。
答：−x2y/3 = −(1/3)x2y，是单项式，系数 −1/3，次数 3；3/(xy) 的分母含字母，不是单项式。

例 2 求系数与次数（含 π 与分数系数）

写出下列单项式的系数和次数：

(1) −4x2y3；(2) 2πr；(3) −a；(4) 5；(5) (2/3)ab；(6) −x2y/3。

解

(1) −4x2y3 = (−4)·x2y3，系数是 −4；次数是 2 + 3 = 5。

(2) 2πr = (2π)·r，系数是 2π；r 的指数是 1，次数是 1。

(3) −a = (−1)·a，系数是 −1；次数是 1。

(4) 5 中不含字母，系数是 5；非零常数的次数是 0。

(5) (2/3)ab 的系数是 2/3；次数是 1 + 1 = 2。

(6) −x2y/3 = −(1/3)·x2y，系数是 −1/3；次数是 2 + 1 = 3。

变式：单项式 −πx2y2/4 的系数和次数分别是多少？
答：系数是 −π/4，次数是 2 + 2 = 4。注意 π 算在系数里，不能当作字母。

例 3 由次数确定字母的指数

(1) 已知单项式 −5x2ym 的次数是 6，求 m 的值。

(2) 已知 (a + 2)x2yb−1 是关于 x、y 的五次单项式，且系数是 −5，求 a + b 的值。

解

(1) 这个单项式中，x 的指数是 2，y 的指数是 m。由次数的定义得

2 + m = 6，所以 m = 4。

(2) 由“五次单项式”得 2 + (b − 1) = 5，即 b + 1 = 5，所以 b = 4。

由“系数是 −5”得 a + 2 = −5，所以 a = −7。

因此 a + b = (−7) + 4 = −3。

答：(1) m = 4；(2) a + b = −3。

变式：若单项式 3xmy2 的次数是 5，求 m 的值。
答：由 m + 2 = 5 得 m = 3。注意次数与系数 3 无关，不能把 3 也算进去。

方法归纳：求单项式的系数与次数，按下面三步进行：
  • 第一步，判类型：先看它是不是“数与字母的积”，含加减或分母含字母的，直接排除。
  • 第二步，写形式：把单项式写成“数字因数 × 字母部分”，数字因数连同符号一起作为系数。注意补上省略的 1 和 −1，把 π 归入数字因数。
  • 第三步，求次数：把每个字母右上角的指数相加，省略的指数按 1 计算；不含字母的常数次数为 0。
拓展：单项式的次数反映了它的“结构复杂程度”。在以后的学习中，我们会按次数给多项式分类（一次式、二次式……），也会发现两个次数相同的单项式相乘，积的次数等于两个次数之和，例如 x2·x3 = x5，次数 2 + 3 = 5。这一规律在下一节学习整式的乘除时会用到，现在先有一个印象即可。

课时 2多项式与整式

上一课时我们研究了单项式。可是实际问题中的代数式，往往不是一个单项式那么简单。例如：

  • 一个长方形的长是 a、宽是 b，它的周长是 2a + 2b；
  • 一个三位数，百位数字是 a、十位数字是 b、个位数字是 c，这个三位数是 100a + 10b + c；
  • 某班有男生 a 人、女生 b 人，全班共有 a + b 人；
  • 把 3 个单项式 3x2、−2x、5 相加，得到 3x2 − 2x + 5。

这些式子都是几个单项式的和。这一课时就来研究这类式子，并给整式下一个完整的定义。

1. 多项式的意义

几个单项式的和叫做多项式。例如 3x2 − 2x + 5 是 3x2、−2x、5 三个单项式的和；a + b 是 a 与 b 的和；2a + 2b 是 2a 与 2b 的和。

多项式中的每一个单项式，叫做这个多项式的项。例如 3x2 − 2x + 5 的项是 3x2、−2x、5。

这里有一个极易出错的地方：每一项都包括它前面的符号。3x2 − 2x + 5 的第二项是 −2x，不是 2x；第三项是 +5（通常写成 5）。因为多项式是“几个单项式的和”，写成 3x2 + (−2x) + 5 就看得更清楚了。

多项式中不含字母的项叫做常数项。3x2 − 2x + 5 中，5 就是常数项。

要点：多项式是“几个单项式的和”，所以它的每一项都带着自己前面的符号。找项时，先把这个多项式改写成“和”的形式，例如把 x2 − 3x + 1 看成 x2 + (−3x) + 1，项就是 x2、−3x、1。这一步做对了，后面求次数、合并同类项、去括号才不会出错。

2. 多项式的次数与“几次几项式”

多项式里次数最高的项的次数，叫做这个多项式的次数。

例如在 3x2 − 2x + 5 中，三项的次数分别是 2、1、0，最高的是 2，所以这个多项式的次数是 2。

一个多项式含有几项，最高次项是几次，就把它叫做几次几项式。3x2 − 2x + 5 有三项、最高次是 2，所以它是二次三项式。

再如：a3 − 2a2b + b3 的三项次数分别是 3、3、3，最高次是 3，所以它是三次三项式；x + 1 是一次二项式；−5 可以看成单项式，也可以看成只有常数项的多项式（零次）。

易错：① 把多项式的次数算成“各项次数的和”，例如把 3x2 − 2x + 5 的次数算成 2 + 1 + 0 = 3，正确是 2；② 找项时漏掉符号，把 3x2 − 2x + 5 的项写成 3x2、2x、5；③ 把常数项也算进“几次”里，其实常数项的次数是 0，不影响多项式的次数；④ 把 x2 + 1/x 当成多项式，其实 1/x 不是单项式，整个式子也不是多项式。

图 21 把 3x2 − 2x + 5 拆成了三个“项”来看：第一项 3x2 次数是 2，第二项 −2x 次数是 1，第三项 5 是常数项、次数是 0。三项中最高的是 2，所以整个多项式是二次三项式。看清“项”，是学好整式加减的第一步。

3. 多项式的排列

一个多项式里的项，可以按某个字母的指数重新排序，这叫多项式的排列。

  • 按某个字母的指数从大到小排列，叫做按这个字母降幂排列；
  • 按某个字母的指数从小到大排列，叫做按这个字母升幂排列。

例如把 −3x2 + 5x3 − 2 + x 按 x 降幂排列：先找各项中 x 的指数，5x3 是 3，−3x2 是 2，x 是 1，−2 是 0，从大到小排得

5x3 − 3x2 + x − 2。

按 x 升幂排列，则从小到排得

−2 + x − 3x2 + 5x3。

排列时要注意两点：一是连同符号一起移动，把 −3x2 搬到后面，要带着负号；二是各项不能遗漏、不能重复。排列只改变项的顺序，不改变多项式的大小。

提示：习惯上把多项式按降幂排列，这样最高次项在最前面，一眼就能看出它是几次多项式。含多个字母时，要先说明“按哪个字母”排列，例如“把 3x2y − 2xy2 + y3 按 y 降幂排列”，结果是 y3 − 2xy2 + 3x2y。

想一想：为什么要排列

有同学会问：多项式里的项本来就是相加的关系，顺序又不影响结果，为什么还要费劲去排列呢？

排列的第一个好处是“看得清”。把多项式按降幂排好以后，最高次项一定在最前面，一眼就能看出它是几次多项式，也方便判断两个多项式是不是同类项、能不能合并。例如看到 5x3 − 3x2 + x − 2，立刻就知道这是三次四项式；如果写成 −2 + x + 5x3 − 3x2，就要多看几眼。

排列的第二个好处是“好核对”。把两个多项式都按同一个字母降幂排列，再把同类项上下对齐，合并时就不容易漏项、错位。以后学习竖式加减、多项式除法时，这个习惯会带来很大方便。

排列的第三个好处是“便于比较”。两个多项式按同一字母降幂排列后，从最高次项开始逐项比较，就能判断它们是否相等，或者在哪一项上不同。

4. 整式

单项式与多项式统称整式。也就是说，整式包括两类：一类是单项式，另一类是多项式。用图来表示，整式是一个“大圈”，里面套着“单项式”和“多项式”两个“小圈”。

按这个定义：3x、−5a2b、πr2、7 是整式（单项式）；3x2 − 2x + 5、a + b、2a + 2b 也是整式（多项式）。而 2/x、1/(x + 1) 的分母中含有字母，它们既不是单项式，也不是多项式，因此不是整式。

要特别注意：x/2 是整式（它是单项式 (1/2)x），而 2/x 不是整式。分母里有没有字母，是判断的关键。

例 1 指出多项式的项、常数项与次数

指出多项式 2x3 − x2 + 3x − 5 的项、常数项和次数，并说出它是几次几项式。

解

把多项式写成“和”的形式：2x3 + (−x2) + 3x + (−5)。

所以它的项是 2x3、−x2、3x、−5，共四项。

其中不含字母的项是 −5，所以常数项是 −5（注意带负号）。

各项的次数分别是 3、2、1、0，最高的是 3，所以这个多项式的次数是 3。

它有四项、最高次是 3，所以是三次四项式。

变式：说出 a3 − 2a2b + b3 的项、常数项和次数。
答：项是 a3、−2a2b、b3，没有常数项（常数项是 0）；各项次数分别是 3、3、3，所以次数是 3，是三次三项式。

例 2 把多项式按降幂、升幂排列

把多项式 −x3 + 4x − 2x2 + 7 分别按 x 降幂排列和按 x 升幂排列。

解

先找出各项以及各项中 x 的指数：

−x3（指数 3），4x（指数 1），−2x2（指数 2），7（指数 0，常数项）。

按 x 的指数从大到小排列（降幂），得

−x3 − 2x2 + 4x + 7。

按 x 的指数从小到大排列（升幂），得

7 + 4x − 2x2 − x3。

注意：移动 −2x2 时把负号一起带走，所以它排在 4x 后面时仍然带负号。

变式：把 3x2y − 2xy2 + y3 按 y 降幂排列。
答：各项中 y 的指数分别是 1、2、3，从大到小排得 y3 − 2xy2 + 3x2y。

例 3 由“几次几项式”确定字母的值

已知关于 x 的多项式 (m − 1)x3 + 2x2 − (n + 2)x + 3 是二次三项式，求 m、n 应满足的条件。

解

这个多项式是二次三项式，说明它的次数是 2，并且恰好有三项。

次数是 2，就意味着三次项必须“消失”，即它的系数为 0：

m − 1 = 0，所以 m = 1。

此时多项式变成 2x2 − (n + 2)x + 3。要保证它有三项，一次项的系数不能为 0，即

n + 2 ≠ 0，所以 n ≠ −2。

答：m = 1，且 n ≠ −2。

检验：取 n = 0，多项式为 2x2 − 2x + 3，确实是二次三项式；若取 n = −2，多项式变成 2x2 + 3，只有两项，是二次二项式，不符合要求。

变式：若多项式 2x3 + (m − 3)x2 − x + 1 中不含 x2 项，求 m 的值。
答：不含 x2 项，说明 x2 项的系数为 0，即 m − 3 = 0，所以 m = 3。

方法归纳：研究一个多项式，按“拆项—定次—命名—排序”四步走：
  • 拆项：把多项式改写成几个单项式相加的形式，看清每一项连同它的符号。
  • 定次：分别算出每一项的次数，取最大的那个作为多项式的次数。
  • 命名：数一数有几项、最高次是几次，写成“几次几项式”。
  • 排序：需要时按某个字母降幂或升幂排列，移动时连同符号一起搬。

5 【拓展】已知关于 x、y 的多项式 3xmy2 − (m − 1)xy + 5 是四次三项式，求 m 的值。
答案与解析

这个多项式有三项：3xmy2、−(m − 1)xy、5。

各项次数分别是：m + 2、(1 + 1) = 2、0。

要使它是四次三项式，最高次必须是 4，所以 m + 2 = 4，得 m = 2。

还要检验“三项”：当 m = 2 时，第二项的系数 −(m − 1) = −1 ≠ 0，所以第二项确实存在，共有三项。

答：m = 2。

如果只算出 m = 2 而不检验，万一第二项系数为 0，多项式就只有两项了，所以“检验”这一步不能省。

课时 3同类项与合并同类项

先看一个生活中的例子。3 个苹果加 2 个苹果，是 5 个苹果；3 个苹果加 2 个梨，就不能说成“5 个苹果梨”。也就是说，只有“同类”的东西才能直接相加。

代数式也一样。3a + 2a 可以合并成 5a，因为 3a 与 2a 都是“a 的倍数”，本质上是 3 个 a 加 2 个 a；而 3a + 2b 就不能合并成 5ab 或 5(a + b)，因为 a 与 b 不是同一种字母。那么，什么样的项才能合并？这一课时就来研究。

1. 同类项

所含字母相同，并且相同字母的指数也相同的项，叫做同类项。

例如 3x2y 与 −5x2y 是同类项：它们都只含字母 x、y，而且 x 的指数都是 2，y 的指数都是 1，完全相同。

判断同类项，要抓住两个“相同”：

  • 字母相同。所含的字母必须完全一样，不能一个含 x、y，另一个只含 x。
  • 相同字母的指数也相同。只看字母对不对还不够，指数也必须一一对应相等。

有几个重要结论要记住：

  • 同类项与系数无关。3x2y 与 −100x2y 是同类项，系数一个是 3、一个是 −100，不影响“同类”。
  • 同类项与字母的排列顺序无关。5ab 与 −5ba 是同类项，因为 ab 与 ba 表示同一个乘积。
  • 所有的常数项都是同类项。−4 与 7 是同类项，5 与 −0.3 也是同类项，因为它们都不含字母（可以看成“字母部分为空”）。
要点：判断同类项只看“字母部分”：所含字母是否相同、相同字母的指数是否相同。系数是多少、正还是负、字母写的顺序如何，都不影响判断。两个“相同”缺一不可：3x2y 与 3xy2 虽然字母一样，但 x、y 的指数正好对调了，所以不是同类项。

图 22 中，上下两排共 8 个单项式，连线把它们分成了 4 组同类项：3x2y 与 −6x2y、2ab2 与 7ab2、−4xy2 与 0.5xy2、5m2n 与 −3m2n。可以看出，每组里两个式子的系数完全不同，但字母部分一模一样——这正是同类项的特点。

2. 合并同类项

把多项式中的同类项合并成一项，叫做合并同类项。

合并同类项的依据是乘法对加法的分配律：3a + 2a = (3 + 2)a = 5a。一般地，有

合并同类项法则
把同类项的系数相加，所得的结果作为系数，字母和字母的指数不变。

例如：

  • 3x + 5x = (3 + 5)x = 8x；
  • 7a2 − 4a2 = (7 − 4)a2 = 3a2；
  • −2mn + 6mn = (−2 + 6)mn = 4mn；
  • 3x2y − 3x2y = (3 − 3)x2y = 0。

最后一条要特别注意：系数相加得 0 时，这一项就消失了，不要写成 0x2y。

合并同类项的一般步骤是：

  • 找：用记号（如相同的下划线）把同类项标出来；
  • 移：利用加法交换律、结合律把同类项放在一起（移动时连同符号一起搬）；
  • 合：把各组的系数相加，字母和指数照抄不变。

合并后的结果要做到：不再含有同类项，也就是说，能合的都要合完。检验的办法是看结果里还有没有字母部分相同的项。

议一议：合并同类项的依据是什么

为什么“系数相加、字母和指数不变”是合理的？可以用分配律来说明。以 3a + 2a 为例：

3a + 2a = (3 + 2)a = 5a。

这里把 a 看成一个“公共的因数”，3 个 a 加 2 个 a，就是 (3 + 2) 个 a，也就是 5 个 a。这与“3 个苹果加 2 个苹果等于 5 个苹果”是同一个道理。

再以 5x2y − 3x2y 为例：两个式子都有 x2y 这个“字母部分”，把它看成公共因数，得

5x2y − 3x2y = (5 − 3)x2y = 2x2y。

反过来想：如果字母部分不同，比如 3x + 2y，就没有公共的“字母部分”可以提出来，也就没法合并。这就是“同类项才能合并”的根本原因。所以判断同类项时，只看字母部分，不看系数——系数正是那个要被“加减”的对象。

易错：① 合并时把指数也相加，例如把 3x2 + 5x2 算成 8x4，正确是 8x2——系数相加，指数不变；② 把不是同类项的硬合并，例如把 3x + 2y 算成 5xy；③ 系数相加得 0 时写成 0x，应当直接把这个项去掉；④ 移动项时漏掉负号，例如把 5a − 3a 中的 −3a 当成 3a。

3. 化简求值

有了合并同类项，我们就可以把复杂的式子“化简”。化简的意义在于：式子里项数变少、系数变小，代入数值时计算量大大减少，也更不容易算错。

化简求值的一般做法是：先合并同类项，把式子化成最简形式，再代入数值计算。不要一上来就把数代进去硬算。

例 1 判断同类项

下列各组中的两项是不是同类项？说明理由。

(1) 3x2y 与 −5x2y；(2) 2ab 与 2ab2；(3) 3m2n 与 3mn2；(4) −4 与 7；(5) 5ab 与 −5ba；(6) 2x3 与 3x2。

解

(1) 是同类项。字母都是 x、y，且 x 的指数都是 2、y 的指数都是 1。系数 3 与 −5 不同，不影响判断。

(2) 不是同类项。虽然字母都是 a、b，但 b 的指数一个是 1、一个是 2，不相同。

(3) 不是同类项。m、n 的指数正好对调，一个是 m2n，一个是 mn2。

(4) 是同类项。两个都是常数项，不含字母，所有常数项都是同类项。

(5) 是同类项。ab 与 ba 表示同一个乘积，字母相同、指数也相同，与字母的书写顺序无关。

(6) 不是同类项。字母都是 x，但指数一个是 3、一个是 2，不相同。

变式：判断 −2x2y3 与 3y3x2 是不是同类项。
答：是同类项。两个式子都含字母 x、y，且 x 的指数都是 2、y 的指数都是 3，只是书写顺序不同。

例 2 合并同类项

合并下列多项式中的同类项：5a2b − 3ab2 + 2a2b + 4ab2 − a2b。

解

第一步，找同类项。含 a2b 的项有 5a2b、2a2b、−a2b；含 ab2 的项有 −3ab2、4ab2。

第二步，把同类项放在一起（加法交换律、结合律）：

原式 = (5a2b + 2a2b − a2b) + (−3ab2 + 4ab2)。

第三步，系数相加，字母和指数不变：

= (5 + 2 − 1)a2b + (−3 + 4)ab2

= 6a2b + ab2。

检查结果：6a2b 与 ab2 的字母指数不同，不是同类项，不能再合并。所以结果已经是最简形式。

变式：合并 4x2y − 3xy2 + 2x2y + xy2。
答：原式 = (4 + 2)x2y + (−3 + 1)xy2 = 6x2y − 2xy2。

例 3 先化简，再求值

先化简，再求值：5a2 − 3a + 2 − 4a2 + 2a − 3，其中 a = −2。

解

先合并同类项。含 a2 的项：5a2 与 −4a2；含 a 的项：−3a 与 2a；常数项：2 与 −3。

原式 = (5 − 4)a2 + (−3 + 2)a + (2 − 3)

= a2 − a − 1。

再把 a = −2 代入化简后的式子：

当 a = −2 时，a2 − a − 1 = (−2)2 − (−2) − 1 = 4 + 2 − 1 = 5。

答：原式化简为 a2 − a − 1，当 a = −2 时，值是 5。

说明：代入负数时要加括号，(−2)2 表示 (−2)×(−2) = 4，不能写成 −22（那是 −4）。

变式：先化简，再求值：2x2 − 5x + 3 − 3x2 + 4x − 1，其中 x = −1。
答：原式 = −x2 − x + 2；当 x = −1 时，值为 −1 + 1 + 2 = 2。

方法归纳：合并同类项要过“三关”：
  • 第一关，认得出：先看字母是否相同，再看相同字母的指数是否相同，两条都满足才是同类项，与系数、顺序无关。
  • 第二关，搬得对：用交换律、结合律把同类项聚在一起，搬动时把符号一起搬走，不要漏项、不要改号。
  • 第三关，合得准：系数相加（注意负数相加的法则），字母和字母的指数原样照抄；系数为 0 时这一项直接去掉。
化简求值时，一定先合并到最简，再代值计算；代入负数或分数时，要加上括号。
拓展：合并同类项体现了“分类”与“整体”的思想。把 (a + b) 看成一个整体，那么 2(a + b) − 3(a + b) + 5(a + b) 就可以像合并同类项一样，把系数 2、−3、5 相加，得到 4(a + b)。这种“把一个式子当成一个字母”的整体思想，在以后解方程、因式分解时经常用到。

课时 4去括号

先做一个“算一算”的练习。已知 a = 5，b = 8，c = 3，分别计算下面两个式子：

a + (b − c) = 5 + (8 − 3) = 5 + 5 = 10；

a + b − c = 5 + 8 − 3 = 10。

结果相同。再算一组：

a − (b − c) = 5 − (8 − 3) = 5 − 5 = 0；

a − b + c = 5 − 8 + 3 = 0。

结果也相同。这两组算式说明：括号可以去掉，但去掉括号时，括号里各项的符号怎么变，是有规律的。这一课时就来研究这条规律。

1. 去括号法则

把括号和它前面的符号一起去掉，叫做去括号。法则有两条：

去括号法则
括号前是“+”，把括号和它前面的“+”去掉后，括号里各项都不变符号；
括号前是“−”，把括号和它前面的“−”去掉后，括号里各项都改变符号。

用字母写出来就是：

a + (b − c) = a + b − c；

a − (b − c) = a − b + c。

这两条法则其实很好理解。括号前是“+”时，相当于把括号里的整体“加上去”，加上的东西不变，所以各项符号照旧。括号前是“−”时，相当于“减去括号里的整体”，减去一个和，等于把和里的每一项都减掉，所以每一项都要变号。

也可以从相反数的角度看：−(b − c) 表示 b − c 的相反数，而 b − c 的相反数是 −b + c。所以 a − (b − c) = a + (−b + c) = a − b + c。这与减法法则 a − b = a + (−b) 是一致的。

要点：去括号时，先看括号前面是什么符号，再决定括号里各项“变不变号”。括号前是“+”，各项不变号；括号前是“−”，各项都变号，而且是每一项都变，不是只变第一项。另外，去掉的是“括号和它前面的符号”，括号本身的“壳”没有了，但括号里各项之间的符号要保留（它们变成结果里各项之间的符号）。

看图 23 可以对照记忆：左半边的括号前是“+”，去括号后 b 仍是 b、−c 仍是 −c；右半边的括号前是“−”，去括号后 b 变成 −b、−c 变成 +c，两项都变了。

2. 括号前有数字因数

有时括号前面不只是一个符号，还有一个数，例如 −2(a − 3b)。这时可以用乘法对加法的分配律，把数乘进括号里的每一项：

−2(a − 3b) = (−2)·a + (−2)·(−3b) = −2a + 6b。

也可以把它看成分两步：先算 2(a − 3b) = 2a − 6b，再取相反数得 −2a + 6b。两种做法结果相同。

要提醒的是：乘进括号时，括号里的每一项都要乘，不能只乘第一项。−2(a − 3b) 中，−2 要分别与 a 和 −3b 相乘，所以结果是 −2a + 6b，而不是 −2a − 3b。

3. 多重括号

有些式子有两层甚至三层括号，例如 3x2 − [2x − (x2 + 3x) − 4]。去多重括号有两条路线：

  • 由内向外：先去掉最里面（小括号）的，合并后再去掉外面（中括号）的。这条路稳妥，不容易乱。
  • 由外向内：先去掉最外面的括号，注意里面的括号整体要变号，再逐层往里。这条路快，但容易漏变号。

初学时建议用“由内向外”。每去一层括号，就把括号里的同类项合并一次，式子会越来越短，不容易出错。

4. 添括号

去括号的反过来，就是添括号：把一个多项式中的某几项括起来，前面加上“+”或“−”。

添括号的法则与去括号正好相反：

  • 添上括号，括号前面是“+”，括到括号里的各项都不变符号；
  • 添上括号，括号前面是“−”，括到括号里的各项都改变符号。

例如：a + b − c = a + (b − c)；a − b + c = a − (b − c)。

检验的办法是“添完再去”：把添好的括号按去括号法则去掉，看能不能还原成原式。能还原，就说明添对了。

5. 例题

例 1 直接去括号

去括号：

(1) a + (b − c)；(2) a − (b − c)；(3) −(2x − 3y + 1)；(4) +(x2 − 2x)。

解

(1) 括号前是“+”，括号里各项都不变号，所以 a + (b − c) = a + b − c。

(2) 括号前是“−”，括号里各项都变号：b 变成 −b，−c 变成 +c。所以 a − (b − c) = a − b + c。

(3) 括号前是“−”，括号里三项都变号：2x 变成 −2x，−3y 变成 +3y，1 变成 −1。所以 −(2x − 3y + 1) = −2x + 3y − 1。

(4) 括号前是“+”，各项不变号，所以 +(x2 − 2x) = x2 − 2x。

变式：去括号：−(a − 2b) + (−3a + b)。
答：−(a − 2b) = −a + 2b；+(−3a + b) = −3a + b。所以原式 = −a + 2b − 3a + b = −4a + 3b。

例 2 去括号后合并同类项

化简：4a − 2(a − 3b) + (b − a)。

解

先去括号。−2(a − 3b) 用分配律，把 −2 分别乘括号里的每一项：

−2(a − 3b) = −2a + 6b；

+(b − a) 的括号前是“+”，各项不变号，得 b − a。

所以原式 = 4a − 2a + 6b + b − a。

再合并同类项：含 a 的项 4a − 2a − a = (4 − 2 − 1)a = a；含 b 的项 6b + b = 7b。

所以原式 = a + 7b。

检验：取 a = 1、b = 2，原式 = 4 − 2(1 − 6) + (2 − 1) = 4 + 10 + 1 = 15；化简后的式子 = 1 + 14 = 15，两者相等。

变式：化简：3(x − 2y) − 2(x + y)。
答：3(x − 2y) = 3x − 6y，−2(x + y) = −2x − 2y，所以原式 = 3x − 6y − 2x − 2y = x − 8y。

例 3 多重括号的去法

化简：3x2 − [2x − (x2 + 3x) − 4]。

解

采用“由内向外”的顺序。

第一步，去小括号：括号前是“−”，括号里各项都变号，得

2x − (x2 + 3x) − 4 = 2x − x2 − 3x − 4。

合并同类项：2x − 3x = −x，所以中括号里变成

−x2 − x − 4。

第二步，去中括号：括号前是“−”，括号里各项都变号，得

原式 = 3x2 − (−x2 − x − 4) = 3x2 + x2 + x + 4。

第三步，合并同类项：3x2 + x2 = 4x2。

所以原式 = 4x2 + x + 4。

检验：取 x = 1，原式 = 3 − [2 − 4 − 4] = 3 − (−6) = 9；化简后的式子 = 4 + 1 + 4 = 9，两者相等。

变式：化简：a − {2a − [3a − (4a − 5)]}。
答：由内向外：3a − (4a − 5) = 3a − 4a + 5 = −a + 5；2a − (−a + 5) = 2a + a − 5 = 3a − 5；a − (3a − 5) = a − 3a + 5 = −2a + 5。

方法归纳：去括号分三步走：
  • 第一步，看符号：看清括号前面是“+”“−”，还是带着数字因数。
  • 第二步，定变化：括号前是“+”，各项照抄；是“−”，各项变号；有数字因数，先用分配律把数乘进每一项。
  • 第三步，查项数：数一数括号里原来有几项，去括号后就应该有几项，少一项就是漏了。
遇到多重括号，由内向外逐层去，每去一层就合并一次同类项，式子越算越短，错误也就越少。
拓展：去括号与添括号是一对“互逆”的操作，它们和减法是加法的逆运算、乘法是除法的逆运算一样，都是数学中“逆运算”思想的体现。掌握了这一对操作，以后解方程时的“移项”“合并”会轻松很多：移项本质上就是利用等式性质与去括号、添括号的变形。另外，添括号还有一个用处——把一个多项式“分组”，为后面的因式分解做准备。

练习（课时 4）

1 【基础】去括号：
(1) a + (b − c)；(2) a − (b − c)；(3) −(m − n)；(4) +(x − y + z)；(5) −2(a − 3b)。
答案与解析

(1) 括号前是“+”，各项不变号：a + b − c。

(2) 括号前是“−”，各项变号：a − b + c。

(3) 括号前是“−”，各项变号：−m + n。

(4) 括号前是“+”，各项不变号：x − y + z。

(5) 用分配律，−2 分别乘两项：−2a + 6b。

2 【基础】化简：
(1) 5a − (3a − 2b)；(2) (2x2 + 3x) − (x2 + 2x)。
答案与解析

(1) 5a − (3a − 2b) = 5a − 3a + 2b = 2a + 2b。

(2) (2x2 + 3x) − (x2 + 2x) = 2x2 + 3x − x2 − 2x = x2 + x。

注意第 (2) 题第二个括号前是“−”，括号里两项都变了号。

3 【提升】化简：2(a2 − 3a) − 3(a2 − 2a + 1)。
答案与解析

先用分配律去括号：

2(a2 − 3a) = 2a2 − 6a；

−3(a2 − 2a + 1) = −3a2 + 6a − 3（三项都要乘）。

所以原式 = 2a2 − 6a − 3a2 + 6a − 3。

合并同类项：2a2 − 3a2 = −a2；−6a + 6a = 0；常数项是 −3。

所以原式 = −a2 − 3。

检验：取 a = 1，原式 = 2(1 − 3) − 3(1 − 2 + 1) = 2 × (−2) − 3 × 0 = −4；化简后 = −1 − 3 = −4，相等。

4 【提升】添括号：把 3x2 − 2x + 5 的后两项括起来，(1) 使括号前面是“+”；(2) 使括号前面是“−”。
答案与解析

(1) 括号前是“+”，括到括号里的各项不变号，所以

3x2 − 2x + 5 = 3x2 + (−2x + 5)。

(2) 括号前是“−”，括到括号里的各项都变号，所以

3x2 − 2x + 5 = 3x2 − (2x − 5)。

检验：把 (2) 的结果去括号，得 3x2 − 2x + 5，与原式相同，说明添对了。

5 【拓展】化简：a − {2a − [3a − (4a − 5)]}。
答案与解析

由内向外逐层去括号。

第一层（小括号）：3a − (4a − 5) = 3a − 4a + 5 = −a + 5。

第二层（中括号）：2a − (−a + 5) = 2a + a − 5 = 3a − 5。

第三层（大括号）：a − (3a − 5) = a − 3a + 5 = −2a + 5。

所以原式 = −2a + 5。

检验：取 a = 1，原式 = 1 − {2 − [3 − (−1)]} = 1 − {2 − 4} = 1 − (−2) = 3；化简后 = −2 + 5 = 3，相等。

课时 5整式的加减

前面四个课时，我们分别学了单项式、多项式、同类项和去括号。现在把这些工具合起来用，就能完成整式的加减。

看一个具体问题：某长方形的长是 3x + 2，宽是 x − 1，求它的周长。周长等于 2 倍的（长 + 宽），列式就是 2[(3x + 2) + (x − 1)]。这个式子里有括号、有同类项，要算出最简结果，就得先化简。这一课时就来研究整式加减的一般步骤和应用。

1. 整式加减的一般步骤

整式的加减，实质上就是去括号和合并同类项两件事的组合。一般步骤是：

整式加减的一般步骤
先去括号，再合并同类项

具体地说：

  • 第一步，去括号。按去括号法则处理每一个括号；括号前有数字因数的，先用分配律把数乘进括号里的每一项。
  • 第二步，合并同类项。把字母部分相同的项合在一起，系数相加，字母和指数不变。
  • 第三步，检查。看结果里还有没有同类项、有没有漏项、次数有没有算错。结果要化到最简。

几个整式相加减时，要特别注意：把每个多项式看成一个整体。遇到“减去一个多项式”，一定要先给它加上括号，再去括号，否则很容易漏变号。

例如计算 (3x2 − 2x + 1) − (2x2 + 5x − 4) 时，第二个多项式是一个整体，减号管着它的每一项，所以去括号后每一项都要变号：

(3x2 − 2x + 1) − (2x2 + 5x − 4) = 3x2 − 2x + 1 − 2x2 − 5x + 4。

易错：① 两个多项式相减时忘了加括号，把 A − B 写成 A − B 的“第一项 − 第二项”，导致后面的项没变号；② 去括号时只变第一项的符号；③ 合并同类项时把系数相加后，又顺手把指数也加了；④ 结果里还留着同类项没有合并完，例如把 3x + 2x 留在答案里；⑤ 化简求值时先把数代进去硬算，算到一半就乱了。

2. 整式加减的计算

例 1 两个多项式的和与差

计算：

(1) (3x2 − 2x + 1) + (2x2 + 5x − 4)；

(2) (3x2 − 2x + 1) − (2x2 + 5x − 4)。

解

(1) 括号前是“+”，各项都不变号，直接去括号：

原式 = 3x2 − 2x + 1 + 2x2 + 5x − 4。

合并同类项：3x2 + 2x2 = 5x2；−2x + 5x = 3x；1 − 4 = −3。

所以原式 = 5x2 + 3x − 3。

(2) 第二个括号前是“−”，括号里三项都要变号：

原式 = 3x2 − 2x + 1 − 2x2 − 5x + 4。

合并同类项：3x2 − 2x2 = x2；−2x − 5x = −7x；1 + 4 = 5。

所以原式 = x2 − 7x + 5。

对比两小题可以看到：同样两个多项式，“和”与“差”的结果差别很大，关键就在于减号后面那一项要不要变号。

变式：计算 (5a2 − 2a) − (3a2 − 4a + 1)。
答：原式 = 5a2 − 2a − 3a2 + 4a − 1 = 2a2 + 2a − 1。

例 2 先化简，再求值

先化简，再求值：3(x2 − 2x) − 2(x2 − 3x + 1)，其中 x = −3。

解

先去括号（用分配律）：

3(x2 − 2x) = 3x2 − 6x；

−2(x2 − 3x + 1) = −2x2 + 6x − 2。

所以原式 = 3x2 − 6x − 2x2 + 6x − 2。

合并同类项：3x2 − 2x2 = x2；−6x + 6x = 0；常数项是 −2。

所以原式 = x2 − 2。

当 x = −3 时，x2 − 2 = (−3)2 − 2 = 9 − 2 = 7。

答：原式化简为 x2 − 2，当 x = −3 时，值是 7。

体会一下“先化简”的好处：化简后只剩两项，代入时只需算一次平方，比直接代入两个括号要快得多，也不容易错。

变式：先化简，再求值：2(a2 − 3a) − 3(a2 − 2a + 1)，其中 a = 1。
答：化简得 −a2 − 3；当 a = 1 时，值为 −1 − 3 = −4。

议一议：化简前后，式子的值变了吗

有同学担心：把式子“改写”了，值会不会跟着变？答案是不会。化简用的是去括号法则和合并同类项，这两步都只是在“换一种写法”，并不改变式子的值。

去括号的依据是减法法则与分配律，添括号、去括号只是把同一种运算换了个样子；合并同类项的依据是分配律，把“3 个 x 加 2 个 x”写成“5 个 x”。这些变形对任何允许的字母取值都成立，所以化简前后的式子，代入同一个数得到的结果一定相同。

正因为如此，我们才能放心地“先化简，再求值”。化简的好处也很明显：项数少了，系数小了，代入时计算量小，出错的机会也少。反过来，如果化简后代入算出的结果与直接代入算出的结果不一致，那就说明化简过程中某一步出了错，这本身就是一个很好的自我检查办法。

还有一点值得注意：既然化简前后的值对任何字母取值都相同，那么有些题目即使不给出字母的值，也能求出结果。例如已知 a + b = 3，求 2(a + b) − 3(a + b) + 5(a + b) 的值：把 (a + b) 看成整体，原式 = (2 − 3 + 5)(a + b) = 4(a + b) = 4 × 3 = 12。这种“整体代入”的办法，在以后的学习中会经常用到。

3. 整式加减的实际应用

整式的加减在几何和生活中都有用。常见的有三类：

  • 周长问题。先把各边表示出来，再相加；长方形周长 = 2 ×（长 + 宽）。列式时要把“长 + 宽”括起来，再乘 2。
  • 面积问题。把图形分割成几块，分别写出各块的面积，再相加或相减。图 24 就是一个例子。
  • 方案比较。把两种方案的“花费”或“收益”分别用整式表示，再求它们的差，根据差的正负判断哪种方案更合算。

解决这类问题时，第一步是用字母把未知量表示出来，第二步是根据数量关系列式，第三步才是化简。化简完成后，如果需要求具体数值，再把数代入。

图 24 中，一个大长方形被分成左右两块。左块的面积是 2x2 + 3x − 1，右块的面积是 x2 − 2x + 4。求总面积，就是把两个整式相加；求两块面积相差多少，就是把两个整式相减。这正是整式加减的用武之地。

例 3 用整式加减求面积

如图 24，一个大长方形被分成左右两块，左块的面积是 2x2 + 3x − 1，右块的面积是 x2 − 2x + 4。

(1) 用含 x 的式子表示这个大长方形的总面积；

(2) 用含 x 的式子表示左块比右块大多少；

(3) 当 x = 2 时，求总面积。

解

(1) 总面积等于两块面积之和：

(2x2 + 3x − 1) + (x2 − 2x + 4)

= 2x2 + 3x − 1 + x2 − 2x + 4

= 3x2 + x + 3。

(2) “左块比右块大多少”就是左块面积减去右块面积：

(2x2 + 3x − 1) − (x2 − 2x + 4)

= 2x2 + 3x − 1 − x2 + 2x − 4

= x2 + 5x − 5。

(3) 当 x = 2 时，总面积 = 3 × 22 + 2 + 3 = 12 + 2 + 3 = 17。

答：总面积是 3x2 + x + 3；左块比右块大 x2 + 5x − 5；当 x = 2 时，总面积是 17。

变式：在例 3 中，当 x = 3 时，左块比右块大多少？
答：把 x = 3 代入 x2 + 5x − 5，得 9 + 15 − 5 = 19，所以左块比右块大 19。

方法归纳：整式的加减，可以概括为“一看、二去、三合、四查”：
  • 一看：看清题目要求的是“和”还是“差”，几个整式相加减时，把每个整式看成一个整体。
  • 二去：按去括号法则去括号；括号前是“−”的，每一项都变号；有数字因数的，用分配律乘进每一项。
  • 三合：合并同类项，系数相加，字母和指数不变；系数为 0 的项直接去掉。
  • 四查：检查有没有漏项、有没有同类项没合完、符号有没有搬错；化简求值时，先化简再代入。
拓展：整式的加减有一个重要特点：两个多项式的和或差，次数不会超过原来两个多项式中较高的次数。例如两个二次三项式相加减，结果最多是二次式，绝不会出现三次项。这是因为加减法只把同类项的系数相加减，不会产生新的字母乘积。另外，整式加减的结果仍然是一个整式，这一点在以后学习“整式乘法”时会发生变化：乘法可能提高次数，那时就要重新考虑了。

1 【基础】计算：(2x2 − 3x + 1) + (x2 + 4x − 5)。
答案与解析

括号前都是“+”，各项不变号：

原式 = 2x2 − 3x + 1 + x2 + 4x − 5。

合并同类项：2x2 + x2 = 3x2；−3x + 4x = x；1 − 5 = −4。

所以原式 = 3x2 + x − 4。

2 【基础】计算：(5a2 − 2a) − (3a2 − 4a + 1)。
答案与解析

第二个括号前是“−”，括号里三项都变号：

原式 = 5a2 − 2a − 3a2 + 4a − 1。

合并同类项：5a2 − 3a2 = 2a2；−2a + 4a = 2a；常数项 −1。

所以原式 = 2a2 + 2a − 1。

3 【提升】一个长方形的长是 2a + 3b，宽是 a − b。(1) 用含 a、b 的式子表示它的周长；(2) 当 a = 4，b = 1 时，求周长。
答案与解析

(1) 长方形的周长 = 2 ×（长 + 宽），要把“长 + 宽”先括起来：

周长 = 2[(2a + 3b) + (a − b)]

= 2(2a + 3b + a − b)

= 2(3a + 2b)

= 6a + 4b。

(2) 当 a = 4，b = 1 时，周长 = 6 × 4 + 4 × 1 = 24 + 4 = 28。

答：周长是 6a + 4b；当 a = 4、b = 1 时，周长是 28。

4 【提升】先化简，再求值：(3x2 − 2x + 1) − 2(x2 − x + 3)，其中 x = −2。
答案与解析

先去括号（注意 2(x2 − x + 3) 前面是“−”，乘进去以后每一项都要变号）：

原式 = 3x2 − 2x + 1 − 2x2 + 2x − 6。

合并同类项：3x2 − 2x2 = x2；−2x + 2x = 0；1 − 6 = −5。

所以原式 = x2 − 5。

当 x = −2 时，x2 − 5 = (−2)2 − 5 = 4 − 5 = −1。

答：原式化简为 x2 − 5，当 x = −2 时，值是 −1。

5 【拓展】某游泳馆有两种收费方式：方式一，先办会员卡 150 元，每次游泳再付 10 元；方式二，不办卡，每次游泳付 25 元。设游泳 x 次（x 为正整数）。
(1) 用含 x 的式子分别表示两种方式的费用；
(2) 求方式一的费用比方式二少多少（用含 x 的式子表示）；
(3) 当 x = 12 时，哪种方式更合算？省多少钱？
答案与解析

(1) 方式一的费用 = 150 + 10x；方式二的费用 = 25x。

(2) “方式一比方式二少多少”，就是方式二的费用减去方式一的费用：

25x − (150 + 10x) = 25x − 150 − 10x = 15x − 150。

所以方式一的费用比方式二少 (15x − 150) 元。

(3) 当 x = 12 时，方式一：150 + 10 × 12 = 150 + 120 = 270（元）；方式二：25 × 12 = 300（元）。

270 < 300，所以方式一更合算，省 300 − 270 = 30（元）。

也可以直接用 (2) 的式子检验：15 × 12 − 150 = 180 − 150 = 30（元），与上面一致。

答：方式一的费用是 150 + 10x 元，方式二的费用是 25x 元；方式一比方式二少 (15x − 150) 元；当 x = 12 时，方式一更合算，省 30 元。

本节知识网络：
  • 单项式：数与字母的积（单独一个数或字母也是单项式）。系数是数字因数，要带符号；次数是所有字母的指数的和；π 是常数，要算进系数；2/x 不是单项式。
  • 多项式：几个单项式的和。每一项都包括它前面的符号；不含字母的项叫常数项；多项式的次数是次数最高项的次数；按项数和次数称为“几次几项式”。
  • 整式：单项式与多项式统称整式。分母含字母的式子（如 2/x）不是整式。
  • 同类项：所含字母相同，并且相同字母的指数也相同。与系数无关、与字母顺序无关；所有常数项都是同类项。
  • 合并同类项：系数相加，字母和字母的指数不变；系数为 0 时该项消失。化简求值要先化简再代入。
  • 去括号：括号前是“+”，各项不变号；括号前是“−”，各项都变号。括号前有数字因数时，用分配律乘进每一项。
  • 添括号：与去括号互逆。括号前是“+”，括进去的各项不变号；括号前是“−”，括进去的各项都变号。
  • 整式加减：先去括号，再合并同类项。几个整式相加减时，把每个整式看成整体，减去一个多项式要先加括号；结果要化到最简。
  • 易错清单：系数漏负号；把 π 当字母；次数算成系数乘指数；多项式次数算成各项次数之和；合并时把指数也相加；去括号只变第一项；两个多项式相减不加括号。

探索与表达规律

1, 4, 9, 16, … 下一个数是多少？用火柴棒摆正方形，摆 10 个要几根？日历上圈出的九个数，和与中间那个数有什么关系？这些看似毫不相干的问题，背后都藏着“规律”。本节就来学习怎样从数、算式和图形中发现规律，用含 n 的代数式表示第 n 项，再用 n = 1, 2, 3 代入检验。

学习目标

  • 能通过观察数列、算式、月历和图形的前几项，发现其中的数量关系，提出关于第 n 项的猜想。
  • 会用含 n 的代数式表示规律，并能用 n = 1, 2, 3（必要时再加上 n = 4）代入逐一验证。
  • 会分析图形结构，从“每多摆一个图形要多用几根、多几个点”入手，求出火柴棒、点阵、拼接、对角线等问题的通项。
  • 体会“从特殊到一般，再用一般检验特殊”的思想，知道不完全归纳必须经过验证才可靠。
  • 能分清“项数 n”与“第 n 项的值”，并会用通项求指定项、判断某个数是不是数列中的项。

课时 1探索数字与算式规律

先来做一道填空题：3, 7, 11, 15, (　　), (　　)。多数同学会脱口而出“19、23”，因为相邻两个数都相差 4。可是如果再问一句“第 100 个数是多少”，一位一位往下加就太慢了。我们需要的不是“接着写”，而是“一句话说清楚第 n 个数是谁”。这句话，就是含 n 的代数式。

1. 从“接着写”到“写出第 n 项”

找规律，第一步是观察：看相邻两项怎样变化，看每一项与它的序号之间有没有固定的联系。第二步是猜想：用含 n 的式子把这个联系写出来。第三步是验证：把 n = 1, 2, 3 代进去，看算出的结果是否正好是数列的第 1、2、3 项。三步都通过了，这个式子才算靠谱。

为什么要验证？因为只看前几项得到的猜想不一定对。比如数列 1, 2, 4, 8, …，有人猜第 n 项是 2 的 (n − 1) 次方，这个猜想对不对，要靠后面的项来检验；也有人可能猜成别的式子，前四项恰好也是 1, 2, 4, 8，但从第五项起就分道扬镳了。所以“猜”只是开始，“验”才是把关。

要点：用代数式表示规律，就是把“第 n 项”写成含 n 的式子。写完之后，一定要把 n = 1, 2, 3 代入，逐一核对算出的值是否等于数列的前三项；必要时再验 n = 4。全部吻合，才能确认这个式子。

2. 等差数列：每次加同一个数

数列 3, 7, 11, 15, … 的特点是：后一项减前一项的差都是 4。这样的数列叫做等差数列，那个固定的差叫做公差。我们来把每一项“拆”成序号的样子：

把每一项写成含序号的形式
第 1 项：3 = 4×1 − 1
第 2 项：7 = 4×2 − 1
第 3 项：11 = 4×3 − 1
第 4 项：15 = 4×4 − 1

规律一目了然：第几项，就是“4 乘几再减 1”。所以第 n 项是 4n − 1。验证一下：n = 1 时 4×1 − 1 = 3，等于第 1 项；n = 2 时 4×2 − 1 = 7，等于第 2 项；n = 3 时 4×3 − 1 = 11，等于第 3 项；n = 4 时 4×4 − 1 = 15，等于第 4 项。四项全对，通项就是 4n − 1。

也可以这样想：第 1 项是 3，此后每往后一项就加一个 4，从第 1 项到第 n 项一共加了 (n − 1) 次，所以第 n 项 = 3 + 4(n − 1) = 3 + 4n − 4 = 4n − 1。两种想法得到同一个式子，这正说明规律找对了。

方法归纳：等差数列求第 n 项，可以用“首项 + (n − 1) × 公差”。先看公差是几，再看首项是几，代进去化简即可。算出式子后，务必用 n = 1, 2, 3 回代检验；若有一项对不上，说明首项或公差看错了。

有了通项，很多问题就变成“代入算一算”。第 100 项 = 4×100 − 1 = 399；反过来，如果问“399 是这个数列的第几项”，只要解 4n − 1 = 399，得 4n = 400，n = 100，说明 399 是第 100 项。要是解出的 n 不是正整数，那就说明这个数不在数列里。

3. 平方数：差在变的数列

再看数列 1, 4, 9, 16, 25, …。相邻两项的差是 3, 5, 7, 9，差本身也在变，所以它不是等差数列，不能套上面的公式。换个角度看：1 = 1×1，4 = 2×2，9 = 3×3，16 = 4×4，25 = 5×5。每一项都是“序号乘序号”，所以第 n 项是 n2。

验证：n = 1 时 12 = 1 ✓；n = 2 时 22 = 4 ✓；n = 3 时 32 = 9 ✓；n = 4 时 42 = 16 ✓。第 10 项就是 102 = 100。

顺便注意一个有趣的事实：1, 4, 9, 16 这些平方数，正好是前若干个连续奇数的和。1 = 1；1 + 3 = 4；1 + 3 + 5 = 9；1 + 3 + 5 + 7 = 16。也就是说，前 n 个奇数的和等于 n2。这条规律在后面还会用到。

4. 符号交替：一正一负的数列

数列 1, −1, 1, −1, … 的绝对值都是 1，只是符号在交替。奇数项是 1，偶数项是 −1。怎样用一个式子统一表示？可以借助 (−1) 的幂：

符号交替的两种写法
第 n 项 = (−1)n+1
或：n 为奇数时是 1，n 为偶数时是 −1

检验第一种写法：n = 1 时 (−1)2 = 1 ✓；n = 2 时 (−1)3 = −1 ✓；n = 3 时 (−1)4 = 1 ✓；n = 4 时 (−1)5 = −1 ✓。四项全对。

如果数列是 −1, 1, −1, 1, …，符号正好反过来，这时第 n 项写成 (−1)n：n = 1 时 (−1)1 = −1 ✓，n = 2 时 (−1)2 = 1 ✓，n = 3 时 (−1)3 = −1 ✓。

符号交替常常和别的规律“叠加”。例如 2, −4, 6, −8, …：绝对值依次是 2, 4, 6, 8，第 n 项是 2n；符号是正、负、正、负，对应 (−1)n+1。两者相乘，第 n 项 = (−1)n+1 × 2n。验证：n = 1 时 1×2 = 2 ✓；n = 2 时 (−1)3×4 = −4 ✓；n = 3 时 (−1)4×6 = 6 ✓；n = 4 时 (−1)5×8 = −8 ✓。

提示：遇到符号交替，先不管符号，把绝对值组成的数列的通项写出来，再单独乘一个 (−1) 的幂来控制符号。奇数项为正就用 (−1)n+1，奇数项为负就用 (−1)n。分两步写，不容易错。

5. 分数数列：分子分母各走各的

数列 1/2, 2/3, 3/4, 4/5, … 中，分子依次是 1, 2, 3, 4，第 n 项的分子是 n；分母依次是 2, 3, 4, 5，第 n 项的分母是 n + 1。所以第 n 项是 n/(n+1)。

验证：n = 1 时 1/2 ✓；n = 2 时 2/3 ✓；n = 3 时 3/4 ✓；n = 4 时 4/5 ✓。第 10 项就是 10/11。

分数数列的通项，分子、分母往往各是一个简单数列。分别找，再拼起来，这是常用的办法。要注意多项式做分子或分母时要加括号，例如 (n+1)/(n+2)。

6. 月历中的规律

月历是研究规律的好材料。一个月历每行排 7 天，从星期日到星期六。于是有两条最基本的关系：同一行中，右边的数比左边的大 1；同一列中，下面的数比上面的大 7。

如果月历中某个数是 a，那么它周围几个数就可以用 a 表示出来：左边是 a − 1，右边是 a + 1，上面是 a − 7，下面是 a + 7，右上是 a − 6，右下是 a + 8，左下是 a + 6，左上是 a − 8。

把方框圈成“十字形”，也就是中间一个数加上它上、下、左、右四个数。设中间的数为 a，五个数分别是 a − 7, a − 1, a, a + 1, a + 7。把它们加起来：

十字形五个数的和
(a − 7) + (a − 1) + a + (a + 1) + (a + 7) = 5a

−7 与 +7 抵消，−1 与 +1 抵消，只剩下 5 个 a。所以十字形五个数的和总是中心数的 5 倍。用图 40 检验：中心 17，五个数是 10, 16, 17, 18, 24，和 = 10 + 16 + 17 + 18 + 24 = 85，而 5 × 17 = 85 ✓。

再看九宫格，也就是 3 行 3 列共九个数。设中心为 a，九个数是 a − 8, a − 7, a − 6, a − 1, a, a + 1, a + 6, a + 7, a + 8。全部相加：

九宫格九个数的和
和 = 9a + (−8 − 7 − 6 − 1 + 0 + 1 + 6 + 7 + 8) = 9a

括号里的数两两抵消，结果是 0，所以九宫格九个数的和恰好是中心数的 9 倍。也可以这样理解：九宫格里关于中心对称的两数，和都是 2a，例如 9 + 25 = 34 = 2 × 17，10 + 24 = 34，11 + 23 = 34，16 + 18 = 34。四对共 8 个数，加上中心 17，和 = 4 × 2a + a = 9a。用图 40 检验：9 + 10 + 11 + 16 + 17 + 18 + 23 + 24 + 25 = 153 = 9 × 17 ✓。

易错：用月历规律时要注意边界。同一行最左边的数没有“左边的数”，最右边的数没有“右边的数”；跨月的日期也不能直接套用。另外，“同行差 1、同列差 7”这个顺序不要记反：横着走一步差 1，竖着走一步差 7。还有，九宫格的中心数必须落在能取到上下左右各一格的位置，不能是月历的第一行或最后一行。

7. 算式中的规律

规律不只在数列里，算式里也有。看下面一组等式：

一组有规律的算式
1 × 3 + 1 = 4 = 22
2 × 4 + 1 = 9 = 32
3 × 5 + 1 = 16 = 42
4 × 6 + 1 = 25 = 52

先看左边的乘法：第 1 个式子是 1 × 3，两个因数相差 2，小的那个是 1；第 2 个式子是 2 × 4，小的那个是 2；第 3 个是 3 × 5，小的那个是 3。所以第 n 个式子的乘法部分是 n(n + 2)。再加上 1，左边就是 n(n + 2) + 1。

再看右边：4 = 22，9 = 32，16 = 42，25 = 52。底数 2, 3, 4, 5 比序号 1, 2, 3, 4 各大 1，所以右边是 (n + 1)2。于是猜想：

算式规律的通式
n(n + 2) + 1 = (n + 1)2

验证：n = 1 时，1 × 3 + 1 = 4 = 22 ✓；n = 2 时，2 × 4 + 1 = 9 = 32 ✓；n = 3 时，3 × 5 + 1 = 16 = 42 ✓；n = 4 时，4 × 6 + 1 = 25 = 52 ✓。

这个规律为什么对任意正整数 n 都成立？把左边展开就知道了：n(n + 2) + 1 = n2 + 2n + 1，而 (n + 1)2 = (n + 1)(n + 1) = n2 + n + n + 1 = n2 + 2n + 1。两边都是 n2 + 2n + 1，所以恒等。这里用到了乘法分配律：n(n + 2) = n · n + n · 2。

拓展：还有一组更简单的算式规律：1 + 3 = 4 = 22，1 + 3 + 5 = 9 = 32，1 + 3 + 5 + 7 = 16 = 42。前 n 个连续奇数的和等于 n2。这个结论和我们前面说的平方数正好呼应：平方数数列 1, 4, 9, 16 的第 n 项是 n2，而它恰好也是前 n 个奇数的和。
例 1 由数列求通项，并判断某个数是否在数列中

观察数列 5, 9, 13, 17, …，(1) 写出它的第 n 项；(2) 求第 20 项；(3) 2025 是不是这个数列中的项？如果是，是第几项？

解

(1) 相邻两项的差都是 4，是等差数列。把每一项拆开看：第 1 项 5 = 4 × 1 + 1，第 2 项 9 = 4 × 2 + 1，第 3 项 13 = 4 × 3 + 1，第 4 项 17 = 4 × 4 + 1。所以第 n 项是 4n + 1。

验证：n = 1 时 4 × 1 + 1 = 5 ✓；n = 2 时 4 × 2 + 1 = 9 ✓；n = 3 时 4 × 3 + 1 = 13 ✓；n = 4 时 4 × 4 + 1 = 17 ✓。四项全部吻合。

(2) 把 n = 20 代入：4 × 20 + 1 = 81，所以第 20 项是 81。

(3) 设 4n + 1 = 2025，则 4n = 2024，解得 n = 506。因为 506 是正整数，所以 2025 是这个数列的第 506 项。

答：第 n 项是 4n + 1；第 20 项是 81；2025 是第 506 项。

变式：数列 5, 9, 13, 17, … 中，2024 是不是它的项？解 4n + 1 = 2024 得 4n = 2023，n = 2023/4，不是正整数，所以 2024 不在这个数列中。判断一个数是否在数列里，关键就是看方程解出的 n 是不是正整数。

例 2 月历中九宫格的和

在某月的月历中，用正方形方框圈出 3 行 3 列共九个数（如图 40）。(1) 若中心的数是 a，用含 a 的代数式表示这九个数的和；(2) 若九个数的和是 162，求中心数；(3) 九个数的和可能是 100 吗？为什么？

解

(1) 由月历的规律，同一行相邻两数差 1，同一列相邻两数差 7。以中心 a 为基准，九个依次是：上一行 a − 8、a − 7、a − 6；中间一行 a − 1、a、a + 1；下一行 a + 6、a + 7、a + 8。

把它们相加：和 = 9a + (−8 − 7 − 6 − 1 + 0 + 1 + 6 + 7 + 8)。括号里 −8 与 8、−7 与 7、−6 与 6、−1 与 1 分别抵消，剩下 0，所以和 = 9a。

(2) 由 9a = 162 得 a = 18。检验：以 18 为中心的九个数是 10, 11, 12, 17, 18, 19, 24, 25, 26，和 = 10 + 11 + 12 + 17 + 18 + 19 + 24 + 25 + 26 = 162 ✓。

(3) 若 9a = 100，则 a = 100/9。因为 a 必须是月历中的日期，是正整数，而 100/9 不是整数，所以九个数的和不可能是 100。

答：九个数的和是 9a；和为 162 时中心数是 18；和不可能等于 100。

例 3 符号与分数叠加的数列

观察数列 1/2, −3/4, 5/6, −7/8, …，(1) 写出它的第 n 项；(2) 求第 10 项；(3) 这个数列中有没有等于 −1 的项？

解

(1) 先看符号：第 1 项正、第 2 项负、第 3 项正、第 4 项负，奇数项为正，偶数项为负，可以用 (−1)n+1 控制。

再看绝对值：1/2, 3/4, 5/6, 7/8, …，分子是 1, 3, 5, 7，即 2n − 1；分母是 2, 4, 6, 8，即 2n。所以绝对值部分是 (2n − 1)/(2n)。

合起来，第 n 项 = (−1)n+1 × (2n − 1)/(2n)。

验证：n = 1 时 (−1)2 × 1/2 = 1/2 ✓；n = 2 时 (−1)3 × 3/4 = −3/4 ✓；n = 3 时 (−1)4 × 5/6 = 5/6 ✓；n = 4 时 (−1)5 × 7/8 = −7/8 ✓。

(2) n = 10 时，(−1)11 × (2×10 − 1)/(2×10) = −19/20。所以第 10 项是 −19/20。

(3) 若某一项等于 −1，则该项的绝对值必须等于 1。而绝对值 (2n − 1)/(2n) 的分子总比分母小 1，所以它总小于 1，不可能等于 1。因此这个数列中没有等于 −1 的项。

答：第 n 项是 (−1)n+1 × (2n − 1)/(2n)；第 10 项是 −19/20；没有等于 −1 的项。

8. 练一练

1 【基础】观察数列 2, 6, 10, 14, …，(1) 写出它的第 n 项；(2) 求第 10 项。
答案与解析

(1) 相邻两项的差都是 4，是等差数列。第 1 项 2 = 4 × 1 − 2，第 2 项 6 = 4 × 2 − 2，第 3 项 10 = 4 × 3 − 2，所以第 n 项是 4n − 2。

验证：n = 1 时 4 − 2 = 2 ✓；n = 2 时 8 − 2 = 6 ✓；n = 3 时 12 − 2 = 10 ✓；n = 4 时 16 − 2 = 14 ✓。

(2) n = 10 时，4 × 10 − 2 = 38，所以第 10 项是 38。

2 【基础】数列 1, 4, 9, 16, 25, … 的第 n 项是什么？第 12 项是多少？
答案与解析

每一项都是序号乘序号：1 = 12，4 = 22，9 = 32，16 = 42，25 = 52，所以第 n 项是 n2。

验证：n = 1 时 12 = 1 ✓；n = 2 时 22 = 4 ✓；n = 3 时 32 = 9 ✓；n = 4 时 42 = 16 ✓。

第 12 项是 122 = 144。

3 【提升】某月月历中，同一列相邻的三个日期之和是 60，求这三个日期。
答案与解析

设中间的日期为 a。由月历规律，同一列上下相邻相差 7，所以上面的日期是 a − 7，下面的是 a + 7。

三数之和 = (a − 7) + a + (a + 7) = 3a。

由 3a = 60 得 a = 20，于是三个日期是 13, 20, 27。

验证：13 + 20 + 27 = 60 ✓；且 13、20、27 两两相差 7，确实在同一列 ✓。

答：这三个日期是 13 日、20 日、27 日。

4 【提升】观察算式 1 × 3 + 1 = 4 = 22，2 × 4 + 1 = 9 = 32，3 × 5 + 1 = 16 = 42。(1) 写出第 4 个算式；(2) 用含 n 的式子表示第 n 个算式，并用 n = 5 验证；(3) 说明这个式子为什么总成立。
答案与解析

(1) 第 4 个算式是 4 × 6 + 1 = 25 = 52。

(2) 第 n 个算式中，乘法的两个因数相差 2，较小的是 n，较大的是 n + 2；右边是 (n + 1) 的平方。所以第 n 个算式为 n(n + 2) + 1 = (n + 1)2。

验证：n = 1 时 1 × 3 + 1 = 4 = 22 ✓；n = 2 时 2 × 4 + 1 = 9 = 32 ✓；n = 3 时 3 × 5 + 1 = 16 = 42 ✓；n = 5 时 5 × 7 + 1 = 36 = 62 ✓。

(3) 把左边展开：n(n + 2) + 1 = n2 + 2n + 1（用乘法分配律）。而 (n + 1)2 = n2 + 2n + 1。两边化简后完全相同，所以对任意正整数 n 都成立。

5 【拓展】观察数列 −1/2, 2/5, −3/10, 4/17, …，(1) 写出它的第 n 项；(2) 求第 6 项。
答案与解析

(1) 分三步看。符号：第 1 项负、第 2 项正、第 3 项负、第 4 项正，奇数项为负，用 (−1)n 控制。

分子：1, 2, 3, 4, …，第 n 项是 n。

分母：2, 5, 10, 17, …，相邻两项的差是 3, 5, 7（连续奇数），每一项都等于序号平方加 1：12 + 1 = 2，22 + 1 = 5，32 + 1 = 10，42 + 1 = 17，所以第 n 项的分母是 n2 + 1。

合起来，第 n 项 = (−1)n × n/(n2 + 1)。

验证：n = 1 时 (−1)1 × 1/2 = −1/2 ✓；n = 2 时 (−1)2 × 2/5 = 2/5 ✓；n = 3 时 (−1)3 × 3/10 = −3/10 ✓；n = 4 时 (−1)4 × 4/17 = 4/17 ✓。

(2) n = 6 时，(−1)6 × 6/(36 + 1) = 6/37，所以第 6 项是 6/37。

课时 2探索图形规律

上一课时，规律藏在数和算式里；这一课时，规律藏在图形里。用火柴棒摆正方形、用小圆点摆点阵、把小正方形拼成长条——每多摆一个，需要多用几根火柴、多几个点、周长变成多少？这些问题看起来要用眼睛数，其实只要抓住“每增加一个，变化了多少”，就能用代数式把任意一个图形的情况一次说清。

1. 火柴棒摆正方形

用火柴棒摆正方形，要求排成一排，相邻两个正方形共用一条边，如图 41 上面一行。摆 1 个正方形要用 4 根；摆 2 个时，第二个正方形有一条边和第一个共用，只需要再加 3 根，共 7 根；摆 3 个再加 3 根，共 10 根；摆 4 个再加 3 根，共 13 根。

把根数排成一列：4, 7, 10, 13, …，这是一个等差数列，公差是 3。第 1 个用 4 根，从第 1 个到第 n 个一共增加了 (n − 1) 次，每次增加 3 根，所以第 n 个图形需要

摆 n 个正方形所需火柴棒
4 + 3(n − 1) = 3n + 1（根）

验证：n = 1 时 3 × 1 + 1 = 4 ✓；n = 2 时 3 × 2 + 1 = 7 ✓；n = 3 时 3 × 3 + 1 = 10 ✓；n = 4 时 3 × 4 + 1 = 13 ✓。四个都对，说明 3n + 1 就是通项。

还可以换一种“看结构”的数法。一排 n 个正方形，上面那条边由 n 根火柴接成，下面那条边也由 n 根接成，竖着的边一共有 n + 1 根。所以总数 = n + n + (n + 1) = 3n + 1。两种方法结果一样，但第二种更能说明“为什么是 3n + 1”，而不是碰巧凑出来的。

有了通项，问“摆 10 个要几根”，只要代 n = 10：3 × 10 + 1 = 31（根）；问“摆 100 个”，代 n = 100：3 × 100 + 1 = 301（根）。反过来，如果问“有 100 根火柴能摆几个”，就解 3n + 1 = 100，得 3n = 99，n = 33，能摆 33 个。

2. 火柴棒摆三角形

用同样的办法摆正三角形，排成一排，相邻两个共用一条边，如图 41 下面一行。摆 1 个用 3 根；摆 2 个时第二个共用一条边，再加 2 根，共 5 根；摆 3 个再加 2 根，共 7 根。

根数排成一列：3, 5, 7, …，公差是 2。第 1 个用 3 根，共增加 (n − 1) 次，所以

摆 n 个三角形所需火柴棒
3 + 2(n − 1) = 2n + 1（根）

验证：n = 1 时 2 × 1 + 1 = 3 ✓；n = 2 时 2 × 2 + 1 = 5 ✓；n = 3 时 2 × 3 + 1 = 7 ✓。n = 10 时，2 × 10 + 1 = 21（根）。

易错：数火柴棒最容易犯两个错。一是忘记“共用的边只算一次”，把每个图形的边数直接相加，摆 n 个正方形就写成 4n 根，比正确答案 3n + 1 多算了 (n − 1) 根。二是只写 3n 而漏掉那个“+1”，因为第 1 个图形并不需要 3 根，而是 4 根。记住：通项 = 第 1 个图形的根数 + 每次增加量 × (n − 1)，先把“第 1 个用几根”和“每次多几根”这两个数找准，再化简。

3. 点阵中的三角形数

用小圆点按图 42 的样子摆“三角形点阵”：第 1 个图形只有 1 个点；第 2 个图形有 2 行，从上到下每行 1、2 个点，共 3 个点；第 3 个图形有 3 行，每行 1、2、3 个点，共 6 个点；第 4 个图形有 4 行，共 10 个点。

点数排成一列：1, 3, 6, 10, …。相邻两项的差是 2, 3, 4，差在变，所以它不是等差数列。但它的结构很规整：第 n 个图形有 n 行，从上到下每行分别是 1, 2, 3, …, n 个点。所以总点数是

第 n 个三角形点阵的点数
1 + 2 + 3 + … + n = n(n + 1)/2（个）

验证：n = 1 时 1 × 2/2 = 1 ✓；n = 2 时 2 × 3/2 = 3 ✓；n = 3 时 3 × 4/2 = 6 ✓；n = 4 时 4 × 5/2 = 10 ✓。和图形上数出来的一模一样。

为什么是 n(n + 1)/2 而不是 n(n + 1)？拿两个完全一样的点阵，其中一个倒过来，与另一个拼在一起，就得到一个 n 行、(n + 1) 列的长方形点阵，共 n(n + 1) 个点。原来的点阵只占其中的一半，所以是 n(n + 1)/2 个。以 n = 4 为例：拼成的长方形是 4 行 5 列共 20 个点，原来那个占一半，即 10 个 ✓。

提示：1 + 2 + 3 + … + n 这种“从 1 加到 n”的和，也常写成 n(n + 1)/2，叫做三角形数。第 10 个三角形数是 10 × 11/2 = 55。它与平方数不同：平方数是“正方形点阵”，三角形数是“三角形点阵”，不要混淆。

4. 小正方形拼接的周长

把 n 个边长是 1 的小正方形拼成一排，如图 43。拼 1 个时是 1 个正方形，周长 4；拼 2 个时成一个 1 × 2 的长方形，周长 6；拼 3 个时周长 8；拼 4 个时周长 10。

周长排成一列：4, 6, 8, 10, …，公差是 2，所以第 n 个图形的周长是 4 + 2(n − 1) = 2n + 2。验证：n = 1 时 2 + 2 = 4 ✓；n = 2 时 4 + 2 = 6 ✓；n = 3 时 6 + 2 = 8 ✓；n = 4 时 8 + 2 = 10 ✓。

也可以从结构上想：n 个小正方形拼成一排，得到一个长 n、宽 1 的长方形，周长 = 2 × (长 + 宽) = 2(n + 1) = 2n + 2。还可以用“减少”的思路：n 个正方形各自周长之和是 4n，每拼接一次有 2 条边重合，一共拼了 (n − 1) 次，所以周长 = 4n − 2(n − 1) = 2n + 2。三条路殊途同归。

拓展：如果把这 n 个小正方形拼成一个大正方形（要求 n 是完全平方数），那么边长是 √n，周长是 4√n。例如 9 个小正方形拼成 3 × 3 的大正方形，周长是 12；而拼成一排时长 9、宽 1，周长是 20。同样多的小正方形，拼法不同，周长也不同——拼得越“方”，周长越小。

5. 多边形的对角线

连接多边形不相邻的两个顶点，得到的线段叫做对角线。四边形有 2 条对角线，五边形有 5 条，六边形有 9 条。怎样用 n 表示 n 边形的对角线数？

先固定一个顶点来数。从一个顶点出发，它不能连自己，也不能连与它相邻的两个顶点，剩下的 (n − 3) 个顶点都可以连成对角线。多边形有 n 个顶点，照这样数一共能数出 n(n − 3) 条。

但这样数，每条对角线被它的两个端点各数了一次，重复了一倍。所以真正的条数要除以 2：

n 边形的对角线数
n(n − 3)/2（条），其中 n ≥ 3

验证：n = 3 时 3 × 0/2 = 0，三角形没有对角线 ✓；n = 4 时 4 × 1/2 = 2 ✓；n = 5 时 5 × 2/2 = 5 ✓；n = 6 时 6 × 3/2 = 9 ✓。和实际画出来数的一致。

十二边形的对角线数是 12 × 9/2 = 54（条）；二十边形是 20 × 17/2 = 170（条）。

易错：对角线公式里有两个容易出错的地方。第一，n − 3 中的 3 是“自己 + 两个相邻顶点”，不是 2，也不是 4；第二，最后一定要除以 2，因为每条对角线被两个端点各数了一次。如果忘了除以 2，算出的数会正好是正确答案的 2 倍。另外，三角形（n = 3）没有对角线，公式给出 0，是对的。

6. 图形规律与数字规律的对应

回头看，这一课时遇到的每个图形问题，都可以翻译成一个数列问题：

  • 火柴棒摆正方形：4, 7, 10, 13, … 是公差为 3 的等差数列，通项 3n + 1。
  • 火柴棒摆三角形：3, 5, 7, 9, … 是公差为 2 的等差数列，通项 2n + 1。
  • 三角形点阵：1, 3, 6, 10, … 不是等差数列（差在变），通项 n(n + 1)/2。
  • 正方形拼接的周长：4, 6, 8, 10, … 是公差为 2 的等差数列，通项 2n + 2。
  • 多边形对角线：n = 4, 5, 6 时依次是 2, 5, 9，通项 n(n − 3)/2。

所以“探索图形规律”其实有两步：先把图形翻译成数（数一数第 1、2、3 个图形各是多少），再从数里找规律、写通项。图形给的是直观，代数式给的是普适。这就是数形结合的好处。

方法归纳：探索图形规律，按“数—看—写—验”四步走：
  • 第一步，数：照图数出第 1、2、3 个图形对应的数量，列成一列数。
  • 第二步，看：看相邻两个数差几，是固定不变，还是在变；也可以直接看图形结构，想“每多摆一个，多用了哪几根”。
  • 第三步，写：用“第 1 个的数量 + 每次增加量 × (n − 1)”写出通项，再化简。
  • 第四步，验：把 n = 1, 2, 3 代入，逐一核对是否等于数出来的结果。

例 1 火柴棒摆正方形的通项与应用

按图 41 上面一行的方式，把正方形排成一排，相邻两个共用一条边。(1) 摆 5 个需要多少根火柴棒？(2) 摆 n 个需要多少根？(3) 摆 100 个需要多少根？(4) 用 100 根火柴棒最多能摆几个这样的正方形？

解

(1) 数一数：摆 1 个用 4 根，摆 2 个用 7 根，摆 3 个用 10 根，摆 4 个用 13 根。每次多 3 根，所以摆 5 个需要 13 + 3 = 16 根。

(2) 第 1 个用 4 根，从第 1 个到第 n 个一共增加了 (n − 1) 次，每次 3 根，所以需要 4 + 3(n − 1) = 3n + 1（根）。

验证：n = 1 时 3 + 1 = 4 ✓；n = 2 时 6 + 1 = 7 ✓；n = 3 时 9 + 1 = 10 ✓；n = 4 时 12 + 1 = 13 ✓；n = 5 时 15 + 1 = 16 ✓。

(3) n = 100 时，3 × 100 + 1 = 301（根）。

(4) 设 3n + 1 ≤ 100，则 3n ≤ 99，n ≤ 33。所以最多能摆 33 个，此时用去 3 × 33 + 1 = 100（根），正好用完。

答：摆 5 个需 16 根；摆 n 个需 (3n + 1) 根；摆 100 个需 301 根；100 根最多摆 33 个。

变式：按同样方式摆三角形（图 41 下面一行），摆 n 个需要 (2n + 1) 根。验证：n = 1 时 3 根 ✓，n = 2 时 5 根 ✓，n = 3 时 7 根 ✓。若用 61 根火柴，则 2n + 1 = 61，得 n = 30，能摆 30 个。

例 2 三角形点阵的点数

按图 42 的方式摆三角形点阵。(1) 第 n 个点阵有多少个点？(2) 第 8 个点阵有多少个点？(3) 有没有哪个点阵恰好有 100 个点？

解

(1) 第 n 个点阵有 n 行，从上到下每行依次有 1, 2, 3, …, n 个点，所以总点数是 1 + 2 + … + n = n(n + 1)/2。

验证：n = 1 时 1 × 2/2 = 1 ✓；n = 2 时 2 × 3/2 = 3 ✓；n = 3 时 3 × 4/2 = 6 ✓；n = 4 时 4 × 5/2 = 10 ✓。与图 42 数出的结果完全一致。

(2) n = 8 时，8 × 9/2 = 36，所以第 8 个点阵有 36 个点。

(3) 设 n(n + 1)/2 = 100，则 n(n + 1) = 200。试算：n = 13 时 13 × 14 = 182；n = 14 时 14 × 15 = 210。因为 n(n + 1) 随 n 增大而增大，182 < 200 < 210，所以没有正整数 n 使 n(n + 1) = 200。

答：第 n 个点阵有 n(n + 1)/2 个点；第 8 个有 36 个点；不存在恰好 100 个点的点阵。

例 3 多边形的对角线

(1) 十二边形有多少条对角线？(2) 一个多边形的对角线共有 20 条，它是几边形？

解

(1) 从 n 边形的一个顶点出发，除了它本身和与它相邻的两个顶点，其余 (n − 3) 个顶点都能连成对角线。照这样，n 个顶点一共能数出 n(n − 3) 条，但每条对角线被两个端点各数了一次，所以要除以 2，即 n(n − 3)/2 条。

验证：n = 3 时 3 × 0/2 = 0 ✓（三角形没有对角线）；n = 4 时 4 × 1/2 = 2 ✓；n = 5 时 5 × 2/2 = 5 ✓；n = 6 时 6 × 3/2 = 9 ✓。

当 n = 12 时，12 × (12 − 3)/2 = 12 × 9/2 = 54（条）。

(2) 设 n(n − 3)/2 = 20，则 n(n − 3) = 40。试算：n = 7 时 7 × 4 = 28；n = 8 时 8 × 5 = 40；n = 9 时 9 × 6 = 54。所以 n = 8。

检验：八边形的对角线数为 8 × 5/2 = 20 ✓。

答：十二边形有 54 条对角线；对角线共 20 条的是八边形。

1 【基础】按图 41 下面一行的方式用火柴棒摆三角形（一排、共用边），摆 6 个需要多少根火柴棒？摆 n 个呢？
答案与解析

摆 1 个用 3 根，摆 2 个用 5 根，摆 3 个用 7 根，每次多 2 根。所以摆 n 个需要 3 + 2(n − 1) = 2n + 1（根）。

验证：n = 1 时 2 + 1 = 3 ✓；n = 2 时 4 + 1 = 5 ✓；n = 3 时 6 + 1 = 7 ✓。

n = 6 时，2 × 6 + 1 = 13，所以摆 6 个需要 13 根。

2 【基础】第 n 个三角形点阵有 n(n + 1)/2 个点，第 12 个点阵有多少个点？
答案与解析

n = 12 时，12 × 13/2 = 156/2 = 78，所以第 12 个点阵有 78 个点。

验证公式：n = 1 时 1 个点 ✓；n = 2 时 3 个点 ✓；n = 3 时 6 个点 ✓，与图形一致。

也可以这样核对：第 12 个点阵有 12 行，从上到下每行 1, 2, …, 12 个点，和 = (1 + 12) × 12 ÷ 2 = 78。

3 【提升】把 n 个边长是 1 的小正方形拼成一排，所得图形的周长是 (2n + 2)。若周长是 30，求 n。
答案与解析

由 2n + 2 = 30 得 2n = 28，n = 14。

验证公式：n = 1 时周长 4 ✓；n = 2 时周长 6 ✓；n = 3 时周长 8 ✓。

检验答案：14 个小正方形拼成 1 × 14 的长方形，周长 = 2 × (1 + 14) = 30 ✓。

答：n = 14。

4 【提升】十边形有多少条对角线？
答案与解析

n 边形的对角线数为 n(n − 3)/2。当 n = 10 时，10 × (10 − 3)/2 = 10 × 7/2 = 35（条）。

验证公式：n = 4 时 4 × 1/2 = 2 ✓；n = 5 时 5 × 2/2 = 5 ✓；n = 6 时 6 × 3/2 = 9 ✓。

答：十边形有 35 条对角线。

5 【拓展】按图 41 上面一行的方式摆正方形（一排、共用边），需要 (3n + 1) 根火柴棒。用 2024 根火柴棒能否恰好摆出若干个这样的正方形？若不能，最少再添几根才可以？
答案与解析

先验证公式：n = 1 时 4 根 ✓；n = 2 时 7 根 ✓；n = 3 时 10 根 ✓，与图中数出的一致。

若恰好用完 2024 根，则 3n + 1 = 2024，即 3n = 2023。因为 2023 ÷ 3 = 674 余 1，n 不是正整数，所以不能恰好用完 2024 根。

再试 2025 根：3n = 2024，2024 ÷ 3 余 2，也不行。

再试 2026 根：3n = 2025，n = 675，是正整数。

检验：3 × 675 + 1 = 2025 + 1 = 2026 ✓。

答：用 2024 根不能恰好摆出整数个正方形；最少再添 2 根（共 2026 根），可以摆 675 个。

本节知识网络：
  • 核心思路：观察（数出前几项）→ 猜想（写出含 n 的式子）→ 验证（代 n = 1, 2, 3）→ 表达（化简成最简代数式）。
  • 等差数列：相邻两项的差固定，第 n 项 = 首项 + (n − 1) × 公差。如 3, 7, 11, … 的通项是 4n − 1。
  • 平方数：1, 4, 9, 16, … 的第 n 项是 n2；前 n 个奇数的和也等于 n2。
  • 符号交替：奇数项为正用 (−1)n+1，奇数项为负用 (−1)n，与绝对值部分的通项相乘即可。
  • 分数数列：分子、分母各找一个简单数列，分别写出通项再拼起来；多项式作分子或分母要加括号。
  • 月历规律：同一行相邻两数差 1，同一列相邻两数差 7；以中心数 a 为基准，十字形五个数的和是 5a，九宫格九个数的和是 9a。
  • 算式规律：如 n(n + 2) + 1 = (n + 1)2，把左边展开成 n2 + 2n + 1，就能说明它对任意正整数 n 都成立。
  • 火柴棒：摆 n 个正方形（一排、共用边）需 (3n + 1) 根；摆 n 个三角形需 (2n + 1) 根。规律是“第 1 个的根数 + 每次增加量 × (n − 1)”。
  • 点阵与拼接：三角形点阵第 n 个有 n(n + 1)/2 个点；n 个小正方形拼成一排的周长是 (2n + 2)。
  • 多边形对角线：n 边形有 n(n − 3)/2 条对角线（n ≥ 3），每个顶点可连 n − 3 条，每条被算两次。
  • 数形结合：图形给直观，代数式给普适。把图形翻译成数列，再从数列找通项，是本节最常用的转化。
  • 注意：不完全归纳只保证前几项吻合，必须验证；用通项判断某个数是否在数列中，要看方程解出的 n 是不是正整数。

问题解决策略：归纳

把 1、3、5、7 加起来，结果是 16；把 1、3、5、7、9 加起来，结果是 25——它们恰好都是某个数的平方。多边形的边数每增加一条，内角和就增加 180°。这些结论最初都不是“算出来”的，而是从几个具体例子中“看出来”的。从特殊的事实中发现一般的规律，这就是归纳。本节课我们来学习这一重要的解决问题的策略。

学习目标

  • 能说出归纳的含义，知道它是一种“从特殊到一般”的思维方法，并体会它在发现结论中的作用。
  • 经历“观察—猜想—验证—表达”的完整归纳过程，会用含 n 的代数式表达一般结论。
  • 会用归纳解决连续奇数求和、握手与比赛、多边形内角和等典型问题，并能用 n=1，2，3 检验所得结论。

课时 1问题解决策略：归纳

想一想：结论是从哪里来的

请先算一算下面几个式子：

1+3=4；1+3+5=9；1+3+5+7=16；1+3+5+7+9=25。

算完以后，不要急着往下看，先盯着这四个结果看一会儿：4，9，16，25。它们有什么共同点？

你可能已经发现：4=2×2，9=3×3，16=4×4，25=5×5。也就是说，从 1 开始的连续奇数相加，结果恰好是一个数的平方，而且这个数正好等于奇数的个数——加 2 个奇数得 22，加 3 个奇数得 32，加 4 个奇数得 42。

我们并没有计算“1+3+5+…一直加到某个数”的一般方法，只是看了四个具体的例子，就“看出”了一条规律。这种由若干个具体事例概括出一般结论的做法，就是本节课要研究的归纳。

再看一个例子。三角形的内角和是 180°，四边形的内角和是 360°，五边形的内角和是 540°。三个例子摆在一起，规律也很明显：边数每增加 1，内角和就增加 180°。于是我们可以猜：n 边形的内角和是 (n−2)×180°。这个猜想对不对？为什么对？这正是归纳要回答的问题。

1. 什么是归纳

从若干个具体事例中发现共同规律，提出猜想，再加以验证或说明理由，这种由特殊到一般的思维方法，叫做归纳。

这个定义里有四个关键词，缺一不可：

若干个具体事例——归纳的起点是“看例子”，而且例子不能太少，一两个例子说明不了问题；

共同规律——要善于从不同的例子中找出“都一样”的地方，也就是变化的量背后不变的关系；

提出猜想——把发现的规律用一句话或一个式子写出来，它此时还只是一个“猜想”，不是已经成立的结论；

验证或说明理由——用更多的例子检验猜想，或者用代数式推演，说明它对所有情况都成立。

要点：归纳是“从特殊到一般”。特殊，指的是一个个具体的例子；一般，指的是对任意情形都成立的结论。归纳的价值在于帮助我们发现结论、提出猜想、找到思路，数学中很多公式和法则，最初都是这样被发现的。

归纳在日常生活中的影子随处可见。医生看病，要看过许多相似的病例，才能总结出某种病的典型症状；农民种地，要观察许多年的气候，才能总结出“清明前后，种瓜点豆”的农谚；警察破案，要从若干起案件中找到共同点，才能判断是否为同一团伙所为。这些做法本质上都是归纳——从有限的、具体的经验中，提炼出一般的认识。

数学中的归纳比生活中的归纳更进一步：生活中的归纳往往停在“经验”层面，数学中的归纳则要求把结论写成准确的代数式，并且说明它为什么对任意情形都成立。这正是数学的严谨之处。

第二步：猜想。把发现的关系用含 n 的代数式写出来。写的时候要交代清楚：n 表示什么？从几开始取？例如“设 n 为正整数”或“设 n 为不小于 3 的整数”。没有交代范围的猜想，是不完整的。

第四步：表达。用代数式把结论写清楚，并说明理由。理由可以来自图形的结构（例如点阵中多出的一圈），也可以来自代数式的变形（例如把 n(n−1)/2 化简、检验）。只有说清了理由，猜想才真正变成结论。

提示：归纳时最有用的一句话是“第 n 个比第 n−1 个多了什么”。找到了“多出来的部分”，往往就找到了通项。例如点阵中每次多出的一圈、多边形中每次多出的一个三角形、握手中每次多出的 n−1 次握手。

3. 案例一：连续奇数的和

回到开头的问题：从 1 开始的连续奇数相加，和是多少？

先观察几个特例：

1=12；1+3=4=22；1+3+5=9=32；1+3+5+7=16=42；1+3+5+7+9=25=52。

把这五个等式排在一起，规律就清楚了：等号左边有几个奇数，右边就是几的平方。第 n 个等式左边是 n 个连续奇数，最后一个是 2n−1，右边是 n2。

连续奇数的和
1+3+5+…+(2n−1)=n2（n 为正整数）

这个结论还可以用图形来看，而且图形能告诉我们“为什么”。

看图 51：把 1 个点看作 1×1 的正方形；再加 3 个点，正好把正方形扩大成 2×2；再加 5 个点，扩大成 3×3；再加 7 个点，扩大成 4×4。每次新增的点排成一个“拐角”，个数依次是 1，3，5，7，…，第 n 次新增 2n−1 个点，而 n 层正方形的点数是 n2。图形把“为什么等于平方”讲清楚了。

用代数式也能说明理由。第 n 个正方形比第 n−1 个正方形多出 2n−1 个点，于是

(n−1)2+(2n−1)=n2−2n+1+2n−1=n2。

这说明“每加一圈就得到下一个平方数”这件事，对任意正整数 n 都成立，而不是只在画得出的前几个图形里成立。

验证一下：取 n=5，左边 1+3+5+7+9=25，右边 52=25，成立；取 n=6，左边比 n=5 时多 11，等于 36，右边 62=36，成立；取 n=7，左边为 36+13=49，右边 72=49，成立。

方法归纳：归纳连续奇数求和，关键是抓住“第 n 项是 2n−1”和“共 n 项”这两件事。已知最后一个奇数求项数时，令 2n−1=最后一个奇数，解出 n 即可。例如 1+3+5+…+99 中，2n−1=99，得 n=50，所以和是 502=2500。

4. 案例二：握手与比赛

新学期开始，一个小组的同学两两握手，互相认识。如果小组里有 n 个人，每两人之间都握一次手，一共要握多少次？

还是从最简单的例子开始观察：

2 个人：只有 1 对，握手 1 次；

3 个人：甲和乙、甲和丙、乙和丙，握手 3 次；

4 个人：在 3 个人的基础上，第 4 个人要分别和前面 3 人握手，共 3+3=6 次；

5 个人：在 4 个人的基础上，第 5 个人要分别和前面 4 人握手，共 6+4=10 次。

把数据排成表：人数 2，3，4，5 对应的次数是 1，3，6，10。相邻两项的差是 2，3，4，正好等于“新增的那个人与前面每个人各握一次”的次数。可是差在变，说明它不是等差数列，直接套公式不行，还得再想一层。

换一个角度数：如果按“每个人握了几次”来数，那么 n 个人中，每人都要和其他 n−1 个人各握一次，所以总共是 n(n−1) 次。但是这样一来，甲和乙的那一次握手，在数甲的时候算了一次，在数乙的时候又算了一次，每次握手都被重复数了两遍。因此总次数应当是

握手（单循环比赛）的总次数
n(n−1)/2（n 为不小于 2 的整数）

图 52 把这个“重复计数”的过程画了出来：5 个点代表 5 个人，任意两点之间的线段代表一次握手。从 A 出发有 4 条线段，说明 A 与其余 4 人各握一次；5 个人都这样数一遍就是 5×4=20，但每条线段都被两端的两个人各数了一次，所以真正不同的线段只有 20÷2=10 条，也就是握手 10 次。

用公式检验前面数出来的结果：n=2 时，2×1/2=1；n=3 时，3×2/2=3；n=4 时，4×3/2=6；n=5 时，5×4/2=10。与逐个数的结果完全一致，猜想得到了验证。

再看 n=6：6×5/2=15。用“增加法”检验：5 个人时 10 次，第 6 个人要新增 5 次，10+5=15，一致。n=7 时，15+6=21，而 7×6/2=21，也一致。

这个公式有很多“马甲”。例如：

① 单循环比赛：n 个队进行单循环赛（每两队赛一场），总场次为 n(n−1)/2；

② 平面上 n 个点（任意三点不共线），两两连线段，共有 n(n−1)/2 条线段；

③ 从 n 个人中任选 2 人组成一组，共有 n(n−1)/2 种选法。

它们的共同点是“从 n 个对象中取 2 个，不计顺序，且不重复”。抓住这个共同点，就能认出同一类问题。

拓展：如果握手有方向（例如互赠贺卡，甲送乙一张和乙送甲一张算两件），那么就没有“重复计数”的问题，总数是 n(n−1)。另外，n 边形的对角线条数是 n(n−3)/2：n 个顶点两两相连共 n(n−1)/2 条线段，去掉 n 条边，剩下的就是对对角线。例如五边形有 5×(5−3)/2=5 条对角线，六边形有 6×3/2=9 条。

5. 案例三：多边形的内角和

三角形的内角和是 180°，这是小学就学过的结论。四边形、五边形、六边形的内角和是多少？

办法是“把不熟悉的问题变成熟悉的问题”：从一个顶点出发画对角线，把多边形分割成若干个三角形。四边形可以分成 2 个三角形，内角和是 2×180°=360°；五边形可以分成 3 个三角形，内角和是 3×180°=540°；六边形可以分成 4 个三角形，内角和是 4×180°=720°。

观察“边数—三角形个数—内角和”这三列数据：

3 边形：1 个三角形，180°；

4 边形：2 个三角形，360°；

5 边形：3 个三角形，540°；

6 边形：4 个三角形，720°。

规律很清楚：三角形的个数总比边数少 2，即 n−2 个，所以内角和是 (n−2)×180°。

多边形内角和
n 边形的内角和 = (n−2)×180°（n 为不小于 3 的整数）

验证：n=3 时，(3−2)×180°=180°；n=4 时，(4−2)×180°=360°；n=5 时，(5−2)×180°=540°；n=6 时，(6−2)×180°=720°。全部与数出来的结果一致。再看 n=7：(7−2)×180°=900°，而六边形到七边形多了一个三角形，720°+180°=900°，也一致。

这里的“理由”很扎实：从一个顶点出发，可以向除它自己和相邻两个顶点之外的 n−3 个顶点画对角线，把 n 边形分成 n−2 个三角形；每个三角形的内角和是 180°，所以内角和是 (n−2)×180°。这不是“看出来的”，而是“推出来的”。

顺便可以推出正 n 边形每个内角的度数：(n−2)×180°÷n。例如正五边形每个内角是 540°÷5=108°，正六边形每个内角是 720°÷6=120°。

易错：使用内角和公式时，n 表示边数，必须是不小于 3 的整数，代入前先确认 n 的含义。另外，(n−2)×180° 中不要漏写括号：写成 n−2×180° 就成了“n 减去 360”，意义完全变了。已知内角和反求边数时，先用内角和除以 180° 再加 2，例如 1440°÷180°=8，8+2=10，所以是十边形。

6. 案例四：末位数字的循环规律

再来看一类“看不出差、也看不出比”的规律。请观察 2 的正整数次幂的个位数字：

21=2，个位是 2；22=4，个位是 4；23=8，个位是 8；24=16，个位是 6；

25=32，个位是 2；26=64，个位是 4；27=128，个位是 8；28=256，个位是 6。

个位数字依次是 2，4，8，6，2，4，8，6……每四个一循环。原因是：个位数字只由前一个数的个位数字决定，2×6=12 的个位又回到 2，于是循环重新开始。

有了这个规律，求 22024 的个位数字就不必真的把这个大数算出来：把指数 2024 除以 4，2024÷4=506，正好整除，说明第 2024 个落在循环的最后一个，个位数字是 6。

同样的方法可以处理 3 的幂：3，9，7，1 循环，周期是 4。求 32025 的个位数字，2025÷4=506 余 1，所以落在循环的第 1 个，个位数字是 3。

拓展：“个位数字循环”也是一种归纳：观察若干个幂的个位，发现它们按固定周期重复，于是猜想周期是 4，再用更多特例验证。要注意的是，验证“循环确实存在”靠的是观察，而说明“为什么一定循环”靠的是“个位只受前一项个位影响”这个道理。两者结合，结论才可靠。

7. 归纳可靠吗：不完全归纳的局限

前面几个案例，归纳都成功了。但归纳并不总是可靠的：验证了若干个特例，并不等于结论对一切都成立。这样的归纳叫做不完全归纳。

看一个著名的例子。计算 n2+n+41 的值：

n=1 时，1+1+41=43，是素数；

n=2 时，4+2+41=47，是素数；

n=3 时，9+3+41=53，是素数；

n=4 时，16+4+41=61，是素数；

n=5 时，25+5+41=71，是素数；

……一直算下去，n=1，2，3，…，39 时，结果都是素数。例如 n=10 时得 151，是素数；n=39 时得 1521+39+41=1601，也是素数。

看到这里，很容易猜想：对任意正整数 n，n2+n+41 都是素数。这个猜想对吗？

不对。取 n=40：

402+40+41=1600+40+41=1681，而 1681=41×41，它是合数，不是素数。

一个反例，就把“对任意正整数都成立”的猜想推翻了。事实上，n=41 时，412+41+41=1681+82=1763=41×43，也不是素数。

易错：“验证了 39 个特例都成立”并不能保证第 40 个也成立。归纳得到的结论只是猜想，要让它成为定理，必须说明理由——或者用代数式推演，证明它对任意情形都成立；或者指出它成立的范围。只看几个例子就宣布“一定成立”，是归纳中最常见的错误。

再举一个例子。观察 2n−1：

n=2 时，22−1=3，是素数；

n=3 时，23−1=7，是素数；

n=5 时，25−1=31，是素数；

n=7 时，27−1=127，是素数。

四个特例都是素数，是不是“当 n 为素数时，2n−1 都是素数”？也不是。n=11 时，211−1=2048−1=2047，而 2047=23×89，是合数。

那么，怎样才能减少归纳出错的可能？可以注意三点：

① 例子要足够多，而且要“分布得开”，不要只算开头几个；

② 专门试一试边界情形和特殊情形，例如最小的 n、使式子取到 0 或负数的 n；

③ 找到规律后，尽量说明理由。能用代数式推出来的，就不要只靠举例。

要点：归纳能帮我们发现结论，但不能替我们证明结论。数学上正确的顺序是：先归纳、提出猜想，再推演、说明理由。猜想被证明以后，才是可靠的结论；猜想被反例推翻，就要修改或放弃。

观察下列等式：

1=12；1+3=22；1+3+5=32；1+3+5+7=42。

（1）写出第 5 个等式；

（2）计算 1+3+5+…+99；

（3）用含 n 的式子表示第 n 个等式，并用 n=1，2，3 验证。

解

1+3+5+7+9=52。

（2）先确定 1+3+5+…+99 中一共有多少个奇数。这些奇数的第 n 个是 2n−1，令 2n−1=99，得 2n=100，n=50。所以一共有 50 个奇数，由归纳得到的规律，和为

502=2500。

（3）猜想：第 n 个等式为 1+3+5+…+(2n−1)=n2（n 为正整数）。

验证：n=1 时，左边=1，右边=12=1，成立；n=2 时，左边=1+3=4，右边=22=4，成立；n=3 时，左边=1+3+5=9，右边=32=9，成立。

理由：把点排成正方形（见图 51），第 n 层比第 n−1 层多出 2n−1 个点，而 (n−1)2+(2n−1)=n2−2n+1+2n−1=n2，所以每加一层就得到下一个平方数，结论对任意正整数 n 都成立。

变式：计算 1+3+5+…+201。答：令 2n−1=201，得 n=101，所以和为 1012=10201。

例 2 握手问题：从特例到公式，再由公式反求人数

（1）某班共 40 人，毕业时每两人握手一次，一共握手多少次？

（2）某小组的成员每两人握手一次，一共握手 66 次，这个小组有多少人？

解

（1）先回顾归纳的过程：2 人握手 1 次，3 人握手 3 次，4 人握手 6 次，5 人握手 10 次。因为每人都要与其他 n−1 人各握一次，n 个人共数出 n(n−1) 次，而每次握手被两人各数了一遍，所以总次数为 n(n−1)/2。

取 n=40：40×39/2=1560/2=780（次）。

（2）设这个小组有 n 人，由题意得 n(n−1)/2=66，即 n(n−1)=132。

因为 n 与 n−1 是相邻的两个正整数，而 12×11=132，所以 n=12。

验证：12×11/2=132/2=66，与题设相符。也可以反过来检查规律：11 人时握手 11×10/2=55 次，第 12 人再加入要新增 11 次，55+11=66，一致。

答：40 人共握手 780 次；握手 66 次的小组有 12 人。

变式：若改为互赠贺卡（甲送乙、乙送甲算两张），12 人共送出多少张？答：每人送出 11 张，共 12×11=132 张。注意互赠没有“重复计数”，所以是 n(n−1) 而不是 n(n−1)/2。

例 3 特例都成立，结论就一定成立吗

小明依次计算了 n2+n+41 在 n=1，2，3，4，5 时的值：43，47，53，61，71，发现它们都是素数。他又算了 n=10，得 151，是素数；算了 n=39，得 1601，还是素数。于是小明猜想：对任意正整数 n，n2+n+41 都是素数。

（1）小明的猜想正确吗？请说明理由。

（2）这个例子说明了归纳的什么局限？

解

（1）不正确。取 n=40，则

402+40+41=1600+40+41=1681，

而 1681=41×41，所以 1681 是合数，不是素数。

只这一个反例，就足以推翻“对任意正整数都成立”的猜想。

（还可以再取 n=41：412+41+41=1681+82=1763=41×43，也不是素数。）

（2）这个例子说明：不完全归纳得到的结论只是猜想。小明验证了 39 个特例都成立，仍然不能保证第 40 个成立。要想确认结论对任意正整数都成立，必须说明理由，而不能只靠举例。

反过来看，如果只想说明“猜想不成立”，那么找出一个反例就够了——这正是反例的价值：一个反例胜过一千个正例。

变式：判断“当 n 为素数时，2n−1 都是素数”是否正确。答：不正确。n=2，3，5，7 时，2n−1 分别为 3，7，31，127，都是素数；但 n=11 时，211−1=2048−1=2047=23×89，是合数。

练习

1 【基础】观察 1=12，1+3=22，1+3+5=32，…，填空：（1）1+3+5+7+9=______=______2；（2）1+3+5+…+19=______；（3）第 n 个等式右边的底数是______。
答案与解析

（1）左边有 5 个连续奇数，和为 1+3+5+7+9=25，而 25=52，所以填 25 和 5。

（2）令 2n−1=19，得 n=10，即共有 10 个奇数，和为 102=100。可以抽查：前 5 个奇数的和是 25，后 5 个（11，13，15，17，19）的和是 75，25+75=100，一致。

（3）第 n 个等式右边是 n2，底数是 n。用 n=1，2，3 检验：12=1，22=4，32=9，与左边 1、1+3、1+3+5 分别相等，正确。

2 【基础】（1）求八边形的内角和；（2）一个多边形的内角和是 1440°，求它的边数。
答案与解析

（1）n 边形的内角和为 (n−2)×180°。取 n=8，得 (8−2)×180°=6×180°=1080°。

（2）设边数为 n，则 (n−2)×180°=1440°，所以 n−2=1440°÷180°=8，n=10。

检验：十边形的内角和为 (10−2)×180°=8×180°=1440°，与题设相符，所以是十边形。

3 【提升】某学习小组的成员每两人握手一次，一共握手 45 次。这个小组有多少人？
答案与解析

设这个小组有 n 人。由握手问题的公式，总次数为 n(n−1)/2，于是

n(n−1)/2=45，即 n(n−1)=90。

因为 n 与 n−1 是相邻的两个正整数，而 10×9=90，所以 n=10。

验证：10×9/2=45，符合题意。也可以这样检查：9 人时握手 9×8/2=36 次，第 10 人再加入要新增 9 次，36+9=45，一致。

答：这个小组有 10 人。

4 【提升】观察 2 的正整数次幂的个位数字，求 2100 与 32025 的个位数字。
答案与解析

先归纳 2 的幂的个位数字：21=2，22=4，23=8，24=16（个位 6），25=32（个位 2），26=64（个位 4），27=128（个位 8），28=256（个位 6）。个位数字按 2，4，8，6 四个一循环，周期为 4。

100÷4=25，正好整除，没有余数，说明 2100 落在循环的最后一个，个位数字是 6。

再归纳 3 的幂的个位数字：31=3，32=9，33=27（个位 7），34=81（个位 1），35=243（个位 3）。个位数字按 3，9，7，1 四个一循环，周期也是 4。

2025÷4=506 余 1，说明 32025 落在循环的第 1 个，个位数字是 3。

答：2100 的个位数字是 6，32025 的个位数字是 3。

5 【拓展】（1）判断“当 n 为正整数时，n2+n+41 的值都是素数”是否正确，并说明理由；（2）再举一个“若干特例都成立、但一般结论不成立”的例子，写出算式。
答案与解析

（1）不正确。取 n=40，n2+n+41=1600+40+41=1681，而 1681=41×41，是合数，所以“都是素数”的说法被推翻。

需要说明的是：n=1，2，3，4，5 时分别得 43，47，53，61，71，确实都是素数；但特例成立不等于一般成立。

（2）参考答案示例：观察 2n−1。n=2 时得 3，n=3 时得 7，n=5 时得 31，n=7 时得 127，都是素数；但 n=11 时，211−1=2047=23×89，是合数。

（其他合理例子也可以，例如“n2−n+11 在 n=1，2，3，4，5 时为素数，n=11 时为 121=112”等，只要算式算对、反例成立即可。）

结论：归纳得到的猜想必须说明理由才能成为结论；一个反例就足以推翻一个猜想。

方法归纳：用归纳解决问题，可以按“四步”走：一看（列特例、排表格，找变化与不变）、二猜（用含 n 的式子写出一般结论，交代 n 的含义和范围）、三验（代入 n=1，2，3 等更多特例，专门试边界情形）、四说（用图形结构或代数变形说明理由）。要牢记两点：通项公式一定要用 n=1，2，3 代回去检验；特例再多也不能代替理由，能证明的要证明，不能证明的要写清“这只是猜想”。
本节知识网络：
  • 归纳的含义：从若干个具体事例中发现共同规律，提出猜想，再加以验证或说明理由；是由特殊到一般的思维方法。
  • 四个关键词：若干具体事例、共同规律、提出猜想、验证或说明理由，缺一不可。
  • 归纳的价值：帮助我们发现结论、提出猜想、找到解题思路；数学中的许多公式和法则最初都是这样被发现的。
  • 四个步骤：观察（列举特例、整理数据）→ 猜想（提出一般结论）→ 验证（代入更多特例、寻找反例）→ 表达（用含 n 的代数式表示并说明理由）。四步可循环，验证不通过就回到猜想。
  • 典型案例一：1+3+5+…+(2n−1)=n2；已知末项 2n−1 可先求项数 n，再求平方。
  • 典型案例二：握手、单循环比赛、两点连线段的条数都是 n(n−1)/2；互赠贺卡这类有方向的问题是 n(n−1)；对角线条数是 n(n−3)/2。
  • 典型案例三：n 边形内角和为 (n−2)×180°（n ≥ 3），理由是从一个顶点出发可分成 n−2 个三角形。
  • 典型案例四：末位数字的循环规律，如 2 的幂个位按 2，4，8，6 循环，周期为 4；用指数除以周期看余数。
  • 不完全归纳的局限：验证若干特例不等于证明。n2+n+41 在 n=1 到 39 时都是素数，但 n=40 时 402+40+41=1681=412，不是素数；2n−1 在 n=2，3，5，7 时是素数，n=11 时 2047=23×89 不是素数。
  • 反例的作用：一个反例就足以推翻一个猜想；而再多的正例也不能证明猜想。要确认结论，必须说明理由。
  • 与“探索与表达规律”的关系：归纳是策略（方法），规律是结果；探索规律的过程就是归纳的过程，最终要用含 n 的代数式表达并验证。
  • 书写提醒：通项公式要写清 n 表示什么、取值范围；检验时把 n=1，2，3 逐个代回，两边分别算，写清“左边=…，右边=…”。

一、本章知识结构

本章内容可以概括为“一条起点、两个转化、三类式子、一个策略”。起点是用字母表示数——这是算术走向代数的第一步；两个转化是“文字语言转化为符号语言”（列代数式）和“式子转化为最简形式”（整式的加减）；三类式子是单项式、多项式、整式；一个策略是归纳，即从特殊到一般地发现并表达规律。下图把这条线索画成了一张结构图。

看图时请抓住三条“竖线”。第一条是概念线：用字母表示数是起点，代数式是“用运算符号把数、字母连起来的式子”，其中由数与字母的积组成的叫单项式，几个单项式的和叫多项式，二者统称整式。第二条是运算线：整式的加减只有两个动作——去括号和合并同类项；去括号解决“括号挡路”的问题，合并同类项解决“项太多”的问题。第三条是规律线：从具体的数、图形出发，观察变化，猜想第 n 个情形，用含 n 的代数式表达，再代回具体数值检验。

很多同学把“代数式”“整式”“单项式”当成三个并列的名词来背，其实它们是层层包含的关系。下表先把这几个概念摆在一起，说清“谁包含谁”。

五、思想方法

1. 符号化：把一句话变成一个式子

用字母表示数，是本章最重要的观念转变。它带来三个好处：一是简洁，“一个长方形的长比宽多 3 cm”写成 a + 3，比一大段文字清楚得多；二是一般，a + b = b + a 表示的不只是 2 + 3 = 3 + 2，而是所有数都成立；三是可算，式子可以像数一样运算，运算的结果又反过来告诉我们新的结论。列代数式的训练，本质上就是“翻译”训练：先找关键词（和、差、积、商、倍、几分之几、多、少），再定运算顺序，最后检查要不要加括号。

2. 从特殊到一般：归纳的力量

探索规律的标准路径是“观察—猜想—验证—表达”。先列举 n = 1，2，3 时的具体结果，观察每次增加多少；再猜想第 n 个情形；然后把 n = 4，5 代入猜想检验；最后用含 n 的代数式写出来，并说明理由。例如摆正方形：1 个用 4 根，2 个用 7 根，3 个用 10 根，每次多 3 根，于是第 n 个用 3n + 1 根。代 n = 1 得 4，代 n = 2 得 7，都对。归纳得到的结论必须验证，因为“前几项都对”并不等于“永远都对”。

3. 整体思想：把一坨看成一个字母

有些式子看起来很复杂，但如果把某一部分“打包”成一个字母，就会立刻变简单。例如 3(x + y) − 2(x + y) + 5(x + y)，把 (x + y) 看成 A，原式就是 3A − 2A + 5A = 6A，即 6(x + y)。整体代入更是求值题的“捷径”：已知 a + b = 5，求 3(a + b) − 2a − 2b + 4 时，不必求出 a、b 各是多少，只要把 −2a − 2b 写成 −2(a + b)，整体代入即可。

4. 数形结合：让式子“看得见”

代数式也能画出来。长方形的面积可以解释乘法分配律：一个宽为 3、长分成 x 和 2 两段的长方形，整体面积是 3(x + 2)，分成两块后是 3x 与 6，所以 3(x + 2) = 3x + 6。同理，边长为 (a + b) 的正方形可以分成四块，得到 (a + b)2 = a2 + 2ab + b2。图形帮我们“看见”式子的结构，式子帮我们“算准”图形的数量，这就是数形结合。

六、易错清单

下面 13 条是本章作业与测验中出现频率最高的错误。建议逐条读，读到哪一条心里“咯噔”一下，就把它抄进错题本，并补一道自己的错题。

易错清单：
  1. 系数漏掉符号。−3x2y 的系数是 −3，不是 3；−m 的系数是 −1，不是 1，也不是没有系数。
  2. 次数算错。x2y 的次数是 2 + 1 = 3，不是 2；多项式的次数取最高次项的次数，不是各项次数之和。
  3. 把 π 当成字母。πr2 的系数是 π，次数是 2；π 是常数，不参与“字母指数之和”的计算。
  4. 同类项判断错。2x2y 与 2xy2 字母相同但指数不同，不是同类项；同类项与系数大小、字母顺序都无关。
  5. 合并同类项漏系数。5a2 − 2a2 = 3a2，不能写成 3a4；合并时字母和指数都不变。
  6. 去括号只变第一项。−(a − b + c) = −a + b − c，三项都要变号，不能写成 −a − b + c。
  7. 两个多项式相减不加括号。求 (x2 + 1) 与 (2x − 3) 的差，要写成 (x2 + 1) − (2x − 3)，漏掉括号就会把 −3 变成 +3 或把 −2x 算成 +2x。
  8. 代入负数不加括号。当 x = −2 时，x2 应写成 (−2)2 = 4，直接写 −22 就成了 −4。
  9. 通项公式不验证。猜出 3n + 1 后，必须代 n = 1，2，3 检验；只凭“看着像”就下结论，很容易差一个常数。
  10. 把代数式写成等式。“a 与 b 的和的 2 倍”应写成 2(a + b)，不能写成 2(a + b) = 2a + 2b——后者是等式，不是代数式。
  11. 书写不规范。a × 3 应写作 3a（数字在前）；1 × a 写作 a；a ÷ b 写作 a/b；带分数要化成假分数。
  12. 合并同类项时“跨项”。3a2 与 3a 不是同类项，不能合并成 6a2 或 6a；指数不同就是不同的项。
  13. 化简求值先代后算。题目说“先化简，再求值”，就要先化到最简再代入；直接代入既慢又容易出错，还得不到“化简”这一步的分。

七、回顾与思考

下面 4 个问题没有标准答案，重要的是“说清楚”。先自己说一遍，再对照参考答案，看看漏了哪一层。

思考 1 用字母表示数有什么好处？请各举一个例子说明。
答案与解析

参考答案：好处主要有三条。①简洁：把“一个长方形的长比宽多 3 cm，求它的周长”写成 2(a + a + 3) = 4a + 6，一句话就变成了一个式子。②一般：加法交换律写成 a + b = b + a，表示的不只是 2 + 3 = 3 + 2，而是所有数都成立，这是用具体的数做不到的。③可算：式子能像数一样运算，运算的结果又能推出新结论。例如由 (a + b)2 = a2 + 2ab + b2，取 a = 1，b = 1 就得到 4 = 4，取别的数也成立。

再补一句：字母还可以表示“变化的量”。例如第 n 个图形用 3n + 1 根火柴棒，n 取不同的值，就得到不同图形的结果，一个式子概括了无穷多种情况。

思考 2 单项式、多项式、整式之间是什么关系？请用图或表说明，并各举一例。
答案与解析

参考答案：整式包含单项式和多项式，单项式与多项式没有公共部分。可以画成“一个大圈里套两个小圈”：大圈写“整式”，左边小圈写“单项式”，右边小圈写“多项式”，两个小圈不重叠。

举例：单项式有 −3x2y、πr2、5；多项式有 x2 − 2x + 1、2a + 3b；它们都是整式。而 2/x、1/x + 1 分母上有字母，既不是单项式，也不是多项式，所以不是整式。

判断顺序建议这样走：先看分母有没有字母（有→不是整式）；没有再看是不是“几个单项式的和”（是→多项式）；不是就是单项式。注意单独一个数或一个字母也属于单项式。

思考 3 去括号时，括号前是“−”为什么要“各项都变号”？请说明理由。
答案与解析

参考答案：去括号的依据是乘法分配律。−(a − b + c) 相当于 (−1) × (a − b + c)，用 −1 去乘括号里的每一项，得 −a + b − c。所以不是“只把第一项变号”，而是每一项都要变号。

也可以用具体的数验证：取 a = 5，b = 2，c = 1，则 −(5 − 2 + 1) = −4；而 −5 + 2 − 1 = −4，两者相等。若只变第一项写成 −5 − 2 + 1 = −6，就不相等了。

还可以用相反数的意义理解：括号里整体的相反数，就是每一项都取相反数再相加。

思考 4 探索规律的一般过程是什么？为什么归纳得到的结论还要验证？
答案与解析

参考答案：一般过程是“观察—猜想—验证—表达”。先列举几个具体情形（n = 1，2，3），观察数量怎样变化、每次增加多少；再猜想第 n 个情形的一般结论；然后把 n = 4，5 等代入猜想检验；最后用含 n 的代数式把结论写出来，并说明理由。

必须验证的原因：归纳是从“若干特例”推出“一般结论”，属于不完全归纳，前几项都对并不能保证后面也对。例如 n2 − n + 11，当 n = 1，2，…，10 时结果都是质数，但 n = 11 时结果是 121 = 112，不是质数，说明“前十项都对”不足以支撑“永远都对”。

更可靠的做法是用代数式说明理由，比如 n(n + 2) + 1 = n2 + 2n + 1 = (n + 1)2，这样对任意 n 都成立，才算真正证明了规律。

本节知识网络：
  • 一个起点：用字母表示数（表示数、数量关系、运算律、公式）。
  • 两个转化：文字语言 → 符号语言（列代数式）；复杂式子 → 最简形式（整式的加减）。
  • 三类式子：单项式（系数、次数）、多项式（项、常数项、次数）、整式（二者统称）。
  • 两条法则：同类项“字母同、指数同”；去括号“括号前是 −，各项都变号”。
  • 一个策略：归纳（观察—猜想—验证—表达），通项公式要用 n = 1，2，3 检验。
  • 四种思想：符号化、从特殊到一般、整体思想、数形结合。
  • 一条习惯：先看符号，再找同类项，最后查括号。

复习题全章检测与自我评价

提示：做整式题时，建议在草稿上按“去括号—找同类项—合并—检查符号”四步走，每一步只做一件事。化简求值题一定要先化到最简再代入，这样既快又能拿全步骤分。

一、知识技能（第 1—6 题）

1 【知识技能】用代数式表示：（1）a 的 3 倍与 b 的差；（2）长是 a、宽是 b 的长方形的周长；（3）某商品原价 x 元，打八折后的售价；（4）甲、乙两地相距 s km，汽车以 v km/h 的速度行驶，从甲地到乙地所需的时间；（5）十位数字是 a、个位数字是 b 的两位数；（6）一个数 x 的相反数的 2 倍；（7）棱长为 a 的正方体的表面积。
答案与解析

（1）3a − b。注意“a 的 3 倍”是 3a，“与 b 的差”是减去 b，顺序不能颠倒。

（2）2(a + b)。周长 = 2 ×（长 + 宽），括号不能漏，否则就成了 2a + b。

（3）0.8x（元）。打八折就是按原价的 80% 出售；也可以写成 (4/5)x。

（4）s/v（h）。由“路程 = 速度 × 时间”得“时间 = 路程 ÷ 速度”，除法要写成分数形式。

（5）10a + b。十位上的 a 表示 a 个十，所以是 10a，不是 a + b。

（6）−2x。x 的相反数是 −x，再乘 2 得 −2x。

（7）6a2。正方体有 6 个面，每个面都是边长为 a 的正方形，面积是 a2。

2 【知识技能】当 a = −2，b = 3 时，求下列代数式的值：（1）a2 − 2ab + b2；（2）(a − b)2；（3）a2 + 2ab + b2；（4）(a + b)2。比较（1）（2）与（3）（4）的结果，你能发现什么？
答案与解析

（1）a2 − 2ab + b2 = (−2)2 − 2 × (−2) × 3 + 32 = 4 + 12 + 9 = 25。

（2）(a − b)2 = (−2 − 3)2 = (−5)2 = 25。

（3）a2 + 2ab + b2 = 4 + 2 × (−2) × 3 + 9 = 4 − 12 + 9 = 1。

（4）(a + b)2 = (−2 + 3)2 = 12 = 1。

发现：（1）与（2）的结果相等，（3）与（4）的结果也相等，即 a2 − 2ab + b2 = (a − b)2，a2 + 2ab + b2 = (a + b)2。这两条式子在以后的学习中还会经常用到。

提醒：代入负数一定要加括号，(2) 中先算括号里的 −2 − 3 = −5，再平方。

3 【知识技能】指出下列单项式的系数和次数：（1）−5x2y；（2）2ab2/3；（3）−m；（4）x/2；（5）πr2。
答案与解析

（1）−5x2y：系数是 −5（符号不能丢），次数是 2 + 1 = 3。

（2）2ab2/3：系数是 2/3，次数是 1 + 2 = 3。

（3）−m：系数是 −1，次数是 1。系数为 −1 时“1”省略不写，但不能说它没有系数。

（4）x/2：系数是 1/2，次数是 1。

（5）πr2：系数是 π（π 是常数，不是字母），次数是 2。

方法：先看“数字因数”（连同符号）作为系数，再把所有字母的指数相加作为次数。字母指数为 1 时通常不写，但计算次数时要算 1。

4 【知识技能】对于多项式 x3 − 2x2y + 3xy2 − y3：（1）写出它的各项；（2）求各项的次数与多项式的次数；（3）它是几次几项式？（4）写出它的常数项。
答案与解析

（1）各项是 x3、−2x2y、3xy2、−y3。项要连同它前面的符号一起写。

（2）各项的次数分别是 3、2 + 1 = 3、1 + 2 = 3、3，所以多项式的次数是 3。

（3）它是三次四项式。

（4）它没有不含字母的项，所以常数项是 0。

提醒：多项式的次数取“最高次项的次数”，不是把各项次数相加。本题四项都是三次，所以是三次四项式，不能说成“十二次”。

5 【知识技能】合并同类项：（1）5a2 − 3a − 2a2 + 4a − 1；（2）3(x + y) − 2(x + y) + 5(x + y)；（3）−2x2y + 3xy2 − 4x2y + xy2；（4）3m2n − 2mn2 + 5m2n + 4mn2。
答案与解析

（1）原式 = (5 − 2)a2 + (−3 + 4)a − 1 = 3a2 + a − 1。

（2）把 (x + y) 看成一个整体，原式 = (3 − 2 + 5)(x + y) = 6(x + y)。也可以写成 6x + 6y，但保留整体形式更能体现思路。

（3）原式 = (−2 − 4)x2y + (3 + 1)xy2 = −6x2y + 4xy2。注意 x2y 与 xy2 不是同类项，不能合并成一项。

（4）原式 = (3 + 5)m2n + (−2 + 4)mn2 = 8m2n + 2mn2。

方法：合并同类项只把系数相加，字母和字母的指数原样照抄。可以先用不同的记号把同类项标出来，再逐组相加。

6 【知识技能】先去括号，再合并同类项：（1）3(a − 2b) − (2a + b)；（2）2x2 − [3x − (x2 + 2x)]；（3）−(2a − b) + 3(a + b)；（4）5(2x − 3) − 2(3x − 1)。
答案与解析

（1）原式 = 3a − 6b − 2a − b = (3 − 2)a + (−6 − 1)b = a − 7b。注意 −(2a + b) 的两项都要变号。

（2）先去小括号：3x − (x2 + 2x) = 3x − x2 − 2x = x − x2；再去中括号：2x2 − (x − x2) = 2x2 − x + x2 = 3x2 − x。

（3）原式 = −2a + b + 3a + 3b = a + 4b。

（4）原式 = 10x − 15 − 6x + 2 = 4x − 13。注意 −2 × (−1) = +2，不要写成 −2。

方法：多重括号由内向外去，每去一层就把“变号”这件事做完再往下走，避免一次去两层而漏变号。

二、数学理解（第 7—12 题）

7 【数学理解】判断下列说法是否正确，并说明理由。（1）3x2 的系数是 3，次数是 2；（2）π/2 是单项式，它的系数是 1/2；（3）2/x 是单项式；（4）3a2b 与 −ba2 是同类项；（5）−(a − b) = −a − b；（6）x + 1/x 是整式。
答案与解析

（1）正确。3x2 的数字因数是 3，字母 x 的指数是 2，所以系数 3、次数 2。

（2）错误。π/2 是单项式，但 π 是常数，所以它的系数是 π/2，不是 1/2。判断系数要把所有“非字母”的因数都算进去。

（3）错误。2/x 的分母中含有字母 x，它表示 2 与 x 的商，不符合“数与字母的积”这一特征，所以不是单项式，也不是整式。

（4）正确。两项都含有字母 a、b，且 a 的指数都是 2、b 的指数都是 1，符合同类项的定义。字母的书写顺序不影响判断。

（5）错误。括号前是“−”，去括号后各项都要变号：−(a − b) = −a + b。可以用 a = 5，b = 2 检验：左边 = −3，而 −5 − 2 = −7，不相等。

（6）错误。1/x 的分母含字母，不是单项式，所以 x + 1/x 不是整式。

8 【数学理解】已知 |a + 2| + (b − 3)2 = 0，求代数式 2a2 − 3ab + b2 的值。
答案与解析

因为 |a + 2| ≥ 0，(b − 3)2 ≥ 0，而它们的和为 0，所以每个非负数都必须等于 0，即 a + 2 = 0，b − 3 = 0，解得 a = −2，b = 3。

代入：2a2 − 3ab + b2 = 2 × (−2)2 − 3 × (−2) × 3 + 32 = 8 + 18 + 9 = 35。

答：代数式的值为 35。

方法：“几个非负数的和为 0，则每个非负数都为 0”是常用结论。代入时注意 −3ab 中 a、b 都是负数，积为正，所以这一项是 +18。

9 【数学理解】用整体代入的方法求值：（1）已知 a + b = 5，求 3(a + b) − 2a − 2b + 4 的值；（2）已知 x2 + x = 3，求 2x2 + 2x − 5 的值；（3）已知 m − n = 2，求 5(m − n) − 3n + 3m 的值。
答案与解析

（1）先变形：−2a − 2b = −2(a + b)，所以原式 = 3(a + b) − 2(a + b) + 4 = (a + b) + 4 = 5 + 4 = 9。

（2）原式 = 2(x2 + x) − 5 = 2 × 3 − 5 = 1。

（3）先变形：−3n + 3m = 3(m − n)，所以原式 = 5(m − n) + 3(m − n) = 8(m − n) = 8 × 2 = 16。

方法：整体思想的关键是“凑”——把待求式凑成已知式子的倍数或和差。凑的时候要注意符号，例如 −2a − 2b 提出 −2 后括号里是 (a + b)，不是 (−a − b)。

10 【数学理解】先化简，再求值：（1）(3x2 − 2x + 1) − 2(x2 − x + 3)，其中 x = −3；（2）2(a2b + ab2) − 2(a2b − 1) + ab2，其中 a = −1，b = 2。
答案与解析

（1）化简：原式 = 3x2 − 2x + 1 − 2x2 + 2x − 6 = (3 − 2)x2 + (−2 + 2)x + (1 − 6) = x2 − 5。

求值：当 x = −3 时，原式 = (−3)2 − 5 = 9 − 5 = 4。

（2）化简：原式 = 2a2b + 2ab2 − 2a2b + 2 + ab2 = (2 − 2)a2b + (2 + 1)ab2 + 2 = 3ab2 + 2。

求值：当 a = −1，b = 2 时，原式 = 3 × (−1) × 22 + 2 = −12 + 2 = −10。

答：（1）的值为 4；（2）的值为 −10。

提醒：化简时 −2(a2b − 1) 的两项都要乘 −2，得 −2a2b + 2，常数项是 +2 而不是 −2。

11 【数学理解】（1）若单项式 2xmy3 与 −5x2yn 是同类项，求 m + n 的值；（2）若多项式 (m − 2)x3 + x2 − 3x + 1 是关于 x 的二次多项式，求 m 的值；（3）若 3x2y|n| 与 −2x2y3 是同类项，求 n 的值。
答案与解析

（1）同类项要求相同字母的指数相同，所以 m = 2，n = 3，于是 m + n = 5。

（2）因为多项式是二次的，所以三次项必须“消失”，即它的系数为 0：m − 2 = 0，解得 m = 2。此时多项式为 x2 − 3x + 1，确实是二次三项式。

（3）由同类项的定义得 |n| = 3，所以 n = 3 或 n = −3。两个值都能使指数为 3，都符合题意。

答：（1）5；（2）m = 2；（3）n = ±3。

方法：第（2）题考的是“系数为 0 使某项消失”，这是含参多项式问题的常用手段；第（3）题含绝对值，要分类讨论，不要漏解。

12 【数学理解】当 x = −1/2，y = 2 时，求代数式 4x2 − 3xy + y2 的值。若把 x = −1/2 直接写成 −1/22 代入，会得到什么错误结果？这说明了什么？
答案与解析

正确代入：4x2 = 4 × (−1/2)2 = 4 × 1/4 = 1；−3xy = −3 × (−1/2) × 2 = 3；y2 = 22 = 4。

所以原式 = 1 + 3 + 4 = 8。

如果写成 −1/22，按运算顺序会先算 22 = 4，得到 −1/4，再乘 4 得 −1，整个结果就变成了 −1 + 3 + 4 = 6，与正确答案 8 相差 2。

这说明：代入分数或负数时一定要加括号，写成 (−1/2)2、(−2)2 这样的形式。括号保证“先取这个数，再乘方”，否则乘方只作用于分母或只作用于数字部分。

答：代数式的值为 8。

三、问题解决（第 13—17 题）

13 【问题解决】用火柴棒按图 62 的方式摆正方形：（1）摆 1 个、2 个、3 个正方形各需要多少根火柴棒？（2）摆 n 个正方形需要多少根？（3）摆 100 个需要多少根？（4）用 2026 根火柴棒最多能摆多少个这样的正方形？
答案与解析

（1）摆 1 个需要 4 根，摆 2 个需要 7 根，摆 3 个需要 10 根。

（2）从第 1 个开始，每多摆 1 个正方形，就多用 3 根火柴棒（新增一个正方形只补 3 条边，左边那条边与已有图形共用）。所以摆 n 个需要 4 + 3(n − 1) = 3n + 1 根。

验证：n = 1 时 3 × 1 + 1 = 4；n = 2 时 3 × 2 + 1 = 7；n = 3 时 3 × 3 + 1 = 10，与（1）的结果一致。

（3）当 n = 100 时，3 × 100 + 1 = 301（根）。

（4）设能摆 n 个，则 3n + 1 ≤ 2026，即 3n ≤ 2025，n ≤ 675。所以最多能摆 675 个，此时用去 3 × 675 + 1 = 2026 根，恰好用完。

答：摆 n 个需要 3n + 1 根；摆 100 个需要 301 根；2026 根最多能摆 675 个。

方法：图形规律题要先想“每增加一个，增加几条边”，再写出“首项 + 增量 ×（n − 1）”，最后整理成 3n + 1 的形式并验证。

14 【问题解决】在某月的日历中，用一个方框框住 3 行 3 列共 9 个数，设正中间的那个数为 a。（1）用含 a 的代数式表示其余 8 个数；（2）求这 9 个数的和；（3）若这 9 个数的和是 135，求中间的数和最小的数；（4）这 9 个数的和可能是 100 吗？为什么？
答案与解析

（1）日历中同一列相邻两数相差 7，同一行相邻两数相差 1。以 a 为中心，其余 8 个数分别是：上一行 a − 8，a − 7，a − 6；同一行 a − 1，a + 1；下一行 a + 6，a + 7，a + 8。

（2）把这 9 个数相加：9a + [(−8) + (−7) + (−6) + (−1) + 0 + 1 + 6 + 7 + 8] = 9a + 0 = 9a。因为 9 个数关于 a “成对抵消”，所以和是中间数的 9 倍。

（3）由 9a = 135 得 a = 15，所以中间的数是 15。最小的数是 a − 8 = 7。

（4）不可能。因为 9a = 100 时 a = 100/9，不是整数，而日历上的数都是正整数，所以这 9 个数的和不可能是 100。这也说明：用代数式表示规律后，可以反过来判断某些情况“能不能发生”。

答：9 个数的和是 9a；和为 135 时中间的数是 15，最小的数是 7；和不可能为 100。

15 【问题解决】某书每本原价 a 元。甲书店一律打八折；乙书店“买 5 本送 1 本”。学校要买 30 本这种书。（1）分别用含 a 的代数式表示在两家书店各需付多少钱；（2）到哪家买更合算？便宜多少元？（3）若 a = 25，分别算出两家的费用。
答案与解析

（1）甲书店：30 本打八折，需付 30 × 0.8a = 24a（元）。

乙书店：每买 5 本送 1 本，即每 6 本只需付 5 本的钱。30 ÷ 6 = 5，正好是 5 组，所以要付 5 × 5 = 25（本）的钱，需付 25a（元）。

（2）因为 24a < 25a（a > 0），所以到甲书店买更合算，便宜 25a − 24a = a（元）。

（3）当 a = 25 时，甲书店需付 24 × 25 = 600（元），乙书店需付 25 × 25 = 625（元），甲比乙便宜 25 元。

答：甲书店需付 24a 元，乙书店需付 25a 元；到甲书店更合算，便宜 a 元；a = 25 时两家分别需付 600 元、625 元。

提醒：乙书店的“买 5 送 1”要理解成“每 6 本只付 5 本的钱”。30 本正好分成 30 ÷ 6 = 5 组，每组付 5 本的钱，所以一共付 5 × 5 = 25 本的钱，即 25a 元。不要错算成“付 30 本、再送 6 本”，也不要把赠送的书重复计入付费本数。两店相比，甲店 24a 元、乙店 25a 元，甲店少花 a 元。

16 【问题解决】一个长方形的长是 a cm，宽是 b cm。（1）用代数式表示它的周长和面积；（2）若长增加 2 cm，宽减少 1 cm，用代数式表示新长方形的周长，并说明周长比原来增加了多少；（3）当 a = 10，b = 6 时，面积是否发生变化？请计算说明。
答案与解析

（1）周长 = 2(a + b)（cm），面积 = ab（cm2）。

（2）新长是 a + 2，新宽是 b − 1，新周长 = 2[(a + 2) + (b − 1)] = 2(a + b + 1) = 2(a + b) + 2。所以新周长比原来增加了 2 cm。

（3）原面积 = 10 × 6 = 60（cm2）；新长 = 12，新宽 = 5，新面积 = 12 × 5 = 60（cm2）。面积没有变化。

答：周长是 2(a + b) cm，面积是 ab cm2；新周长比原来增加 2 cm；当 a = 10，b = 6 时面积不变，都是 60 cm2。

说明：周长增加 2 cm 与 a、b 的具体取值无关，这是“用字母表示”带来的一般性；而面积是否变化要看具体数值，本题恰好不变，换一组数（如 a = 8，b = 5，原面积 40，新面积 10 × 4 = 40 也不变；但 a = 6，b = 6 时原 36，新 8 × 5 = 40，变了）就不一定了。

17 【问题解决】某市出租车的计费规则是：起步价 10 元（含 3 km），超过 3 km 的部分每千米收费 2.4 元。（1）用代数式表示行驶 x km（x > 3）应付的车费；（2）行驶 10 km 应付多少元？（3）若付了 34 元，行驶了多少千米？
答案与解析

（1）超过 3 km 的部分是 (x − 3) km，这部分收费 2.4(x − 3) 元，再加上起步价，得车费 = 10 + 2.4(x − 3) = 10 + 2.4x − 7.2 = 2.4x + 2.8（元）。

（2）当 x = 10 时，车费 = 2.4 × 10 + 2.8 = 24 + 2.8 = 26.8（元）。也可直接算：10 + 2.4 × (10 − 3) = 10 + 16.8 = 26.8（元）。

（3）由 2.4x + 2.8 = 34，得 2.4x = 31.2，x = 13。检验：10 + 2.4 × (13 − 3) = 10 + 24 = 34（元），符合题意。

答：车费为 (2.4x + 2.8) 元；行驶 10 km 应付 26.8 元；付 34 元时行驶了 13 km。

提醒：去括号时 2.4 × (−3) = −7.2，符号容易错；本题只适用于 x > 3 的情形，若 x ≤ 3，车费就是起步价 10 元。

四、联系拓广（第 18—21 题）

18 【联系拓广】（1）计算并观察：1 = 12，1 + 3 = 22，1 + 3 + 5 = 32，猜想 1 + 3 + 5 + … + (2n − 1) 等于多少；（2）用 n = 1，2，3，4 验证你的猜想；（3）计算 1 + 3 + 5 + … + 99；（4）计算 1 + 3 + 5 + … + (2n + 1)。
答案与解析

（1）观察：从 1 开始连续 n 个奇数的和，等于 n2。即 1 + 3 + 5 + … + (2n − 1) = n2。

（2）验证：n = 1 时左边 = 1，右边 = 12 = 1；n = 2 时左边 = 1 + 3 = 4，右边 = 22 = 4；n = 3 时左边 = 1 + 3 + 5 = 9，右边 = 32 = 9；n = 4 时左边 = 1 + 3 + 5 + 7 = 16，右边 = 42 = 16。四次验证都成立。

（3）因为 2n − 1 = 99，所以 n = 50，原式 = 502 = 2500。

（4）1 + 3 + 5 + … + (2n + 1) 比 1 + 3 + … + (2n − 1) 多了一项 (2n + 1)，共 (n + 1) 项，所以和是 (n + 1)2。验证：n = 1 时 1 + 3 = 4 = 22；n = 2 时 1 + 3 + 5 = 9 = 32，符合。

答：（1）n2；（3）2500；（4）(n + 1)2。

说明：这个规律还可以用图形理解——把 n2 个点排成 n 行 n 列的正方形，从外向内一层层剥开，每一层恰好是 1，3，5，… 个点。

19 【联系拓广】观察下列算式：1 × 3 + 1 = 4 = 22；2 × 4 + 1 = 9 = 32；3 × 5 + 1 = 16 = 42。（1）用含 n 的等式表示你发现的规律；（2）用代数式运算说明这个等式为什么成立；（3）计算 2025 × 2027 + 1。
答案与解析

（1）规律：n(n + 2) + 1 = (n + 1)2。验证：n = 1 时 1 × 3 + 1 = 4 = 22；n = 2 时 2 × 4 + 1 = 9 = 32；n = 3 时 3 × 5 + 1 = 16 = 42，都与题中一致。

（2）左边 = n(n + 2) + 1 = n2 + 2n + 1；而 (n + 1)2 = (n + 1)(n + 1) = n2 + 2n + 1。两边都等于 n2 + 2n + 1，所以等式对任意 n 都成立。

（3）取 n = 2025，则 2025 × 2027 + 1 = (2025 + 1)2 = 20262。计算：20262 = 2026 × 2026 = 4 104 676。

答：规律是 n(n + 2) + 1 = (n + 1)2；2025 × 2027 + 1 = 4 104 676。

方法：这是“用代数式证明规律”的典型例子。只靠几个特例只能“猜想”，把式子展开、比较两边，才能说明它对任意 n 都成立。

20 【联系拓广】已知 a、b 满足 |a − 2| + (b + 1)2 = 0。（1）求 a、b 的值；（2）先化简，再求值：2(a2b − ab2) − 3(a2b − 2ab2)；（3）若把（2）中的式子改为 2(a2b − ab2) − 3(a2b + 2ab2)，结果又是多少？
答案与解析

（1）因为 |a − 2| ≥ 0，(b + 1)2 ≥ 0，且它们的和为 0，所以 a − 2 = 0，b + 1 = 0，得 a = 2，b = −1。

（2）化简：原式 = 2a2b − 2ab2 − 3a2b + 6ab2 = (2 − 3)a2b + (−2 + 6)ab2 = −a2b + 4ab2。

求值：当 a = 2，b = −1 时，−a2b = −4 × (−1) = 4，4ab2 = 4 × 2 × 1 = 8，所以原式 = 4 + 8 = 12。

（3）改后化简：2a2b − 2ab2 − 3a2b − 6ab2 = −a2b − 8ab2。代入得 −(−4) − 8 × 2 × 1 = 4 − 16 = −12。

答：（1）a = 2，b = −1；（2）12；（3）−12。

提醒：第（3）问只改了括号里的一个符号，结果就从 12 变成 −12。这说明去括号时“括号前是 −，各项都变号”有多重要。

21 【联系拓广】（1）计算 31，32，33，34，35，36，观察末位数字有什么规律；（2）求 32026 的末位数字；（3）有人说“n2 − n + 11 当 n 取正整数时都是质数”，请判断这个说法是否正确，并说明理由。
答案与解析

（1）31 = 3，32 = 9，33 = 27，34 = 81，35 = 243，36 = 729。末位数字依次是 3，9，7，1，3，9，可见每 4 个一循环，循环节是 3，9，7，1。

（2）因为指数每增加 4，末位数字重复一次，所以用 2026 ÷ 4 = 506 余 2。余数是 2，说明末位数字是循环节中的第 2 个，即 9。所以 32026 的末位数字是 9。

（3）这个说法不正确。当 n = 1，2，3，…，10 时，n2 − n + 11 的值依次是 11，13，17，23，31，41，53，67，83，101，确实都是质数；但当 n = 11 时，n2 − n + 11 = 121 − 11 + 11 = 121 = 112，不是质数。所以只要举出这一个反例，就能否定“都是质数”的说法。

答：末位数字按 3，9，7，1 循环；32026 的末位数字是 9；该说法错误，n = 11 时结果是 121，不是质数。

说明：本题两问正好对应归纳的两面——第（1）（2）问说明归纳能帮我们发现规律并作出预测；第（3）问说明不完全归纳的结论可能被一个反例推翻，所以归纳之后必须验证或证明。
