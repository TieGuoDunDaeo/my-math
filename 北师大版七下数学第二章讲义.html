两条直线的位置关系

十字路口的两条车道线、教室窗框的横档与竖档、剪刀张开的两片刀刃，把这些画面画在纸上，就得到两条直线：它们有时交叉在一起，有时并肩延伸、永不相交。这一节我们从“相交”出发，先认识对顶角、邻补角、余角和补角，弄清它们之间到底有怎样的数量关系；再研究相交中最特殊的情形——垂直，学会用三角板画垂线，弄懂“垂线段最短”和“点到直线的距离”究竟指什么。

学习目标

  • 理解同一平面内两条直线的两种位置关系——相交与平行，知道什么叫交点，会画出相交线与平行线。
  • 掌握邻补角、对顶角的概念，能由图判断两个角是不是对顶角或邻补角，理解并会说明“对顶角相等”。
  • 理解余角、补角的概念，掌握“同角或等角的余角相等”“同角或等角的补角相等”，会求一个角的余角与补角。
  • 理解垂直、垂足的含义，会用三角板过一点画已知直线的垂线，知道“在同一平面内，过一点有且只有一条直线与已知直线垂直”。
  • 理解“垂线段最短”，知道点到直线的距离是垂线段的长度，能解决简单的测量与计算问题。

第 1 课时对顶角、余角和补角

一、十字路口上的“相交”

清晨的十字路口，两条马路在这里交叉；教室的窗框，横档与竖档互相穿过；妈妈裁剪衣服时，剪刀的两片刀刃绕着一个螺丝张开、合拢。这些现象看起来毫不相干，但如果我们把颜色、材料、用途统统丢掉，只留下“形状和位置”，就会发现它们说的是同一件事：两条直线相交于一点。

为什么可以把马路看成直线？因为在这一小段范围内，马路是笔直的，而且它可以向两端一直延伸下去。数学里的直线有两个特点：一是“直”，二是“向两方无限延伸”，没有端点。正因为直线可以无限延伸，两条直线只要方向不同，就一定会有一个公共点，这个公共点叫做它们的交点。反过来，如果两条直线有两个公共点，那么它们就完全重合在一起了，只能算作一条直线。

于是，在同一平面内，两条直线（不重合）的位置关系只有两种：

  • 相交：两条直线有且只有一个公共点，这个公共点叫做交点。
  • 平行：两条直线没有公共点，无论怎样延长都不会相交。

这里有一个很容易被忽略的前提——“在同一平面内”。黑板的上边框和教室地面上的某条线，它们既不相交，也不平行，因为它们不在同一个平面内。这样的两条直线要到高中才会专门研究，初中阶段我们研究的都是同一平面内的两条直线，所以“在同一平面内”这五个字不能丢。

要点：在同一平面内，两条不重合的直线只有相交与平行两种位置关系。判断的标准是“公共点的个数”：一个公共点——相交；没有公共点——平行。说“两条直线一定相交”是错的，说“两条直线一定平行”也是错的，必须先看它们在同一平面内是否相交。

两条直线相交，会把平面分成四个角。如图 1，直线 AB 与直线 CD 相交于点 O，图中共有四个小于平角的角，我们分别记作 ∠1、∠2、∠3、∠4，其中 ∠1 = ∠AOD，∠2 = ∠DOB，∠3 = ∠BOC，∠4 = ∠COA。请注意，∠AOD 也可以写成 ∠DOA，但顶点字母 O 必须写在中间。

数一数就会发现：图 1 中一共有 4 个角，它们两两相邻，组成了一整圈 360°。这 4 个角之间有什么特殊关系？这正是本课时要研究的核心问题。看图时请养成一个习惯：先找顶点，再找边。四个角的顶点都是 O，边都在直线 AB 和直线 CD 上，所以它们之间的关系，完全由“用了哪两条边”决定。

二、邻补角与对顶角

先看 ∠1 与 ∠2。它们有公共顶点 O；有一条公共边 OD；另一边 OA 与 OB 正好在同一条直线 AB 上，方向相反，我们称 OA 与 OB 互为反向延长线。像这样位置关系的两个角，叫做邻补角。同样，∠2 与 ∠3、∠3 与 ∠4、∠4 与 ∠1 也都是邻补角。

再看 ∠1 与 ∠3。它们也有公共顶点 O，但是没有公共边：∠1 的两条边是 OA、OD，∠3 的两条边是 OB、OC，而 OA 与 OB 互为反向延长线，OD 与 OC 也互为反向延长线。像这样，两边分别互为反向延长线的两个角，叫做对顶角。同样，∠2 与 ∠4 也是一对对顶角。

这两种关系可以对照着看，如图 2：左图把一对对顶角涂上了颜色，右图把一对邻补角涂上了颜色。请先自己指着图说一说“公共顶点在哪、公共边是哪条、哪两条边互为反向延长线”，再看下面的定义。

图 2 是两幅独立的小图，左图的 ∠1、∠2 与右图的 ∠3、∠4 分别说明一种关系，它们的编号与图 1 的编号没有联系，请各自独立看待。左图中，∠1 与 ∠2 两边分别互为反向延长线，没有公共边，是对顶角；右图中，∠3 与 ∠4 有公共顶点 O、公共边 OC，另一边 OA 与 OB 互为反向延长线，是邻补角。

邻补角与对顶角的数量关系
邻补角互补：∠1 + ∠2 = 180°　　对顶角相等：∠1 = ∠3

这两条结论中，“邻补角互补”几乎是定义的一部分：因为 OA 与 OB 组成一条直线，∠1 与 ∠2 拼起来正好是一个平角，所以它们的和是 180°。那么“对顶角相等”又是为什么呢？可以用邻补角把它推出来：

∵ ∠1 与 ∠2 是邻补角，∴ ∠1 + ∠2 = 180°，即 ∠1 = 180° − ∠2。

∵ ∠3 与 ∠2 也是邻补角，∴ ∠3 + ∠2 = 180°，即 ∠3 = 180° − ∠2。

∴ ∠1 = ∠3（都等于 180° − ∠2）。

这段推理的关键是“同角的补角相等”——∠1 和 ∠3 都是 ∠2 的补角，所以它们相等。你看，几何里的结论并不是背下来的，而是从更基本的结论一步一步推出来的。以后遇到“对顶角相等”，你既可以直接使用，也可以像这样写出理由。

要点：邻补角要同时满足三个条件：有公共顶点、有一条公共边、另一边互为反向延长线，它的数量关系是互补。对顶角要满足：有公共顶点、没有公共边、两边分别互为反向延长线，它的数量关系是相等。判断时先看“边”，再看“顶点”，最后才谈度数。
易错：（1）“相等的两个角是对顶角”是错的。把两个 50° 的角画在纸的任意两个地方，它们相等，却根本谈不上“对顶”。对顶角一定相等，但相等的角不一定是对顶角。（2）“互补的两个角是邻补角”也是错的。互补只要求度数和为 180°，这两个角可以离得很远；邻补角还要求有公共顶点和公共边。（3）邻补角是“成对”出现的，不能说“∠1 是邻补角”，只能说“∠1 与 ∠2 互为邻补角”。

为了把概念记得更牢，我们把邻补角和对顶角用三种语言各说一遍。以图 1 的 ∠1 与 ∠2 为例：

  • 文字语言：有公共顶点，有一条公共边，另一条边互为反向延长线的两个角，叫做邻补角。
  • 图形语言：两条直线相交，相邻的两个角就是邻补角（如图 1 中 ∠1 与 ∠2）。
  • 符号语言：∵ ∠1 与 ∠2 是邻补角，∴ ∠1 + ∠2 = 180°。

同样，对顶角的三种语言是：文字语言——“两边分别互为反向延长线的两个角叫做对顶角”；图形语言——“两条直线相交，不相邻的两个角是对顶角”；符号语言——“∵ ∠1 与 ∠3 是对顶角，∴ ∠1 = ∠3”。做几何题时，看到图形要能说出文字，看到文字要能画出图形，看到结论要能写出符号，这三种能力缺一不可。

拓展：两条直线相交，一共形成 2 对对顶角、4 对邻补角。三条直线相交于同一点，情况会复杂得多，但判断方法不变：仍然是一个一个角地看“公共顶点、公共边、反向延长线”。有兴趣的同学可以在纸上画三条直线交于一点，数一数一共有多少个角、多少对对顶角、多少对邻补角（答案：6 个角、3 对对顶角、6 对邻补角），再用“每个角都有 1 个对顶角和 2 个邻补角”去检验自己的答案。

三、余角与补角

邻补角和对顶角都离不开“相交”这个位置背景。但生活里还有另一类角的关系，它只跟度数有关，跟位置无关。比如把一块三角板的直角分成两个角，这两个角加起来总是 90°；再比如把一根直木条锯成两段拼成一个平角，两段对应的角加起来总是 180°。如图 3，左图是把一个直角分成 ∠1 与 ∠2，右图是把一个平角分成 ∠3 与 ∠4。

由图 3 可以概括出两个定义：

余角：如果两个角的和等于 90°（直角），就说这两个角互为余角，简称互余，其中一个角叫做另一个角的余角。

补角：如果两个角的和等于 180°（平角），就说这两个角互为补角，简称互补，其中一个角叫做另一个角的补角。

请注意三点。第一，余角、补角都是“两个角”之间的关系，必须说“互为”，单独一个角不能叫余角或补角。第二，余角、补角只与度数有关，与位置无关：图 3 中两个角是拼在一起的，但只要度数和是 90°，哪怕它们隔着十万八千里，也互为余角。第三，邻补角与补角不是一回事：邻补角一定互补，但互补的两个角不一定是邻补角，邻补角比补角多了“位置”的要求。

余角、补角的基本关系
若 ∠1 + ∠2 = 90°，则 ∠1 与 ∠2 互余　　若 ∠1 + ∠2 = 180°，则 ∠1 与 ∠2 互补

由定义还能推出两条很重要的性质。先看“同角的余角相等”：如果 ∠1 + ∠3 = 90°，∠2 + ∠3 = 90°，那么 ∠1 = 90° − ∠3，∠2 = 90° − ∠3，所以 ∠1 = ∠2。同理，“同角的补角相等”：由 ∠1 + ∠3 = 180°，∠2 + ∠3 = 180°，得 ∠1 = ∠2。如果把“同一个角”换成“相等的两个角”，结论仍然成立，这就是“等角的余角相等”“等角的补角相等”。例如 ∠1 + ∠3 = 90°，∠2 + ∠4 = 90°，且 ∠3 = ∠4，同样可得 ∠1 = ∠2。

余角、补角的性质
同角或等角的余角相等　　同角或等角的补角相等

还有一条常用的结论：一个锐角的补角比它的余角大 90°。设这个锐角为 x°（0 < x < 90），则它的补角是 (180 − x)°，余角是 (90 − x)°，两者相减得 (180 − x) − (90 − x) = 90，与 x 取什么值无关。这个结论在列方程时经常用到，它能帮你少设一个未知数。

提示：求一个角的余角、补角时，先看清楚题目给的是“这个角”还是“这个角的余角”。例如“∠A 的余角是 30°”，那么 ∠A = 90° − 30° = 60°；“∠A 比它的余角大 20°”，则 ∠A + (∠A − 20°) = 90°，解得 ∠A = 55°。方向弄反，答案就会全错。

四、例题精讲

下面的三道例题由易到难：第一道练“识图”，第二道练“计算与说理”，第三道练“列方程”。做题时请先遮住解答，自己动手写一遍，再对照检查每一步的依据。

例 1 对顶角与邻补角的识别

（1）如图 1，直线 AB 与 CD 相交于点 O，写出 ∠AOC 的对顶角和邻补角。（2）如图 2，左图中的 ∠1 与 ∠2 是什么关系的角？右图中的 ∠3 与 ∠4 又是什么关系的角？说明判断的依据。

解

（1）∠AOC 的两条边是射线 OA 和射线 OC。

把 OA 反向延长，得到射线 OB；把 OC 反向延长，得到射线 OD。所以 ∠AOC 的两边分别与 ∠BOD 的两边互为反向延长线，且这两个角没有公共边。

∴ ∠AOC 的对顶角是 ∠BOD。

∠AOC 与 ∠AOD 有公共顶点 O，有公共边 OA，另一边 OC 与 OD 互为反向延长线，∴ ∠AOD 是 ∠AOC 的邻补角。

同理，∠AOC 与 ∠BOC 有公共顶点 O，有公共边 OC，另一边 OA 与 OB 互为反向延长线，∴ ∠BOC 也是 ∠AOC 的邻补角。

∴ ∠AOC 的邻补角有两个：∠AOD 和 ∠BOC。

（2）左图中，∠1 的两边与 ∠2 的两边分别互为反向延长线，两个角没有公共边，∴ ∠1 与 ∠2 是对顶角，由对顶角相等得 ∠1 = ∠2。

右图中，∠3 与 ∠4 有公共顶点 O，有公共边 OC，另一边 OA 与 OB 互为反向延长线，∴ ∠3 与 ∠4 是邻补角，由邻补角互补得 ∠3 + ∠4 = 180°。

答：∠AOC 的对顶角是 ∠BOD，邻补角是 ∠AOD 与 ∠BOC；图 2 左图中 ∠1 与 ∠2 是对顶角，右图中 ∠3 与 ∠4 是邻补角。

变式：在图 1 中，（1）写出 ∠2 的对顶角和邻补角；（2）∠1 的邻补角有几个？这两个邻补角有什么关系？（答案：∠2 的对顶角是 ∠4，邻补角是 ∠1 与 ∠3；∠1 的邻补角有 2 个，它们是对顶角，所以相等。理由：∠1 的两条边是 OA、OD，与它相邻的两个角分别由 OB、OC 与这两条边组成，而 ∠1 的两个邻补角的两边恰好分别互为反向延长线。）

这道题的价值在于训练“看边”的习惯。很多同学判断对顶角时只盯着“两个角看起来相对”，结果把邻补角当成了对顶角。请记住：对顶角没有公共边，邻补角一定有一条公共边。只要把两个角各自的两条边写出来，答案就一目了然。

例 2 用对顶角、邻补角计算角度

如图 1，直线 AB 与 CD 相交于点 O，若 ∠AOC = 40°，求 ∠BOD、∠AOD、∠BOC 的度数。

解

∵ ∠AOC 与 ∠BOD 是对顶角，∴ ∠BOD = ∠AOC = 40°（对顶角相等）。

∵ ∠AOC 与 ∠AOD 是邻补角，∴ ∠AOD = 180° − ∠AOC = 180° − 40° = 140°（邻补角互补）。

∵ ∠BOC 与 ∠AOD 是对顶角，∴ ∠BOC = ∠AOD = 140°（对顶角相等）。

检验：40° + 140° + 40° + 140° = 360°，正好是绕点 O 转一圈的度数，说明计算无误。

答：∠BOD = 40°，∠AOD = 140°，∠BOC = 140°。

变式：如图 1，直线 AB 与 CD 相交于点 O，若 ∠AOD = 3∠AOC，求这四个角的度数。（答案：设 ∠AOC = x°，则 ∠AOD = 3x°。∵ ∠AOC 与 ∠AOD 是邻补角，∴ x + 3x = 180，解得 x = 45。∴ ∠AOC = 45°，∠AOD = 135°；由对顶角相等得 ∠BOD = 45°，∠BOC = 135°。检验：45° + 135° + 45° + 135° = 360°。）

这里要提醒一句：四个角中只要知道一个，其余三个就都确定了。因为对顶角相等、邻补角互补，两条结论一配合，就能把整个“十字”算出来。做这类题时，先画出草图，把已知角标上度数，再逐个推出，比死记公式可靠得多。

例 3 余角、补角与方程

（1）已知 ∠α = 35°，求 ∠α 的余角和补角。（2）已知一个角的补角是它的余角的 3 倍，求这个角。

解

（1）∠α 的余角为 90° − 35° = 55°；∠α 的补角为 180° − 35° = 145°。

检验：35° + 55° = 90°，35° + 145° = 180°，且 145° − 55° = 90°，符合“补角比余角大 90°”。

（2）设这个角为 x°。

它的补角是 (180 − x)°，它的余角是 (90 − x)°。

由题意得 180 − x = 3(90 − x)。

去括号，得 180 − x = 270 − 3x；

移项、合并，得 2x = 90，解得 x = 45。

检验：这个角是 45°，它的补角是 135°，余角是 45°，135° = 3 × 45°，符合题意。

答：∠α 的余角是 55°，补角是 145°；这个角是 45°。

变式：一个角的补角比它的余角的 2 倍多 30°，求这个角。（答案：设这个角为 x°，则 180 − x = 2(90 − x) + 30。去括号得 180 − x = 210 − 2x，解得 x = 30。检验：补角 150°，余角 60°，2 × 60° + 30° = 150°，符合题意。所以这个角是 30°。）

方法归纳：用方程求角，一般分四步。第一步“设”：把要求的角设为 x°，注意单位是度；第二步“译”：把题目中的每句话翻译成含 x 的式子，例如“补角”译为 180 − x，“余角”译为 90 − x；第三步“列”：根据“互补”“互余”“几倍多几”等关系列出方程；第四步“验”：把解代回题目的每一句话检验一遍，同时用“补角比余角大 90°”快速核对。方程思想是这一节最重要的工具，比“猜数凑数”可靠得多。

五、练习（第 1 课时）

1 【基础】判断下列说法是否正确，错误的请说明理由。

（1）相等的两个角是对顶角。（　　）

（2）有公共顶点且有一条公共边的两个角是邻补角。（　　）

（3）若 ∠1 + ∠2 = 180°，则 ∠1 与 ∠2 互为邻补角。（　　）

（4）一个角的补角一定比这个角大。（　　）

答案与解析

（1）×。相等的两个角不一定是对顶角。对顶角要求两边分别互为反向延长线，这是位置要求，度数相等只是它的结果。例如两个都是 50° 的角，放在纸的任何位置都相等，但它们不是对顶角。

（2）×。邻补角要求“有公共顶点、有一条公共边、另一边互为反向延长线”，缺一不可。只有公共顶点和公共边，另一边不一定互为反向延长线，这样的两个角只是相邻，不一定互补。

（3）×。互补只要求两个角的度数和是 180°，与位置无关；邻补角还要求有公共顶点和公共边。所以互补的两个角不一定是邻补角，邻补角一定互补。

（4）×。只有当这个角小于 90° 时，它的补角才比它大。例如 120° 的补角是 60°，比它小；90° 的补角还是 90°，与它相等。正确说法是：一个角的补角比它的余角大 90°。

2 【基础】如图 1，直线 AB 与 CD 相交于点 O。（1）写出 ∠1 的对顶角和邻补角；（2）若 ∠1 = 140°，求 ∠2、∠3、∠4 的度数。
答案与解析

（1）∠1 = ∠AOD，它的两边是 OA、OD。与它没有公共边、两边分别互为反向延长线的是 ∠3（∠BOC），所以 ∠1 的对顶角是 ∠3。与它有公共边的两个角是 ∠2（公共边 OD）和 ∠4（公共边 OA），所以 ∠1 的邻补角是 ∠2 与 ∠4。

（2）∵ ∠1 与 ∠2 是邻补角，∴ ∠2 = 180° − ∠1 = 180° − 140° = 40°（邻补角互补）。

∵ ∠3 与 ∠1 是对顶角，∴ ∠3 = ∠1 = 140°（对顶角相等）。

∵ ∠4 与 ∠2 是对顶角，∴ ∠4 = ∠2 = 40°（对顶角相等）。

检验：140° + 40° + 140° + 40° = 360°，计算正确。答：∠2 = 40°，∠3 = 140°，∠4 = 40°。

3 【提升】一个角的余角是它的补角的 1/4，求这个角。
答案与解析

设这个角为 x°，则它的余角是 (90 − x)°，补角是 (180 − x)°。

由题意得 90 − x = (180 − x) / 4。

两边同乘 4，得 360 − 4x = 180 − x；

移项、合并，得 3x = 180，解得 x = 60。

检验：这个角是 60°，余角是 30°，补角是 120°，30° = 120° × 1/4，符合题意。

答：这个角是 60°。

4 【提升】直线 AB 与 CD 相交于点 O，∠AOC 与 ∠AOD 的度数之比为 2 : 3，求这四个角的度数。
答案与解析

∵ ∠AOC 与 ∠AOD 是邻补角，∴ ∠AOC + ∠AOD = 180°（邻补角互补）。

设 ∠AOC = 2k°，则 ∠AOD = 3k°。

∴ 2k + 3k = 180，即 5k = 180，解得 k = 36。

∴ ∠AOC = 2 × 36° = 72°，∠AOD = 3 × 36° = 108°。

∵ ∠BOD 与 ∠AOC 是对顶角，∴ ∠BOD = 72°（对顶角相等）。

∵ ∠BOC 与 ∠AOD 是对顶角，∴ ∠BOC = 108°（对顶角相等）。

检验：72° + 108° + 72° + 108° = 360°，且 72 : 108 = 2 : 3，符合题意。

答：∠AOC = 72°，∠AOD = 108°，∠BOC = 108°，∠BOD = 72°。

5 【拓展】一个角的补角与它的余角的和是 200°。（1）求这个角以及它的余角、补角；（2）由此说明“一个角的补角比它的余角大 90°”对任意角是否都成立。
答案与解析

（1）设这个角为 x°，则它的补角是 (180 − x)°，余角是 (90 − x)°。

由题意得 (180 − x) + (90 − x) = 200。

合并同类项，得 270 − 2x = 200，即 2x = 70，解得 x = 35。

∴ 这个角是 35°，它的余角是 90° − 35° = 55°，补角是 180° − 35° = 145°。

检验：145° + 55° = 200°，符合题意。

（2）设任意一个角为 x°，则补角为 (180 − x)°，余角为 (90 − x)°。

∵ (180 − x) − (90 − x) = 180 − x − 90 + x = 90，结果与 x 无关，

∴ 对任意一个角（0° < x < 90°），它的补角都比它的余角大 90°，这条结论恒成立。

答：这个角是 35°，余角是 55°，补角是 145°；结论恒成立。

课时小结：
  • 同一平面内两条不重合的直线只有相交与平行两种位置关系，相交时只有一个交点。
  • 邻补角：公共顶点、公共边、另一边互为反向延长线，和为 180°；对顶角：公共顶点、无公共边、两边分别互为反向延长线，两角相等。
  • 余角看“和为 90°”，补角看“和为 180°”，二者只与度数有关；邻补角既要求位置，又要求度数。
  • 性质：同角或等角的余角相等，同角或等角的补角相等；一个角的补角比它的余角大 90°。
  • 常用方法：识图先找顶点和边；计算先标已知角再逐步推出；复杂问题设未知数列方程，最后代回检验。

第 2 课时垂线

一、相交中的特殊情况——垂直

上一课时我们看到，两条直线相交会形成四个角，这四个角分成两组：一组是对顶角，一组是邻补角。如果把其中一条直线绕着交点慢慢转动，四个角的大小会跟着变化，但“对顶角相等、邻补角互补”这两条结论始终不变。转动的过程中，有一个位置特别引人注意：四个角变得一样大。

四个角一样大，而它们的和是 360°，所以每个角都是 90°。这时，两条直线相交成直角，我们就说这两条直线互相垂直。其中一条直线叫做另一条直线的垂线，它们的交点叫做垂足。

垂直用符号“⊥”表示。如图 4，直线 AB 与直线 CD 相交于点 O，且 ∠AOC = 90°，我们就记作 AB ⊥ CD 于点 O，读作“AB 垂直于 CD，垂足为 O”。注意写法：垂直符号两边写的是两条直线（或线段、射线）的名称，垂足要写在“于点 O”里，不能写成“AB ⊥ O”。

垂直是相交的一种特殊情形，不是与“相交、平行”并列的第三种位置关系。这一点很多同学会弄混：两条直线垂直，它们当然也是相交的，只不过交角恰好是 90°。所以“同一平面内两条直线的位置关系”仍然是相交与平行两种。

垂直的符号语言
∵ AB ⊥ CD 于点 O，∴ ∠AOC = ∠BOC = ∠AOD = ∠BOD = 90°
∵ ∠AOC = 90°，∴ AB ⊥ CD

这两行符号语言说明：垂直与直角是可以互相推出的。由“垂直”能推出“四个角都是 90°”，由“有一个角是 90°”也能推出“两条直线垂直”。为什么要强调“四个角都是 90°”？因为只要一个角是 90°，它的对顶角也是 90°（对顶角相等），它的两个邻补角都是 180° − 90° = 90°（邻补角互补），所以四个角必然全是直角。这个推理过程正是上一课时两条结论的直接应用，请你务必自己动手写一遍。

易错：（1）垂直是相交的特殊情形，不是与“相交、平行”并列的第三种位置关系；两条直线不垂直，也可能只是普通的相交，不能由此断定它们平行。（2）判断垂直不能只凭“看起来像直角”，必须依据“相交成直角”这个条件，或者用三角板的直角去量。（3）写“AB ⊥ CD 于点 O”时，垂足 O 必须写清楚，因为过一点作垂线，垂足的位置决定了后面所有的计算。

二、垂线的画法与基本事实

怎样画一条直线的垂线？最常用的工具是三角板。三角板有一个角是直角，利用它就能画出 90°。具体画法是：一贴——把三角板的一条直角边贴在已知直线上；二移——沿着直线平移三角板，直到另一条直角边经过已知点；三画——沿着这条直角边画出直线，并在垂足处标上直角符号。如果已知点在直线上，就让直角边经过这个点；如果已知点在直线外，同样让直角边经过这个点，画出的直线一定与已知直线垂直。

也可以用量角器画：把量角器的零刻度线与已知直线重合，找到 90° 的刻度，从已知点引出一条射线即可。两种方法道理相同，都是“让两条直线相交成直角”。

画的过程中你会发现一个现象：无论已知点在直线上还是在直线外，过这个点画出的垂线只有一条。这不是巧合，而是几何中的一条基本事实：

基本事实：在同一平面内，过一点有且只有一条直线与已知直线垂直。

这句话有三个关键词，缺一不可。“在同一平面内”——离开了这个前提，过一点可以作无数条直线与已知直线垂直（它们组成一个平面），初中阶段我们不研究这种情况。“过一点”——这个点可以在已知直线上，也可以在直线外，两种情形都只有一条垂线。“有且只有”——“有”说明这样的直线存在，能画出来；“只有”说明这样的直线唯一，不会画出第二条。数学里把这种“存在且唯一”的结论叫做基本事实，它是我们后面画图、说理的依据。

提示：“过一点作已知直线的垂线”与“过直线外一点作已知直线的平行线”是两条不同的基本事实，不要混淆：垂线是“有且只有一条”，平行线也是“有且只有一条”，但垂线要求“相交成直角”，平行线要求“没有公共点”。画图时，垂线用三角板的直角边，平行线用三角板平移。

三、垂线段最短与点到直线的距离

从直线外一点向直线作垂线，这个点与垂足之间的线段，叫做垂线段。如图 5，P 是直线 l 外一点，PA ⊥ l 于点 A，线段 PA 就是点 P 到直线 l 的垂线段；而 PB、PC、PD 的端点 B、C、D 都在 l 上，但它们与 l 不垂直，这样的线段叫做斜线段。

用尺子量一量图 5 中的四条线段，你会发现 PA 最短。把 P 点固定，让 B 点在 l 上左右移动，PB 的长度会变化，但无论怎样移动，PB 总比 PA 长；只有当 B 移动到 A 的位置时，PB 才与 PA 重合。这正是几何中的另一条基本事实：

基本事实：直线外一点与直线上各点连接的所有线段中，垂线段最短。

这条结论在生活中用处很大。过马路时，我们总想走最短的路，垂直于马路走就是最短的；测量跳远成绩时，皮尺要垂直于起跳线，量的才是真正的成绩；修水渠时，要让水渠最短，就要从村庄向河边作垂线段。这些现象背后的道理都是“垂线段最短”。

既然垂线段最短，那么它的长度就成了刻画“点与直线之间距离”的最好工具。于是我们规定：从直线外一点到这条直线的垂线段的长度，叫做点到直线的距离。

易错：点到直线的距离是一个长度，是一个数量（带单位，如 2.4 cm），而不是一条线段。所以“点 P 到直线 l 的距离是线段 PA”这句话是错的，应说“点 P 到直线 l 的距离是线段 PA 的长度”；也不能说“点 P 到直线 l 的距离是 PA”，因为 PA 是线段名称，要写成“PA 的长”或“PA = 2.4 cm”。另外，距离不能随便量一条线段，必须量垂线段。

把“垂直、垂线、垂线段、点到直线的距离”这几个概念放在一起比较，见表 2。很多同学做题时把“垂线”和“垂线段”混着说，其实前者是直线（无限长），后者是线段（有长度），一字之差，含义完全不同。

四、例题精讲

例 1 垂直与角度计算

如图 4，AB ⊥ CD 于点 O，射线 OE 在 ∠AOC 的内部，且 ∠AOE = 25°，求 ∠EOC 与 ∠BOE 的度数。

解

∵ AB ⊥ CD 于点 O，∴ ∠AOC = 90°（垂直的定义）。

∵ OE 在 ∠AOC 的内部，∴ ∠EOC = ∠AOC − ∠AOE = 90° − 25° = 65°。

∵ AB ⊥ CD 于点 O，∴ ∠BOC = 90°（垂直的定义）。

∵ ∠BOE = ∠BOC + ∠EOC，∴ ∠BOE = 90° + 65° = 155°。

另解：∵ ∠AOE 与 ∠BOE 是邻补角，∴ ∠BOE = 180° − ∠AOE = 180° − 25° = 155°（邻补角互补），与上面结果一致。

答：∠EOC = 65°，∠BOE = 155°。

变式：如图 4，AB ⊥ CD 于点 O，OE 在 ∠AOC 的内部，若 ∠BOE = 140°，求 ∠AOE 与 ∠EOC 的度数。（答案：∵ ∠AOE 与 ∠BOE 是邻补角，∴ ∠AOE = 180° − 140° = 40°；∵ AB ⊥ CD，∴ ∠AOC = 90°，∴ ∠EOC = 90° − 40° = 50°。检验：∠BOE = ∠BOC + ∠EOC = 90° + 50° = 140°，符合题意。）

这道题的关键是“把要求的角放进直角里”。只要看到垂直，就立刻在图上标出四个 90°，再用角的和差去凑。很多同学算错，是因为没有标出 90°，全凭眼睛估计。

例 2 垂线段最短

如图 5，P 是直线 l 外一点，PA ⊥ l 于点 A，B、C、D 是 l 上另外三点，且 A 在 B、C 之间。比较 PA、PB、PC、PD 的长短，并说明理由。

解

PA 最短。理由：PA 是点 P 到直线 l 的垂线段，而 PB、PC、PD 都是斜线段，由“垂线段最短”可知 PA 小于 PB、PC、PD 中的任何一条。

进一步比较三条斜线段：在图 5 中量一量可以发现，斜线段的端点离垂足 A 越远，这条斜线段就越长。

在图 5 中，C 到 A 的距离小于 B 到 A 的距离，B 到 A 的距离又小于 D 到 A 的距离，

∴ PC < PB < PD。

综合起来：PA < PC < PB < PD。

答：四条线段中 PA 最短，大小顺序为 PA < PC < PB < PD。

变式：如图 5，若 PA = 2.4 cm。（1）点 P 到直线 l 的距离是多少？（2）B 是 l 上一点，PB = 3 cm，PB 与 PA 哪条长？（3）若直线 l 上有一点到点 P 的距离恰好也是 2.4 cm，这个点与点 A 有什么关系？（答案：（1）2.4 cm，因为距离就是垂线段 PA 的长度；（2）PB 比 PA 长，因为 PA 是垂线段，PB 是斜线段，垂线段最短；（3）这个点与点 A 重合，因为它若不是 A，它与 P 的连线就是斜线段，由“垂线段最短”必有它大于 PA，即大于 2.4 cm，与已知矛盾。）

请注意第（3）问的推理方式：先假设结论不成立，推出与已知矛盾的结论，从而说明假设错误。这种“反证”的想法在几何里很常用，现在先感受一下，以后会系统学习。

例 3 点到直线的距离

如图 6，在 △ABC 中，∠C = 90°，AC = 3 cm，BC = 4 cm，AB = 5 cm。求点 C 到直线 AB 的距离。

解

过点 C 作 CH ⊥ AB，垂足为 H，则点 C 到直线 AB 的距离就是线段 CH 的长度（点到直线的距离的定义）。

∵ ∠C = 90°，∴ AC ⊥ BC，即 △ABC 是以 AB 为斜边的直角三角形，AC、BC 是两条直角边。

用两种方式表示 △ABC 的面积：

以 AC、BC 为底和高，面积 = 1/2 × AC × BC = 1/2 × 3 × 4 = 6（cm²）；

以 AB 为底、CH 为高，面积 = 1/2 × AB × CH = 1/2 × 5 × CH。

同一个三角形的面积相等，∴ 1/2 × 5 × CH = 6，解得 CH = 12/5 = 2.4（cm）。

答：点 C 到直线 AB 的距离是 2.4 cm。注意，这里的 2.4 cm 是垂线段 CH 的长度，不是线段 CH 本身，也不是斜边 AB 的长。

变式：在 △ABC 中，∠ACB = 90°，AC = 6 cm，BC = 8 cm，AB = 10 cm，求点 C 到 AB 的距离。（答案：面积 = 1/2 × 6 × 8 = 24（cm²）；又 1/2 × 10 × h = 24，解得 h = 4.8（cm）。所以点 C 到 AB 的距离是 4.8 cm。）

方法归纳：求点到直线的距离，第一步是“作垂线、定垂足”，把距离转化成长度；第二步是“找直角三角形”，把已知长度和所求长度放进同一个图形；第三步是“用面积法”，同一个三角形用两种方式算面积，列等式求解。面积法是求斜边上的高的常用办法，比死记公式灵活得多。

1 【基础】判断下列说法是否正确，错误的请说明理由。

（1）两条直线相交所成的四个角中，如果有一个角是直角，那么其余三个角也都是直角。（　　）

（2）在同一平面内，过一点有且只有一条直线与已知直线垂直。（　　）

（3）直线外一点到这条直线的垂线段，叫做点到直线的距离。（　　）

（4）从直线外一点到直线上各点连接的所有线段中，垂线段最短。（　　）

答案与解析

（1）√。设这个直角为 ∠1，则它的对顶角等于 90°（对顶角相等），它的两个邻补角都等于 180° − 90° = 90°（邻补角互补），所以四个角全是直角。

（2）√。这是垂线的基本事实，但“在同一平面内”这个前提不能丢，也不能漏掉“有且只有”中的“只有”。

（3）×。点到直线的距离是垂线段的长度，是一个数量，不是线段本身。应说“直线外一点到这条直线的垂线段的长度，叫做点到直线的距离”。

（4）√。这是“垂线段最短”的基本事实，它是我们测量距离、解决最短路线问题的依据。

2 【基础】如图 4，AB ⊥ CD 于点 O，OE 在 ∠AOC 的内部。若 ∠BOE = 130°，求 ∠AOE 与 ∠EOC 的度数。
答案与解析

∵ ∠AOE 与 ∠BOE 是邻补角，∴ ∠AOE = 180° − ∠BOE = 180° − 130° = 50°（邻补角互补）。

∵ AB ⊥ CD 于点 O，∴ ∠AOC = 90°（垂直的定义）。

∵ OE 在 ∠AOC 的内部，∴ ∠EOC = ∠AOC − ∠AOE = 90° − 50° = 40°。

检验：∠BOE = ∠BOC + ∠EOC = 90° + 40° = 130°，符合题意。

答：∠AOE = 50°，∠EOC = 40°。

3 【提升】在 △ABC 中，∠ACB = 90°，AC = 6 cm，BC = 8 cm，AB = 10 cm，求点 C 到直线 AB 的距离。
答案与解析

过点 C 作 CH ⊥ AB，垂足为 H，则点 C 到直线 AB 的距离就是 CH 的长度。

∵ ∠ACB = 90°，∴ AC ⊥ BC，AC、BC 是两条直角边。

△ABC 的面积 = 1/2 × AC × BC = 1/2 × 6 × 8 = 24（cm²）。

又 △ABC 的面积 = 1/2 × AB × CH = 1/2 × 10 × CH = 5 × CH。

∴ 5 × CH = 24，解得 CH = 4.8（cm）。

答：点 C 到直线 AB 的距离是 4.8 cm。

4 【提升】如图 5，PA ⊥ l 于点 A，PA = 2.4 cm。（1）点 P 到直线 l 的距离是多少？（2）B 是 l 上一点，PB 一定大于 PA 吗？为什么？（3）若直线 l 上有一点到点 P 的距离恰好是 2.4 cm，这个点与点 A 有什么关系？
答案与解析

（1）点 P 到直线 l 的距离是 2.4 cm。因为点到直线的距离就是垂线段 PA 的长度。

（2）PB 一定大于 PA。因为 PA ⊥ l，PA 是垂线段，而 B 是 l 上另一点，PB 是斜线段；由“垂线段最短”，PB 大于 PA。只有当 B 与 A 重合时才有 PB = PA，但题目说 B 是另一点，所以 PB 严格大于 PA。

（3）这个点与点 A 重合。理由：设这个点为 M。若 M 与 A 不重合，则 PM 是斜线段，由“垂线段最短”应有 PM 大于 PA，即 PM 大于 2.4 cm，这与 PM = 2.4 cm 矛盾。所以 M 只能与 A 重合。

答：（1）2.4 cm；（2）一定大于，依据是垂线段最短；（3）这个点就是点 A。

5 【拓展】在 △ABC 中，∠C = 90°，AC = 3 cm，BC = 4 cm，AB = 5 cm。分别求点 A 到直线 BC 的距离、点 B 到直线 AC 的距离、点 C 到直线 AB 的距离，并指出哪一个最短，说明理由。
答案与解析

（1）∵ ∠C = 90°，∴ AC ⊥ BC，垂足为 C，∴ 点 A 到直线 BC 的距离就是 AC 的长度，即 3 cm。

（2）同理，BC ⊥ AC，垂足为 C，∴ 点 B 到直线 AC 的距离就是 BC 的长度，即 4 cm。

（3）过点 C 作 CH ⊥ AB 于点 H，用面积法：1/2 × 3 × 4 = 1/2 × 5 × CH，得 CH = 2.4 cm，∴ 点 C 到直线 AB 的距离是 2.4 cm。

比较三个距离：2.4 cm < 3 cm < 4 cm，所以点 C 到直线 AB 的距离最短。

理由：三条距离分别是三条边上的高。AC、BC 是直角边，CH 是斜边上的高。在直角三角形中，斜边最长，而“等面积”意味着底越长，高越短，所以斜边上的高 CH 一定比两条直角边都短。

答：三个距离分别是 3 cm、4 cm、2.4 cm，点 C 到 AB 的距离最短。

  • 点到直线的距离是垂线段的长度，是一个数量，不是线段本身。
  • 求距离的常用方法：作垂线定垂足 → 找直角三角形 → 用面积法列等式求解。

探索直线平行的条件

铁路上两条笔直的钢轨、窗框上下的两根横档、双杠的两根立柱，看上去都“一样宽”，也就是互相平行。可在纸上，两条直线是不是平行，光靠眼睛看并不可靠：它们也许在很远的地方相交。要判断两条直线平行，就得找一个看得见、量得出的条件。这一节我们先认清两条直线被第三条直线所截形成的 8 个角——同位角、内错角、同旁内角，再用这些角的大小关系去判定两条直线平行，最后学会用三角板和直尺画平行线，并说清画法的道理。

学习目标

  • 理解截线、被截线的意义，能在“三线八角”的图形中正确指出同位角、内错角、同旁内角，会用“先找截线、再看位置”的步骤识图。
  • 经历画图、度量、叠合等操作活动，归纳出基本事实“同位角相等，两直线平行”，并能用符号语言写出推理过程。
  • 能由“内错角相等”或“同旁内角互补”判定两条直线平行，会借助对顶角、邻补角把条件转化为同位角相等。
  • 了解平行公理及推论“平行于同一条直线的两条直线互相平行”，会用三角板和直尺画平行线并说明道理。
  • 在识图与说理中体会文字语言、图形语言、符号语言的互译，养成“先定截线、再看位置、最后写依据”的习惯。

第 1 课时同位角、内错角、同旁内角

先看一个熟悉的画面。铁路上两条笔直的钢轨互相平行，一根根枕木把它们“串”在一起；窗框上下的两根横档互相平行，左右两根竖档又把它们连起来。把钢轨、横档看成直线，把枕木、竖档也看成直线，就得到一个最基本、也最重要的图形：两条直线被第三条直线所截。

这个图形里一共出现 8 个角，习惯上叫做“三线八角”。这一课时要做的，就是在这 8 个角里认清位置特殊的那些角，并给它们起名字。名字起好了，下一课时才能用它们的大小关系去判定两条直线平行。

1. 截线与被截线：先看清是哪三条线

如图 7 的左图，直线 a 与直线 b 被直线 c 所截，c 与 a、b 各交于一点，一共形成 8 个角，依次编号为 ∠1 至 ∠8。这里穿过另外两条直线的直线 c 叫做截线，直线 a、b 叫做被截线。

“截线”这个名称并不表示它有什么特殊身份。在一般的三线八角图形中，三条直线里哪一条都可以当截线，关键是看它是否与另外两条直线都相交。本节的图 7 中 a 与 b 是平行的，它们没有交点，所以这里只能把 c 看成截线，把 a、b 看成被截线。以后还会遇到有两条截线的图形，那时同一个角与不同的角配对，名称就可能改变，这一点要特别注意。

识图的第一步永远是先找截线。8 个角分布在截线穿过的两个交点上，每个交点周围有 4 个角。找到了截线，就能把 8 个角分成上下两组、每组 4 个，位置关系也就一目了然。

再看图 7，可以画出一张“位置地图”。按“在两条被截线的内部还是外部”分：∠3、∠4、∠5、∠6 夹在 a 与 b 之间，属于“内部”；∠1、∠2、∠7、∠8 在 a、b 的外侧，属于“外部”。按“在截线的哪一侧”分：∠1、∠3、∠5、∠7 在 c 的左侧，∠2、∠4、∠6、∠8 在 c 的右侧。每个角都同时有“内外”和“左右”两个身份，把这两个身份说清楚，三类角就自然分出来了。

2. 同位角：形如“F”，一共 4 对

定义：两条直线被第三条直线所截，如果两个角分别在截线的同侧，并且分别在两条被截线的同方（都在上方或者都在下方），那么这两个角叫做同位角。

用“位置地图”去套：截线同侧，被截线同方。在图 7 中，∠1 在 c 的左侧、在 a 的上方；∠5 也在 c 的左侧、在 b 的上方。两个角“左对左、上对上”，位置完全相同，所以 ∠1 与 ∠5 是同位角。照此办理，还有 ∠2 与 ∠6（都在右侧、都在上方）、∠3 与 ∠7（都在左侧、都在下方）、∠4 与 ∠8（都在右侧、都在下方），一共 4 对。

图形语言上，把 ∠1 与 ∠5 的边描出来，会看到一个“F”：截线 c 是 F 的竖，两条被截线是 F 的两横。所以同位角也常被叫做“F 形角”。图 7 右侧第一幅小图画的正是这个“F”，两段弧线标出的一对相等位置的角就是同位角。要注意 F 的两横必须在竖的同一侧，如果一横朝左、一横朝右，那就成不了 F，也就不是同位角。

文字语言、图形语言、符号语言要能互相翻译。以 ∠1 与 ∠5 为例：文字语言是“∠1 与 ∠5 是同位角”；图形语言是“F 形”；符号语言可以写成“∠1 与 ∠5 是直线 a、b 被直线 c 所截得到的同位角”。三句话说的是同一件事，但写推理依据时，第三种说法最不容易出错，因为它把三条直线都点了名。

3. 内错角：形如“Z”，一共 2 对

定义：两个角都在两条被截线之间，并且分别在截线的两侧，这样的两个角叫做内错角。“内”指在被截线之间，“错”指被截线两侧、彼此错开。

图 7 中夹在 a、b 之间的是 ∠3、∠4、∠5、∠6。其中 ∠3 在 c 的左侧、∠6 在 c 的右侧，两个角一左一右，又都在内部，所以 ∠3 与 ∠6 是内错角。另一对是 ∠4 与 ∠5（∠4 在右、∠5 在左）。一共 2 对。

把 ∠3 与 ∠6 的边描出来，得到一个“Z”：∠3 的一条边沿 a 向左，中间一段沿 c 斜下，∠6 的一条边沿 b 向右。图 7 右侧第二幅小图就是这个“Z”。判断内错角时，“Z”的两横方向相反，这一点与“F”的两横同向正好形成对照，把两个图形放在一起记，不容易混。

内错角只有 2 对，原因是内部的角一共 4 个，两两配对成 2 对。这也提醒我们：只有位于两条被截线之间的角，才可能成为内错角或同旁内角；像 ∠1、∠2 这样处在“外部”的角，根本没有内错角，也没有同旁内角。

4. 同旁内角：形如“U”，一共 2 对

定义：两个角都在两条被截线之间，并且都在截线的同一侧，这样的两个角叫做同旁内角。“同旁”指截线同侧，“内”指被截线之间。

图 7 中，∠3 与 ∠5 都在 a、b 之间，又都在 c 的左侧，所以它们是一对同旁内角；∠4 与 ∠6 都在内部、都在 c 的右侧，也是一对同旁内角。一共 2 对。

把 ∠3 与 ∠5 的边描出来，得到的是一个“U”形（横过来看像一个“コ”）：两条被截线之间的两段是 U 的两个“壁”，截线是 U 的“底”。图 7 右侧第三幅小图就是这个“U”。

把三类角放在一起比较，会发现区别只有两句话：两个角在截线的同侧还是两侧？在两条被截线的同方还是之间？同侧加同方是同位角，两侧加之间是内错角，同侧加之间是同旁内角。名称只与位置有关，与角的大小毫无关系——两个同位角可以相等，也可以相差很多。

要点：三线八角里，截线同侧且被截线同方的两个角是同位角（4 对）；截线两侧且被截线之间的两个角是内错角（2 对）；截线同侧且被截线之间的两个角是同旁内角（2 对）。三者的判别只依赖位置，不依赖大小。

同侧同方——同位角；两侧之间——内错角；同侧之间——同旁内角。

5. 识图三步法：先找截线，再看位置

初学识图，最容易犯的毛病是“看到两个角就下结论”。同一幅图里有 8 个角，两两配对能有 28 种组合，名称当然各不相同。所以要养成按步骤走的习惯，不要凭感觉。

方法归纳：
  • 第一步，找截线：找出那条穿过两个交点的直线，另外两条就是被截线。截线找错了，后面的判断全部作废。
  • 第二步，定内外：看这两个角是在两条被截线之间，还是都在外面。
  • 第三步，看同侧还是两侧：两个角在截线的同一旁，还是一左一右。
  • 第四步，对号入座：同侧加同方是同位角；两侧加之间是内错角；同侧加之间是同旁内角；其余组合（例如同侧但一个在内部一个在外部）不属于这三类。

还有一个小技巧：判断时可以先用手指（或用笔尖）沿截线“划一刀”，看两个角是不是被这一刀分在了两边；再沿两条被截线各“划一刀”，看两个角是不是都夹在中间。动手比空想可靠。

例 1 在图 7 中识别三类角

如图 7，直线 a、b 被直线 c 所截。指出 ∠1 的同位角、∠3 的内错角、∠3 的同旁内角。

解

（1）先找 ∠1 的位置：它在截线 c 的左侧，在直线 a 的上方。同位角要在截线同侧、被截线同方，所以在 b 的上方、c 的左侧去找，只有 ∠5 符合。因此 ∠1 的同位角是 ∠5。

（2）再看 ∠3：它在 c 的左侧，夹在 a、b 之间。内错角要在截线两侧、被截线之间，所以在 b 的上方（即内部）、c 的右侧去找，只有 ∠6 符合。因此 ∠3 的内错角是 ∠6。

（3）同旁内角要在截线同侧、被截线之间。与 ∠3 同在 c 左侧、又在 a、b 之间的角是 ∠5。因此 ∠3 的同旁内角是 ∠5。

（4）回头检查一遍：∠1 与 ∠5 是同位角，∠3 与 ∠5 是同旁内角，∠3 与 ∠6 是内错角，三组结论互不矛盾。这也说明同一个角 ∠5 与不同的角配对，可以有不同的名称，关键是先确定“跟谁配、以谁为截线”。

变式：在图 7 中写出 ∠2 的同位角、∠4 的内错角、∠4 的同旁内角。答案：∠2 的同位角是 ∠6；∠4 的内错角是 ∠5；∠4 的同旁内角是 ∠6。

（3）∠3 与 ∠5 都在 a、b 之间，又都在 c 的左侧，截线同侧、被截线之间，所以它们是同旁内角。

（6）∠2 与 ∠3 的顶点相同（都是 c 与 a 的交点），且 ∠2 的两边与 ∠3 的两边分别互为反向延长线，所以它们是对顶角，不是同位角、内错角或同旁内角。

归纳：判断位置关系，第一步确定这两个角是由哪两条直线相交、由哪条直线所截形成的；第二步看它们在截线的同侧还是两侧、在被截线的同方还是之间。同一个角与不同的角配对，名称会不同：∠3 与 ∠6 是内错角，∠3 与 ∠5 是同旁内角，∠3 与 ∠7 是同位角，∠3 与 ∠2 是对顶角，∠3 与 ∠1 是邻补角。可见名称完全由“配对的对象”和“截线是谁”决定，绝不能只看一个角就下结论。

（8）两条截线的图形（如后面练习中图 10（b）那样的图形）：直线 a、b 同时被直线 c、d 所截，相当于把两个三线八角叠在一起。以 c 为截线时，∠1 与 ∠2 都在 a、b 之间、分居 c 的两侧，是内错角；以 d 为截线时，∠3 与 ∠4 都在 a、b 之间、同在 d 的左侧，是同旁内角；而把 a 当作截线、c 与 d 当作被截线时，∠1 与 ∠3 都在 a 的下方、又都在各自被截线的同一侧，成了同位角。同一个角 ∠1，在不同的截线下名称完全不同。所以遇到两条截线的图形，第一步不是看角，而是先确定“这一次以谁为截线”，再判断位置关系；具体用法第 3 课时还会专门练习。

变式：在图 7 中判断 ∠1 与 ∠6 的位置关系。答案：∠1 在两条被截线的外部，∠6 在两条被截线的内部，两个角既不同侧同方，也不同侧之间或两侧之间，所以它们不属于同位角、内错角、同旁内角中的任何一类。

例 3 由角的关系猜想线的位置关系

如图 7，（1）若 ∠1 = ∠5，能判断哪两条直线平行？依据是什么？（2）若 ∠3 = ∠6，能判断哪两条直线平行？依据是什么？（3）若 ∠3 + ∠5 = 180°，能判断哪两条直线平行？依据是什么？

解

（2）∠3 与 ∠6 是内错角。若 ∠3 = ∠6，即内错角相等，则 a∥b。依据是“内错角相等，两直线平行”。

（3）∠3 与 ∠5 是同旁内角。若 ∠3 + ∠5 = 180°，即同旁内角互补，则 a∥b。依据是“同旁内角互补，两直线平行”。

（4）三个小题的结论相同，都是 a∥b，但已知条件不同，依据也不同。这说明判定两条直线平行有三条路可走，分别对应三类角；三条路的方向是一致的：都是由“角的关系”推出“线平行”。这三条判定方法将在后面两个课时里逐一说明理由。

变式：在图 7 中，若 ∠2 = ∠6 = 100°，能否判断 a∥b？答案：能。∠2 与 ∠6 是同位角，且 ∠2 = ∠6，由“同位角相等，两直线平行”得 a∥b。

6. 练习：把“三步法”用熟

1 【基础】如图 7，指出 ∠2 的同位角、∠4 的内错角、∠4 的同旁内角，并说明每一步的判断理由。
答案与解析

∠2 的同位角是 ∠6。理由：∠2 在截线 c 的右侧、直线 a 的上方，与它同侧同方的角只有 b 上方、c 右侧的 ∠6。

∠4 的内错角是 ∠5。理由：∠4 在 c 的右侧、a 与 b 之间，内错角要在 c 的左侧、a 与 b 之间去找，符合的是 ∠5。

∠4 的同旁内角是 ∠6。理由：∠4 与 ∠6 都在 a、b 之间，又都在 c 的右侧，截线同侧、被截线之间。

2 【基础】如图 7，下列各对角中，哪几对是同位角？∠1 与 ∠5、∠2 与 ∠8、∠3 与 ∠7、∠4 与 ∠6。
答案与解析

∠1 与 ∠5 是同位角：都在 c 的左侧，都在各自被截线的上方，同侧同方。

∠3 与 ∠7 是同位角：都在 c 的左侧，都在各自被截线的下方，同侧同方。

∠2 与 ∠8 不是同位角：∠2 在 a 的上方，∠8 在 b 的下方，一个在上一个在下，位置不同。它们同在 c 的右侧，属于“同侧但不同方”。

∠4 与 ∠6 不是同位角：∠4 在 a 的下方，∠6 在 b 的上方，位置不同；它们都在 a、b 之间、都在 c 的右侧，其实是同旁内角。

3 【提升】如图 7，已知 ∠1 = 65°，∠5 = 65°。（1）求 ∠2、∠3 的度数；（2）判断直线 a 与 b 是否平行，并说明理由。
答案与解析

（1）∠1 与 ∠2 有公共顶点，且有一条公共边（沿截线 c 向上的那条边），另一边沿直线 a 互为反向延长线，所以 ∠1 与 ∠2 是邻补角，∠1 + ∠2 = 180°。因为 ∠1 = 65°，所以 ∠2 = 180° − 65° = 115°。

同理，∠1 与 ∠3 有公共边（沿 a 向左的那条边），另一边沿 c 互为反向延长线，它们也是邻补角，所以 ∠3 = 180° − 65° = 115°。也可以这样看：∠2 与 ∠3 是对顶角，所以 ∠3 = ∠2 = 115°，两种算法结果一致。

（2）a∥b。理由：∠1 与 ∠5 是直线 a、b 被直线 c 所截得到的同位角，且 ∠1 = ∠5 = 65°，由“同位角相等，两直线平行”可得 a∥b。

4 【提升】如图 7，∠1、∠2、∠3、∠4 这四个角中，哪些角有内错角？分别写出它们的内错角；∠1 为什么没有内错角？
答案与解析

有内错角的是 ∠3 和 ∠4。∠3 的内错角是 ∠6，∠4 的内错角是 ∠5。

∠1、∠2 没有内错角。原因：内错角的定义要求两个角都在两条被截线之间。∠1 在直线 a 的上方、∠2 也在直线 a 的上方，它们都落在两条被截线的外部，不可能与任何角构成“都在内部、分居截线两侧”的一对角。可见能不能有内错角，先要看这个角是不是夹在两条被截线之间。

顺便还能得到一个结论：内部一共有 4 个角（∠3、∠4、∠5、∠6），两两配成 2 对内错角、2 对同旁内角，这与表 3 中的“2 对”是一致的。

5 【拓展】两条平行直线被两条不同的截线所截。每条截线都截出 4 对同位角、2 对内错角、2 对同旁内角。这样的图形中一共有多少对同位角、多少对内错角、多少对同旁内角？请说明你的算法。
答案与解析

一共有 8 对同位角、4 对内错角、4 对同旁内角。

算法：两条不同的截线各自与两条平行线相交，各自形成一个独立的三线八角图形。每一条截线都截出 4 对同位角，两条截线就贡献 4 + 4 = 8 对同位角；同理，内错角是 2 + 2 = 4 对，同旁内角也是 2 + 2 = 4 对。

说明：两条截线不同，它们与平行线的交点就不同，所以两批角互不重合，可以直接相加。这里只统计“以这两条截线为截线”的角对；如果把 a 或 b 也当作截线，还会出现别的角对，本题不作要求。这个例子告诉我们，遇到“多条截线”的图形，应当先把它拆成几个独立的三线八角图形，逐个处理，再合起来计数；千万不要把不同截线截出的角硬凑成一对，那样得到的名称一定是错的。

易错：（1）把“同位角”与“对顶角”“邻补角”混为一谈。对顶角、邻补角是由两条直线相交形成的，一定有公共顶点；同位角、内错角、同旁内角是由三条直线形成的，两个角的顶点通常不同（只有在两条被截线相交时才会重合）。（2）不看截线就下结论。同一个角与不同的角配对，名称可能完全不同，所以判断前必须先指明截线。（3）认为同位角一定相等。名称只描述位置，同位角可以相等，也可以不相等；只有“两条直线平行”时，同位角才相等（这是下一节要学的内容）。（4）把“同旁内角互补”说成“同旁内角相等”。同旁内角在判定中的用法是“互补”，即和为 180°，不是相等。
本课时小结：三线八角的识图，说到底是两个问题——在截线的同侧还是两侧，在两条被截线的同方还是之间。把这两个问题问清楚，名称自然出来；把截线找准，位置才问得对。

第 2 课时利用同位角判定两直线平行

上一课时我们把 8 个角分了类，但还没有回答一个更基本的问题：怎样判断两条直线平行？

靠眼睛看是不行的。在纸上画两条看起来“很平行”的直线，把它们延长到纸外，也许就在某处相交了。靠“延长后不相交”也不行，因为直线可以无限延长，我们永远看不到尽头。所以必须找一个在有限范围内就能检查的条件——角的大小关系正好合适：角可以量，可以画，可以比较。

1. 做一做：用三角板和直尺画平行线

先回忆小学里画平行线的方法。手边有一块三角板和一把直尺，按下面四步操作，就能过直线 a 外一点 P 画出 a 的平行线，如图 8（c）所示。

一贴：把三角板的一条边（通常用直角边）贴在已知直线 a 上。二靠：把直尺紧靠在三角板的另一条边上，按住直尺不动。三推：沿着直尺推动三角板，一直推到三角板原来贴住 a 的那条边经过点 P。四画：沿这条边过点 P 画直线 b，那么 b 就是所求的平行线。

为什么这样画出来的 b 一定与 a 平行？关键在“推”的过程中三角板没有转动。把直尺边缘所在的直线记作 l，它相当于一条截线，a 与 b 是被截线。第一次位置时，三角板贴 a 的那条边与直尺边缘的夹角，就是 a 与 l 形成的角；推动之后，三角板只是平移，形状和方向都没变，所以贴 b 的那条边与直尺边缘的夹角与原来完全相同。这两个角都在 l 的同一侧，又都在各自被截线的同一方，是一对同位角，而且它们相等。于是可以断定 b∥a。

反过来想：如果推动时手一歪，三角板转了一点，那么这个夹角就变了，画出的直线与 a 被 l 所截得到的同位角不再相等，也就不能保证平行。可见“同位角相等”正是平行与否的分界线。

2. 基本事实：同位角相等，两直线平行

把上面的操作抽象成一句话，就得到本节最重要的一条结论。如图 8（a），直线 a、b 被直线 c 所截，∠1 与 ∠2 是同位角。用三角板画图、用量角器度量、用叠合的方法比较，都会得到同一个结果：只要 ∠1 = ∠2，画出的 a 与 b 就永远不相交，也就是 a∥b。

基本事实（判定方法一）
两条直线被第三条直线所截，如果同位角相等，那么这两条直线平行。简单说成：同位角相等，两直线平行。

符号语言是：因为 ∠1 = ∠2（已知），且 ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角，所以 a∥b（同位角相等，两直线平行）。写推理时，“∠1 与 ∠2 是同位角”这个身份一定要交代清楚，否则别人无法核对条件是否用对。

之所以把它叫做“基本事实”，是因为它不能由更简单的结论推出来，而是人们在长期画图、测量中反复验证后公认的出发点。数学中这样的出发点还有“两点确定一条直线”“两点之间线段最短”等。基本事实可以直接作为推理的依据使用。

使用这条判定时，有两个条件必须同时满足：两个角是同位角，并且这两个角相等。少一个都不行。如果两个角相等却不是同位角，或者两个角是同位角却不相等，都得不出平行的结论。

3. 平行公理与它的推论

画平行线的过程中，还有一个事实值得注意：过直线 a 外一点 P，无论怎么画，画出的平行线都只有一条。也就是说，过直线外一点画已知直线的平行线，能画并且只能画一条。这条结论叫做平行公理。

平行公理
过直线外一点，有且只有一条直线与这条直线平行。

由平行公理还能得到一个常用的推论：如果两条直线都与第三条直线平行，那么这两条直线也互相平行。简单说成：平行于同一条直线的两条直线平行。

这个推论可以说理。已知 b∥a，c∥a，要说明 b∥c。假设 b 与 c 不平行，那么它们一定相交，设交点为 P。因为 b∥a，所以点 P 不在直线 a 上（否则 b 与 a 就相交于 P 了）；同理 c∥a，点 P 也不在 a 上。这样，过直线 a 外的点 P 就有了两条直线 b、c 都与 a 平行，这与平行公理“有且只有一条”矛盾。矛盾说明假设不成立，所以 b∥c。

推论的符号语言：因为 b∥a，c∥a，所以 b∥c（平行于同一条直线的两条直线平行）。它常常用在“接力”式的推理中：先证出两条直线各自与第三条直线平行，再一步到位得到它们互相平行。

例 1 直接使用同位角相等判定平行

如图 8（a），直线 a、b 被直线 c 所截，∠1 与 ∠2 是同位角，且 ∠1 = 60°，∠2 = 60°。判断直线 a 与 b 是否平行，并说明理由。

解

a∥b。

理由：因为 ∠1 = 60°，∠2 = 60°，所以 ∠1 = ∠2。又因为 ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角，根据“同位角相等，两直线平行”，可得 a∥b。

写推理时按“∵……∴……”的格式：∵ ∠1 = 60°，∠2 = 60°，∴ ∠1 = ∠2；∵ ∠1 与 ∠2 是同位角，∴ a∥b（同位角相等，两直线平行）。

变式：如图 8（a），若 ∠1 = 60°，∠2 = 120°，能否判断 a∥b？答案：不能。∠1 与 ∠2 的位置关系虽然是同位角，但它们的度数不相等，不满足“同位角相等”这个条件，所以不能判定 a∥b。

例 2 先用邻补角转化，再用同位角判定

如图 8（b），直线 a、b 被直线 c 所截，∠1 与 ∠2 是邻补角，∠3 与 ∠2 是同位角，且 ∠1 = 70°，∠3 = 110°。判断直线 a 与 b 是否平行，并说明理由。

解

a∥b。

先求 ∠2。因为 ∠1 与 ∠2 是邻补角，所以 ∠1 + ∠2 = 180°。又 ∠1 = 70°，所以 ∠2 = 180° − 70° = 110°。

再比较 ∠2 与 ∠3。由上面的计算得 ∠2 = 110°，而已知 ∠3 = 110°，所以 ∠2 = ∠3。

最后判定。因为 ∠2 与 ∠3 是直线 a、b 被直线 c 所截得到的同位角，且 ∠2 = ∠3，所以 a∥b（同位角相等，两直线平行）。

这个例子说明：题目给出的角，不一定正好是判定所需的同位角。当已知条件“不对口”时，可以先用对顶角相等、邻补角互补把角“搬”到需要的位置上，再作判断。转化的目标很明确——凑出一对相等的同位角。

变式：如图 8（b），若 ∠1 = 100°，∠3 = 80°，判断 a 与 b 是否平行。答案：平行。因为 ∠2 = 180° − 100° = 80°（邻补角互补），所以 ∠2 = ∠3 = 80°，又 ∠2 与 ∠3 是同位角，故 a∥b。

例 3 画图与说理：过直线外一点画平行线

如图 8（c），已知直线 a 和直线 a 外一点 P。过点 P 画直线 a 的平行线，写出画法，并说明“为什么画出的直线与 a 平行”。

解

作法：① 一贴，把三角板的一条直角边贴在直线 a 上；② 二靠，把直尺紧靠在三角板的另一条直角边上，按住直尺不动；③ 三推，沿直尺推动三角板，直到贴在 a 上的那条边经过点 P；④ 四画，沿这条边过点 P 画直线 b，则 b∥a。

道理：设直尺边缘所在的直线为 l。在推动三角板的过程中，三角板只沿 l 平移，没有转动，所以三角板贴在 a 上的边与 l 的夹角保持不变。画出 b 以后，b 与 l 的夹角等于 a 与 l 的夹角。把 l 看成截线，a、b 看成被截线，这两个角在 l 的同一侧，又都在各自被截线的同一方，是一对同位角，并且它们相等。由“同位角相等，两直线平行”，得 b∥a。

补充：由平行公理可知，过点 P 与 a 平行的直线只有这一条，所以这样画出的 b 就是唯一的答案。

变式：过直线 a 外一点 P 画 a 的平行线，能画几条？为什么？答案：只能画 1 条。由平行公理“过直线外一点，有且只有一条直线与这条直线平行”可知，这样的直线存在且唯一。

4. 用同位角判定平行的书写格式

判定的结论虽然只有一句话，写起来却要交代三件事：哪两个角相等、这两个角是什么角、用的是哪条依据。缺一件，推理就有漏洞。下面先给出规范写法，再列出三种常见的毛病。

方法归纳：
  • 第一步，找角：在图上确定要用的两个角，看清它们分别由哪两条直线相交形成。
  • 第二步，说关系：说明这两个角是“直线 a、b 被直线 c 所截得到的同位角”。
  • 第三步，摆条件：写出这两个角的度数相等（或由已知、由邻补角、由对顶角推出相等）。
  • 第四步，下结论：写出 a∥b，并在括号里注明依据“同位角相等，两直线平行”。

规范写法：∵ ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角，且 ∠1 = ∠2，∴ a∥b（同位角相等，两直线平行）。

不规范写法有三种：只写“∵ ∠1 = ∠2，∴ a∥b”，没交代同位角，条件与结论之间缺了一环；写成“∵ a∥b，∴ ∠1 = ∠2”，方向反了，那是性质不是判定；写成“∵ ∠1 = ∠2，∴ a∥b（两直线平行，同位角相等）”，括号里的依据与推理方向自相矛盾。这三种毛病在作业里很常见，写完不妨对照检查一遍。

还要提醒一点：判定平行时，只要有一对同位角相等就够了，不需要把所有角都量一遍。反过来，如果量出某一对同位角不相等，那么这两条直线一定不平行。后一句话是前一句话的逆否命题，两者说的是同一件事，所以它也可以作为判断的依据使用。

5. 练习：判定与说理

1 【基础】如图 8（a），∠1 与 ∠2 是同位角，∠1 = 132°，∠2 = 132°。判断 a 与 b 是否平行，并写出推理过程。
答案与解析

a∥b。

推理：∵ ∠1 = 132°，∠2 = 132°，∴ ∠1 = ∠2。∵ ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角，∴ a∥b（同位角相等，两直线平行）。

注意：写依据时要写“同位角相等，两直线平行”，不能只写“所以平行”，也不能把依据写成“两直线平行，同位角相等”——那是下一节要学的性质，方向正好相反。

2 【基础】用三角板和直尺画平行线分哪四步？为什么这样画出的直线一定与已知直线平行？
答案与解析

四步是：一贴（三角板一边贴住已知直线）、二靠（直尺紧靠三角板另一边）、三推（沿直尺推动三角板）、四画（沿贴过已知直线的那条边画线）。

道理：把直尺边缘所在的直线看成截线。推动过程中三角板只平移不转动，所以三角板与直尺边缘的夹角始终不变；画出的直线与已知直线被这条截线所截，形成的两个角在同侧同方，是一对相等的同位角。由“同位角相等，两直线平行”，画出的直线与已知直线平行。

3 【提升】如图 8（b），∠1 与 ∠2 是邻补角，∠3 与 ∠2 是同位角，∠1 = 75°，∠3 = 105°。判断 a 与 b 是否平行，并写出完整的推理过程。
答案与解析

a∥b。

∵ ∠1 与 ∠2 是邻补角，∴ ∠1 + ∠2 = 180°。∵ ∠1 = 75°，∴ ∠2 = 180° − 75° = 105°。

∵ ∠3 = 105°，∴ ∠2 = ∠3。

∵ ∠2 与 ∠3 是直线 a、b 被直线 c 所截得到的同位角，且 ∠2 = ∠3，∴ a∥b（同位角相等，两直线平行）。

易错提醒：不能由“∠1 与 ∠3 度数不同”直接下结论，也不能把邻补角的关系写成“∠1 = ∠2”。邻补角是互补关系，不是相等关系。

4 【提升】在同一平面内，已知 a∥b，b∥c。a 与 c 是什么位置关系？请说明理由。
答案与解析

a∥c，即 a 与 c 也互相平行。

理由（用平行公理说明）：假设 a 与 c 不平行，那么它们相交，设交点为 P。因为 a∥b，所以点 P 不在直线 b 上；又 c∥b，所以过直线 b 外的点 P 有两条直线 a、c 都与 b 平行，这与平行公理“过直线外一点，有且只有一条直线与这条直线平行”矛盾。所以假设不成立，a∥c。

也可以直接引用推论：如果两条直线都与第三条直线平行，那么这两条直线也互相平行。符号语言：∵ a∥b，b∥c，∴ a∥c。

5 【拓展】如图 8（c），用三角板推平行线时，如果推到一半手一歪，三角板绕接触点转动了一个小角度，画出的直线还与 a 平行吗？为什么？
答案与解析

不一定平行，一般就不平行了。

原因：画出的直线与 a 是否平行，取决于它们被直尺边缘所在直线所截得到的同位角是否相等。三角板一旦转动，贴在 a 上的那条边与直尺边缘的夹角就改变了，画出的直线与直尺边缘的夹角也跟着改变，两个同位角不再相等。由“同位角相等，两直线平行”可知，此时不能保证平行；实际上，画出的直线会与 a 相交。

这个例子从反面说明：画平行线的要害是“推的过程中方向不变”，也就是保持同位角不变。

易错：（1）把判定与性质的方向弄反。本节学的是“由角推线”：同位角相等推出两直线平行；而“由线推角”的“两直线平行，同位角相等”是下一节的性质，不能拿来当本节的依据。（2）条件不全就下结论。只知道两个角相等，还要确认它们确实是同位角；只知道是同位角，还要确认它们相等。（3）把平行公理说成“过一点有且只有一条直线与已知直线平行”。少了“直线外”三个字就错了：如果这个点在已知直线上，过它画不出与已知直线平行的直线。（4）认为“看起来平行”就能判定平行。图形是示意，判断必须靠条件。

第 3 课时利用内错角、同旁内角判定两直线平行

已经知道：同位角相等，两直线平行。那么，如果题目给的不是同位角，而是内错角或同旁内角，还能判定两条直线平行吗？

答案是肯定的，而且办法很朴素：把内错角、同旁内角“变”成同位角，再用上一课时的基本事实。变形的工具，就是上一节学过的对顶角相等和邻补角互补。

1. 内错角相等，两直线平行

如图 9，直线 AB、CD 被直线 EF 所截，∠1 与 ∠2 是内错角。设 ∠1 = ∠2，要说明 AB∥CD。

观察图形：∠1 在交点处有一个对顶角，记作 ∠3。由“对顶角相等”得 ∠3 = ∠1；又已知 ∠1 = ∠2，所以 ∠3 = ∠2。而 ∠3 与 ∠2 的位置正好是“截线同侧、被截线同方”，它们是一对同位角。于是由“同位角相等，两直线平行”得 AB∥CD。

把这段推理压缩成一句话，就是下面的判定方法二。

判定方法二
两条直线被第三条直线所截，如果内错角相等，那么这两条直线平行。简单说成：内错角相等，两直线平行。

符号语言：因为 ∠1 = ∠2，且 ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的内错角，所以 AB∥CD（内错角相等，两直线平行）。

要注意的是，这个判定并不是新的“基本事实”，它可以由基本事实推出来。但在解题时，它可以像基本事实一样直接引用，不必每次都把“对顶角—同位角”的转化过程写一遍。当然，如果题目要求“说明理由”，就要把转化的链条写清楚。

2. 同旁内角互补，两直线平行

如图 10（a），直线 AB、CD 被直线 EF 所截，∠1 与 ∠2 是同旁内角。设 ∠1 + ∠2 = 180°，要说明 AB∥CD。

把 ∠1 的邻补角记作 ∠3。由“邻补角互补”得 ∠1 + ∠3 = 180°；又已知 ∠1 + ∠2 = 180°，比较两式可得 ∠3 = ∠2（同角的补角相等）。而 ∠3 与 ∠2 分居截线两侧、都在两条被截线之间，是一对内错角。由判定方法二，得 AB∥CD。

也可以从对顶角入手：把 ∠1 的对顶角记作 ∠4，则 ∠4 = ∠1，于是 ∠4 + ∠2 = 180°。但 ∠4 在两条被截线之外，与 ∠2 不是同旁内角，不能直接用判定方法三；还要再转化一次，反而多绕一步。所以用邻补角把同旁内角的问题化成内错角的问题，是最省事的做法。

判定方法三
两条直线被第三条直线所截，如果同旁内角互补，那么这两条直线平行。简单说成：同旁内角互补，两直线平行。

符号语言：因为 ∠1 + ∠2 = 180°，且 ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的同旁内角，所以 AB∥CD（同旁内角互补，两直线平行）。

3. 判定方法怎么选

三条判定方法摆在一起，做题时怎样选？看题目给的“角的关系”是什么形状：

方法归纳：
  • 已知两个角相等，先看它们是不是同位角或内错角。是，就直接判定；不是，就用对顶角、邻补角把角搬到同位角或内错角的位置上。
  • 已知两个角互补（和为 180°），先看它们是不是同旁内角。是，就直接判定；不是，就先把其中一个角换成它的邻补角或对顶角，凑成同旁内角。
  • 题目里出现“两条直线被第三条直线所截”以外的图形（例如有两条截线），要先把图形拆成几个三线八角，再逐个处理。
  • 写推理时，每一步都要交代“这两个角是什么角”，最后一步写清用的是哪条判定方法。

解

AB∥CD。

∵ ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的内错角，且 ∠1 = ∠2，∴ AB∥CD（内错角相等，两直线平行）。

如果需要说明这条判定方法的由来，可以补上转化的过程：设 ∠1 的对顶角为 ∠3，则 ∠3 = ∠1（对顶角相等），所以 ∠3 = ∠2；而 ∠3 与 ∠2 是同位角，由“同位角相等，两直线平行”得 AB∥CD。两条路殊途同归，结论一致。

变式：如图 9，若 ∠1 = ∠2 = 90°，AB 与 CD 还平行吗？答案：平行。内错角相等这一条件仍然成立，所以 AB∥CD；此时 AB 与 CD 都垂直于 EF。

例 2 由同旁内角互补判定平行

如图 10（a），直线 AB、CD 被直线 EF 所截，∠1 与 ∠2 是同旁内角，且 ∠1 + ∠2 = 180°。判断 AB 与 CD 是否平行，并说明理由。

解

AB∥CD。

∵ ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的同旁内角，且 ∠1 + ∠2 = 180°，∴ AB∥CD（同旁内角互补，两直线平行）。

若要写清道理：设 ∠1 的邻补角为 ∠3，则 ∠1 + ∠3 = 180°（邻补角互补）。又 ∠1 + ∠2 = 180°，所以 ∠3 = ∠2（同角的补角相等）。而 ∠3 与 ∠2 是内错角，由“内错角相等，两直线平行”得 AB∥CD。

比较例 1 与例 2 可以看到：内错角用“相等”，同旁内角用“互补”，这是两种不同的数量关系，千万不能张冠李戴。

变式：如图 10（a），若 ∠1 = 90°，∠2 = 90°，AB 与 CD 平行吗？答案：平行。因为 ∠1 + ∠2 = 180°，两个角是同旁内角，由“同旁内角互补，两直线平行”得 AB∥CD。

例 3 综合：判定与求角

如图 10（b），直线 a、b 被直线 c 所截，直线 c、d 都与 a、b 相交。已知 ∠1 = ∠2，∠3 = 110°，求 ∠4 的度数，并判断图中哪两条直线平行。

解

（1）判断平行的直线。∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的内错角，且 ∠1 = ∠2，所以 a∥b（内错角相等，两直线平行）。

（2）求 ∠4。∠3 与 ∠4 是直线 a、b 被直线 d 所截得到的同旁内角。因为 a∥b，所以 ∠3 + ∠4 = 180°，于是 ∠4 = 180° − 110° = 70°。

（3）说明。第（1）问用的是判定：由“角相等”推出“线平行”；第（2）问用的是性质：由“线平行”推出“同旁内角互补”。这里用到的“两直线平行，同旁内角互补”是下一节要正式学习的性质，本节先借用它来求角。两件事方向相反，写作业时要分清：判断平行写“内错角相等，两直线平行”，求角写“两直线平行，同旁内角互补”。

（4）答：∠4 = 70°，图中 a∥b。

变式：如图 10（b），若 ∠1 = ∠2，∠3 = 100°，求 ∠4。答案：由 ∠1 = ∠2 得 a∥b；由 a∥b 得 ∠3 与 ∠4 是同旁内角，∠3 + ∠4 = 180°，所以 ∠4 = 180° − 100° = 80°。

4. 练习：判定方法的选择与运用

1 【基础】如图 9，∠1 与 ∠2 是内错角，∠1 = ∠2。判断 AB 与 CD 是否平行，并写出推理过程。
答案与解析

AB∥CD。

∵ ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的内错角，且 ∠1 = ∠2，∴ AB∥CD（内错角相等，两直线平行）。

注意：这里的两个角必须是“内错角”。如果换成一对外部同侧的角，即使相等也推不出平行。

2 【基础】如图 10（a），∠1 与 ∠2 是同旁内角，∠1 = 68°，∠2 = 112°。判断 AB 与 CD 是否平行，并说明理由。
答案与解析

AB∥CD。

∵ ∠1 = 68°，∠2 = 112°，∴ ∠1 + ∠2 = 68° + 112° = 180°。

∵ ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的同旁内角，且 ∠1 + ∠2 = 180°，∴ AB∥CD（同旁内角互补，两直线平行）。

提示：这类题先算和，再看和是不是 180°。如果两个同旁内角的和不是 180°，就不能判定平行。

3 【提升】如图 9，∠1 的邻补角是 125°，且 ∠1 = ∠2。（1）求 ∠1 的度数；（2）判断 AB 与 CD 是否平行，并说明理由。
答案与解析

（1）∵ ∠1 与它的邻补角的和为 180°，∴ ∠1 = 180° − 125° = 55°。

（2）AB∥CD。∵ ∠1 = ∠2，且 ∠1 = 55°，∴ ∠2 = 55°。又 ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的内错角，∠1 = ∠2，∴ AB∥CD（内错角相等，两直线平行）。

说明：求 ∠1 用的是邻补角互补，判定平行用的是内错角相等，两步依据不同，要分别写清。

4 【提升】如图 10（b），已知 ∠1 = ∠2。（1）判断 a 与 b 是否平行；（2）若同时有 ∠1 = ∠3，图中还有哪两条直线平行？为什么？
答案与解析

（1）a∥b。∵ ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的内错角，且 ∠1 = ∠2，∴ a∥b（内错角相等，两直线平行）。

（2）c∥d。把直线 a 看成截线，直线 c、d 看成被截线：∠1 在 a 的下方、c 的左侧，∠3 在 a 的下方、d 的左侧，两个角在截线 a 的同侧，又在各自被截线的同一侧，位置相同，是一对同位角（把图形横过来看，正好是一个“F”形）。因为 ∠1 = ∠3，所以由“同位角相等，两直线平行”得 c∥d。

这个小题说明：同一条直线，在不同的“三线”组合里可以扮演不同角色。判断前一定要先说清楚“以谁为截线、以谁为被截线”。

5 【拓展】工人师傅检查一块木板的两条边缘 a、b 是否平行。他量得 ∠1 = 65°，∠2 = 115°，并确认 ∠1 与 ∠2 是同旁内角，于是判断两条边缘平行。（1）他的判断对吗？（2）如果他量得 ∠2 = 114°，还能判断平行吗？为什么？
答案与解析

（1）对。∵ ∠1 = 65°，∠2 = 115°，∴ ∠1 + ∠2 = 180°。∵ ∠1 与 ∠2 是同旁内角，∴ a∥b（同旁内角互补，两直线平行）。

（2）不能。此时 ∠1 + ∠2 = 65° + 114° = 179°，两个同旁内角不互补，不满足“同旁内角互补”这一条件，所以不能判定 a∥b。量角时出现 1° 的误差很常见，正因为如此，判断平行必须严格按条件核对，不能“差不多就行”。

答：（1）他的判断正确；（2）若 ∠2 = 114°，不能判断两条边缘平行。

易错：（1）把“内错角相等”与“同旁内角互补”记混，写成“同旁内角相等，两直线平行”。正确的说法是：同位角相等、内错角相等、同旁内角互补，三种情况都能判定平行。（2）只写结论不写依据。判定题必须写清“这两个角是什么角”，否则别人无法判断条件是否用对。（3）把判定与性质混用。判断平行用判定（角推线），已知平行求角用性质（线推角），两者方向相反，不能互换。（4）在两条截线的图形中张冠李戴。不同截线截出的角不能配成一对，必须先分组。
本节知识网络：
  • 三条直线两两相交（其中两条平行或待判定），形成“三线八角”：截线、被截线，8 个角。
  • 三类角：同位角（截线同侧、被截线同方，F 形，4 对）；内错角（截线两侧、被截线之间，Z 形，2 对）；同旁内角（截线同侧、被截线之间，U 形，2 对）。
  • 识图三步法：找截线 → 定内外 → 看同侧还是两侧 → 对号入座。
  • 判定方法一：同位角相等，两直线平行（基本事实）。
  • 判定方法二：内错角相等，两直线平行（由对顶角转化为同位角得到）。
  • 判定方法三：同旁内角互补，两直线平行（由邻补角转化为内错角得到）。
  • 平行公理：过直线外一点，有且只有一条直线与这条直线平行；推论：平行于同一条直线的两条直线平行。
  • 画平行线：一贴、二靠、三推、四画；道理是推动过程中同位角保持不变。
  • 思想方法：把“角的关系”与“线的位置关系”互相转化；条件不对口时，用对顶角、邻补角做“搬运工”；遇到多条截线，先拆成几个三线八角再处理。
第 3 节 · 建议 2 课时

平行线的性质

木工检查窗框上下的两根横档是否平行，常把一根斜木条搭上去，量一量斜木条与两根横档所成的角；铁路上两条钢轨平行，斜穿而过的钢轨与它们也成出一组组有规律的角。上一节做的是“由角看线”：用角的大小关系判定两条直线平行。这一节把箭头掉转过来，做“由线看角”：已知两条直线平行，看能推出哪些角的关系。这样得到的结论叫做平行线的性质，它与判定互为逆过程。方向一旦用反，整段推理就会失效，所以这一节既要会算，更要说清每一步的依据。

学习目标

  • 经历画平行线、作截线、量角、比较的操作过程，归纳出平行线的三条性质，体会“由特殊到一般”的归纳方法。
  • 掌握“两直线平行，同位角相等”“两直线平行，内错角相等”“两直线平行，同旁内角互补”，能用文字语言、图形语言、符号语言三种方式表述。
  • 能分清平行线的判定与性质：判定是“由角推线”，性质是“由线推角”，会在推理中正确选用并注明依据。
  • 能综合运用判定与性质进行两步以上的推理与计算，会过拐点作平行线解决“拐点”问题。
  • 会用平行线的性质解决拐弯、方向角等简单实际问题，养成“先定截线、再认角、后写依据”的习惯。

第 1 课时平行线的性质

先动手做一次。在纸上画一条直线 a，把三角板的一条直角边贴在 a 上，用直尺紧靠三角板的另一条边，沿直尺推动三角板，再沿贴住 a 的那条边画一条直线 b。推动的过程中三角板没有转动，所以画出的 b 与 a 平行。这时 a∥b 是“看得见”的：两条线处处一样宽，无论怎样延长都不会相交。

接着在纸上任意画一条直线 c，使它分别与 a、b 相交，于是一共出现 8 个角。用量角器把这 8 个角都量出来，把数据记下来；再换一个位置画 c、换一个倾斜程度画 c，重复几次。数据会呈现出非常整齐的规律：位于相同位置的两个角总是一样大；夹在 a、b 之间、分居 c 两侧的两个角也总是一样大；夹在 a、b 之间、同在 c 一侧的两个角加起来总是 180°。换纸、换尺、换人量，结论都不变。

这不是巧合。两条直线平行，意味着其中一条可以由另一条沿着截线的方向平移得到；平移不改变图形的大小和形状，也就不改变角的大小。所以只要 a∥b，同位角就相等。把这个发现写成结论，就得到平行线的三条性质。要强调的是：这三条性质的前提都是“两直线平行”，没有这个前提，同位角、内错角、同旁内角之间的大小关系一概不成立。

1. 性质一：两直线平行，同位角相等

文字语言：两条平行线被第三条直线所截，同位角相等。习惯上简记为“两直线平行，同位角相等”。

图形语言：如图 11，直线 a∥b，直线 c 与 a、b 分别交于点 P、Q，∠1 与 ∠2 是同位角，那么 ∠1 = ∠2。

符号语言：∵ a∥b，∴ ∠1 = ∠2（两直线平行，同位角相等）。

写符号语言时，括号里的依据不能省。它既是推理的“身份证”，也是检查自己有没有用错方向的凭据。另外，“两直线平行”是条件，“同位角相等”是结论，前后顺序不能调换。

这条性质为什么成立？可以这样想：把直线 a 连同 ∠1 沿着 c 的方向平移到 b 的位置。因为 a∥b，平移之后 a 与 b 重合，∠1 的两条边与 ∠2 的两条边也分别重合，所以 ∠1 = ∠2。平移是“图形运动”观点的雏形，现在先借助它理解结论的合理性，等到九年级学图形变换时还会有更完整的说法。

平行线的性质一
两直线平行，同位角相等。∵ a∥b，∴ ∠1 = ∠2。

2. 性质二：两直线平行，内错角相等

内错角相等可以由性质一推出来。仍看图 11，∠1 与 ∠3 是内错角，推理如下：

∵ a∥b，∴ ∠1 = ∠2（两直线平行，同位角相等）。

∵ ∠2 与 ∠3 是对顶角，∴ ∠2 = ∠3（对顶角相等）。

∴ ∠1 = ∠3（等量代换）。

于是得到：两直线平行，内错角相等。这段推理值得反复看：它把“平行”这个条件先用一次，得到同位角相等；再用对顶角把角“搬”到需要的位置；最后用等量代换收尾。以后遇到“条件不对口”的图形，靠的就是对顶角、邻补角这类“搬运工”，把角挪到能用性质的地方。

平行线的性质二
两直线平行，内错角相等。∵ a∥b，∴ ∠1 = ∠3。

3. 性质三：两直线平行，同旁内角互补

同旁内角互补同样可以推出来。图 11 中 ∠1 与 ∠4 是同旁内角：

∵ a∥b，∴ ∠1 = ∠2（两直线平行，同位角相等）。

∵ ∠2 与 ∠4 是邻补角，∴ ∠2 + ∠4 = 180°（邻补角互补）。

∴ ∠1 + ∠4 = 180°（等量代换）。

于是得到：两直线平行，同旁内角互补。这里再次出现“搬运”：先用性质一得到 ∠1 = ∠2，再用邻补角把 ∠2 换成与 ∠4 互补的角，于是 ∠1 与 ∠4 的和为 180°。三条性质中，只有这一条是“互补”而不是“相等”，计算时最容易写错。

平行线的性质三
两直线平行，同旁内角互补。∵ a∥b，∴ ∠1 + ∠4 = 180°。
要点：平行线的三条性质都是“由线推角”。条件只有一个——两条直线平行；结论有三个——同位角相等、内错角相等、同旁内角互补。三条性质中前两条给出相等关系，第三条给出互补关系，用的时候先认清是哪一类角，再选对应的结论。

三条性质可以看成同一个事实的三张面孔。性质一最根本，它直接来自“平移不改变角的大小”；性质二、性质三则是用性质一加上对顶角、邻补角的性质“加工”出来的。所以做题时如果一时忘了性质二、性质三，完全可以现场推一遍：先由平行得到同位角相等，再看目标角与这个同位角是对顶角还是邻补角，是邻补角就补成 180°。会推，比会背更可靠。

另外要留一个心眼：性质三说的是“互补”，不是“相等”。同旁内角之所以特殊，是因为它们夹在两条平行线之间、又同在截线的一侧，两条边正好凑成一个平角。把它和邻补角区分开：邻补角有一条公共边、另一边互为反向延长线，两个角的顶点相同；同旁内角的两个角顶点不同，分别在两条平行线上。

图 11 把三条性质涉及的角画在了一起，做题时可以对照它辨认：∠1 与 ∠2 位于截线 c 的同一侧、两条平行线的同方，是同位角；∠1 与 ∠3 夹在 a、b 之间、分居 c 的两侧，是内错角；∠1 与 ∠4 夹在 a、b 之间、同在 c 的左侧，是同旁内角。

4. 性质与判定的方向之别

把两条结论并排放在一起看：

判定：∵ ∠1 = ∠2，∴ a∥b（同位角相等，两直线平行）。

性质：∵ a∥b，∴ ∠1 = ∠2（两直线平行，同位角相等）。

两句话的字面几乎一样，但已知和结论正好互换。判定解决的是“怎样说明两条直线平行”，性质解决的是“已知平行能推出什么”。做题时先问自己一句：题目给的是“线”还是“角”？给了角的关系、要说明平行，用判定；给了平行、要求角或说明角的关系，用性质。

还有一处细节容易忽略：判定里的依据写“同位角相等，两直线平行”，性质里的依据写“两直线平行，同位角相等”。这两句话的顺序恰好相反，抄写时如果只凭印象，很容易把前四个字和后四个字颠倒，导致依据与结论对不上。

方法归纳：
  • 看条件：已知“平行”，走性质；已知“角相等或互补”，走判定。
  • 看结论：结论落在“角”上，多半用性质；结论落在“线”上，多半用判定。
  • 看角名：相等关系对同位角、内错角；互补关系只对同旁内角。
  • 写依据：括号里先写条件、再写结论，与推理方向保持一致。

5. 推理的书写格式

规范的推理要写全三样东西：条件（∵）、结论（∴）、依据（括号）。多步推理时，每一步都要单独交代依据，不能只在最后写一次；等量代换、对顶角相等、邻补角互补这些“过渡性”的依据也要写出来。

举一个完整的例子：已知 a∥b，∠1 = 65°，求 ∠4。写法是：∵ a∥b，∴ ∠1 + ∠4 = 180°（两直线平行，同旁内角互补），∴ ∠4 = 180° − 65° = 115°。三行，条件、依据、结论齐全。

如果题目要求“说明理由”，就不能只写答案；如果题目只要求“求度数”，也要在过程中留下依据，否则一旦算错，别人无法判断错在哪一步。阅卷时常见的扣分点，往往不是答案错，而是依据漏写或写反。

对比两种写法。写法一：因为 a∥b，所以 ∠4 = 115°。写法二：∵ a∥b，∴ ∠1 + ∠4 = 180°（两直线平行，同旁内角互补），∴ ∠4 = 180° − 65° = 115°。写法一只给了结果，读者不知道 115° 是怎么来的；写法二把条件、依据、算式都摆了出来，即使中间算错，也能一眼看出错在哪一步。考试中“写出推理过程”的要求，说的就是写法二。

还有一个细节：角的编号要在图上标清楚。同一个字母在不同的三线组合里可能指不同的角，写依据时最好把“哪两条直线被哪条直线所截”一并说清，例如“∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角”。这样即使图上编号有歧义，依据也不会含糊。

易错：（1）丢掉前提，直接写“同位角相等”。同位角只表示位置关系，只有两条被截线平行时才相等。（2）把“同旁内角互补”写成“同旁内角相等”。三条性质中只有前两条是相等，第三条是互补。（3）判定与性质颠倒，已知平行却去用判定。（4）依据只写“平行”两个字，没写清是哪两条直线平行、用的是什么角。（5）算出 ∠4 = 115° 后又顺手写成 ∠3 = 115°，把邻补角与同旁内角混为一谈。

6. 例题

例 1 用三条性质求角

如图 11，直线 a∥b，直线 c 与 a、b 分别交于点 P、Q，∠1 = 65°。求 ∠2、∠3、∠4 的度数。

解

∵ a∥b，∴ ∠2 = ∠1 = 65°（两直线平行，同位角相等）。

∵ a∥b，∴ ∠3 = ∠1 = 65°（两直线平行，内错角相等）。

∵ a∥b，∴ ∠1 + ∠4 = 180°（两直线平行，同旁内角互补），∴ ∠4 = 180° − 65° = 115°。

答：∠2 = 65°，∠3 = 65°，∠4 = 115°。

检验：∠3 与 ∠4 是邻补角，65° + 115° = 180°，与“邻补角互补”相符，说明结果自洽。做题时养成这种回头检查的习惯，可以挡住大部分计算错误。

变式：如图 11，a∥b，若 ∠4 = 2∠1 + 30°，求 ∠1 与 ∠4 的度数。（提示：由“两直线平行，同旁内角互补”得 ∠1 + ∠4 = 180°，列方程解得 ∠1 = 50°，∠4 = 130°。）

例 2 性质与对顶角配合

如图 12，AB∥CD，∠A = 40°。（1）求 ∠C 的度数；（2）若 ∠1 与 ∠A 是对顶角，求 ∠1 的度数。

解

（1）∵ AB∥CD，∴ ∠C = ∠A = 40°（两直线平行，内错角相等）。

（2）∵ ∠1 与 ∠A 是对顶角，∴ ∠1 = ∠A = 40°（对顶角相等）。

答：∠C = 40°，∠1 = 40°。

说明：∠A 与 ∠C 是直线 AB、CD 被直线 AC 所截得到的内错角，这里的截线是 AC，不是 AB，也不是 CD。识图时先定截线，再判断两个角在截线的同侧还是两侧、在被截线之间还是同方，名称才不会认错。第（2）问与平行无关，用的是对顶角的性质，两步的依据完全不同，要分别写清。

变式：如图 12，AB∥CD，若 ∠1 与 ∠A 是邻补角，且 ∠A = 40°，求 ∠1 的度数，并说明 ∠1 与 ∠C 有什么关系。（∠1 = 140°；∠1 + ∠C = 180°。）

再回答：把（1）的条件与结论互换，得到的命题是什么？它属于判定还是性质？

（2）两直线平行，内错角相等。

（3）两直线平行，同旁内角互补。

变式：把例 3 的（3）改为“∵ a∥b，∴ ∠2 + ∠3 = 180°”，括号内应填什么？先想一想 ∠2 与 ∠3 在图 11 中是什么角，再判断这句话是否正确。（∠2 与 ∠3 是对顶角，它们相等而不一定互补，所以这句话在一般情况下不成立；只有当 ∠2 = ∠3 = 90° 时才成立。这也说明：写依据之前，先认清角的位置关系。）

7. 练习

1 【基础】判断下列说法是否正确，错误的请改正：（1）两条直线被第三条直线所截，同位角相等；（2）两直线平行，内错角相等；（3）两直线平行，同旁内角互补；（4）同旁内角互补，两直线平行。
答案与解析

（1）错误。同位角只说明位置关系，大小不一定相等。应改为：两直线平行，同位角相等。

（2）正确，这是平行线的性质二。

（3）正确，这是平行线的性质三。

（4）正确，但它是判定，不是性质：由角的关系推出两条直线平行。

这四句话放在一起，正好把“性质”与“判定”摆在一起对照：（2）（3）是性质，（4）是判定，（1）缺了“两直线平行”这个前提，是把性质当成了普遍规律。

2 【基础】已知 a∥b，直线 c 与 a、b 分别相交，∠1 与 ∠2 是同位角，∠1 = 72°。求 ∠2 的度数，再求 ∠2 的对顶角的度数。
答案与解析

∵ a∥b，∴ ∠2 = ∠1 = 72°（两直线平行，同位角相等）。

∵ 对顶角相等，∴ ∠2 的对顶角 = ∠2 = 72°。

答：∠2 = 72°，∠2 的对顶角也是 72°。

提示：本题用了两条不同的依据，第一条是平行线的性质，第二条是对顶角的性质，写答案时要分开写，不能合并成一句“所以都是 72°”。

3 【提升】两条平行线被第三条直线所截，得到 8 个角。已知其中一个角是 68°，求其余各角中与它相等的角的个数，以及与它互补的角的个数。
答案与解析

8 个角分布在两个交点上，每个交点周围有 4 个角，其中两个是 68°，两个是 112°。所以 8 个角里共有 4 个 68°、4 个 112°。

与已知角（68°）相等的角还有 3 个：它的对顶角 1 个，与它成同位角的 1 个，与它成内错角的 1 个。

与它互补的角有 4 个：它的两个邻补角，与它成同旁内角的 1 个，以及同旁内角的对顶角 1 个。

答：与它相等的角有 3 个，与它互补的角有 4 个。

说明：这道题不需要画图，只要抓住“8 个角中两两相等或互补”这一结构即可。检验的办法是 1 + 3 + 4 = 8，数目正好对上。

4 【提升】两直线平行，∠1 与 ∠2 是同旁内角，且 ∠1 = 2∠2 − 30°。求 ∠1 与 ∠2 的度数。
答案与解析

∵ 两直线平行，∴ ∠1 + ∠2 = 180°（两直线平行，同旁内角互补）。

把 ∠1 = 2∠2 − 30° 代入，得 2∠2 − 30° + ∠2 = 180°，即 3∠2 = 210°，∴ ∠2 = 70°。

∴ ∠1 = 2 × 70° − 30° = 110°。

答：∠1 = 110°，∠2 = 70°。

检验：110° + 70° = 180°，符合同旁内角互补；110° = 2 × 70° − 30°，符合题设。两个条件同时满足，答案正确。

5 【拓展】小明说：“因为 ∠1 与 ∠2 是同位角，所以 ∠1 = ∠2。”你认为这句话对吗？如果不对，请补上缺少的条件，并举一个反例说明。
答案与解析

不对。同位角只是按位置起的名字，两个角分别在截线同侧、在被截线同方，与它们的大小没有关系。

缺少的条件是“两条被截线平行”。补上后应说：因为 a∥b，且 ∠1 与 ∠2 是同位角，所以 ∠1 = ∠2（两直线平行，同位角相等）。

反例：把三角板的一条边当作截线，另外两条边不平行，此时截线与两条边所成的同位角一大一小，并不相等。可见“同位角相等”必须建立在“两直线平行”之上。

答：这句话不对，应补上“两直线平行”这一前提。

第 2 课时判定与性质的综合应用

第 1 课时我们由平行推出角相等，这一课时把两个方向接起来：先由角的关系推出平行，再由平行推出新的角的关系。这种“角—线—角”的交替推理，是本章综合题的基本套路。掌握了它，图中再多的线也能一步一步拆开。

综合题之所以让人觉得难，往往不是因为某一步不会，而是因为不知道该从哪一步下手。其实图上的条件只有两类：一类是“线平行”，一类是“角相等或互补”。把这两类条件当成接力棒，一棒一棒往下传，路线自然就清楚了。

1. 综合推理的基本套路

第一步，看图中哪两条直线可能平行，找出截住它们的第三条直线；第二步，找一对同位角、内错角或同旁内角，用判定得到这两条直线平行；第三步，把刚得到的平行当作新的条件，再用性质求出其他角。三步走完，通常就能把题目要求的角算出来。

关键在于找“桥梁角”——既是判定里的结论角，又是性质里的条件角的那个角。桥梁角一般出现在两条截线的交点处，它同时属于两个“三线八角”图形，把两个图形连接起来。

常见的基本图形要能一眼认出。两条平行线被一条截线所截，如果图形呈“Z”形，夹在中间的那对是内错角，相等；呈“U”形（也可以横过来看成“コ”形），夹在中间且同在截线一侧的那对是同旁内角，互补；呈“F”形，位置相同的那对是同位角，相等。综合题里的线一多，先把图形拆成这几种基本形状，再逐个处理，比盯着整幅图发呆有效得多。

图上如果出现了两条以上的截线，还要先分组。把每一组“两条被截线加一条截线”单独看，认清楚这一组里的同位角、内错角、同旁内角，再去处理另一组。分组清楚了，就不会把不同组的角硬凑成一对。

写综合题还有一条实用经验：每算出一个新的角，就随手在图上标出来。相等的角用同样数量的弧线标注，互补的角用“180° − 已知角”的算式标在旁边。图上的标记越清楚，下一步该用哪条性质就越明显。很多同学卡住，不是不会推理，而是图上空空如也，看不出哪两个角有关系。

例 4 先判定平行，再用性质求角

如图 13，直线 a、b 被直线 c 所截，∠1 = ∠2，∠3 = 75°。求 ∠4 的度数。

解

∵ ∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的同位角，且 ∠1 = ∠2，∴ a∥b（同位角相等，两直线平行）。

∵ a∥b，∴ ∠3 + ∠4 = 180°（两直线平行，同旁内角互补）。

∴ ∠4 = 180° − 75° = 105°。

答：∠4 = 105°。

检验：∠1 与 ∠3 是邻补角，∠3 = 75°，所以 ∠1 = 105°；又 ∠1 = ∠2，所以 ∠2 = 105°。而 ∠2 与 ∠4 是对顶角，∠4 = 105°，与上面的结果一致。

变式：如图 13，∠1 = ∠2，若 ∠3 = 4∠4 − 40°，求 ∠3 与 ∠4 的度数。（由 ∠3 + ∠4 = 180° 得 5∠4 = 220°，∠4 = 44°，∠3 = 136°。）

2. 拐点问题：过拐点作平行线

图形中出现一个“折点”，它不在任何一条已知直线上，也不在截线上，这类问题叫拐点问题。折点处的角往往与已知的两个角没有直接关系，硬算算不出来。

标准做法是：过折点作一条与已知平行线平行的直线。作法要写出来，辅助线用虚线画。为什么要这样作？因为平行线的作用是“把角搬到一起”。过折点 E 作 EF∥AB 之后，∠B 与 ∠BEF 成为内错角，∠D 与 ∠DEF 也成为内错角，一个不好算的大角 ∠BED 就被拆成两个可以直接用性质算的小角。

作辅助线之前要先想清楚方向：EF 画在哪一侧，决定了 ∠B 与 ∠BEF 是内错角还是同旁内角。通常让 EF 落在 ∠BED 的内部，这样 ∠BED 就等于两个小角之和，计算最省事。

常见的三种位置要分清：折点在两条平行线之间、尖角朝一侧，此时大角等于两个小角之和；折点落在两条平行线之外，此时大角等于两个小角之差，究竟是加还是减，必须由图形位置决定，不能死记公式；折点有两个或更多，就过每一个折点都作平行线，把折线一段一段拆开。

辅助线是“看不见的已知条件”，作完之后一定要在推理里用上“∵ EF∥AB，AB∥CD，∴ EF∥CD”这一步，否则辅助线就白作了。这一步用的是平行公理的推论：平行于同一条直线的两条直线互相平行。

方法归纳：
  • 见折点，先作平行线：过折点作已知平行线的平行线，辅助线用虚线。
  • 先证传递：∵ EF∥AB，AB∥CD，∴ EF∥CD。
  • 再拆角：把大角拆成两个小角，分别用“两直线平行，内错角相等”或“同旁内角互补”。
  • 后合并：按图形位置判断是相加还是相减，最后写出答案与依据。
例 5 拐点问题

如图 14，AB∥CD，点 E 在 AB 与 CD 之间，∠B = 30°，∠D = 40°。求 ∠BED 的度数。

解

过点 E 作 EF∥AB（如图 14 中的虚线）。

∵ EF∥AB，AB∥CD，∴ EF∥CD（平行于同一条直线的两条直线平行）。

∵ AB∥EF，∴ ∠BEF = ∠B = 30°（两直线平行，内错角相等）。

∵ EF∥CD，∴ ∠DEF = ∠D = 40°（两直线平行，内错角相等）。

∴ ∠BED = ∠BEF + ∠DEF = 30° + 40° = 70°。

答：∠BED = 70°。

说明：辅助线 EF 把 ∠BED 分成 ∠BEF 与 ∠DEF 两部分，两部分都落在“两条平行线被第三条直线所截”的基本图形里，所以都能用性质直接算。如果没有这条辅助线，∠BED 与 ∠B、∠D 之间看不出任何直接关系。

变式：如图 14，AB∥CD，点 E 在 AB 与 CD 之间，若 ∠B = 30°，∠BED = 100°，求 ∠D 的度数。（∠D = ∠BED − ∠B = 70°。）

3. 实际应用中的平行线

道路、渠道、铁路的拐弯问题，本质上是平行线性质的应用。两次拐弯后两段路平行，说明它们所在的直线平行；拐弯处形成的角，就是截线与平行线所成的角。解决这类问题的顺序是：先把实际问题画成示意图，标出已知的角和平行的两段，再判断要求的角与已知的角是同位角、内错角还是同旁内角，最后选性质计算。

判断是“相等”还是“互补”，不能凭感觉。同一条截线上，两个角如果在截线的同侧、又都夹在两条平行线之间，就是同旁内角，互补；如果分居截线两侧、都夹在两条平行线之间，就是内错角，相等。实际图形里，“两段路在拐弯处向同一侧弯”和“向两侧弯”得到的结论正好相反。

例 6 渠道拐弯的实际问题

一条笔直的渠道 AB 与另一段笔直的渠道 CD 平行，BC 是把两段连接起来的直段。两段渠道在 B、C 处向同一侧拐弯（即点 A 与点 D 在直线 BC 的同侧）。已知 ∠ABC = 120°。（1）求 ∠BCD 的度数；（2）如果设计要求 ∠BCD = 50°，那么 ∠ABC 应挖成多少度？

解

（1）∵ AB∥CD，∴ ∠ABC + ∠BCD = 180°（两直线平行，同旁内角互补）。

∴ ∠BCD = 180° − 120° = 60°。

（2）∵ AB∥CD，∴ ∠ABC = 180° − ∠BCD = 180° − 50° = 130°。

答：∠BCD = 60°；若设计要求 ∠BCD = 50°，∠ABC 应挖成 130°。

说明：这里为什么是互补而不是相等？因为点 A 与点 D 在直线 BC 的同侧，∠ABC 与 ∠BCD 都在截线 BC 的同侧，又都夹在 AB、CD 之间，是一对同旁内角。如果两段渠道向两侧拐弯（A、D 在 BC 的两侧），这两个角就成了内错角，那时 ∠ABC = ∠BCD，计算就要改用“两直线平行，内错角相等”。所以做实际应用题，先要把“点在截线哪一侧”看清楚，再决定用哪条性质。

变式：若两段渠道向两侧拐弯（A、D 在直线 BC 的两侧），∠ABC = 120°，求 ∠BCD；并说明两次拐弯的方向与原来方向的关系。（∠BCD = 120°，因为 ∠ABC 与 ∠BCD 是内错角，两直线平行，内错角相等；此时渠道方向绕了一圈又回到与 AB 平行的方向。）

4. 练习

1 【基础】已知 ∠1 与 ∠2 是内错角，∠1 = ∠2，∠2 = 68°。（1）判断两条被截线是否平行；（2）求 ∠2 的同旁内角的度数。
答案与解析

（1）平行。∵ ∠1 与 ∠2 是内错角，且 ∠1 = ∠2，∴ 两条被截线平行（内错角相等，两直线平行）。

（2）∵ 两条被截线平行，∴ ∠2 与它的同旁内角互补（两直线平行，同旁内角互补），∴ 这个同旁内角 = 180° − 68° = 112°。

答：两条被截线平行，∠2 的同旁内角是 112°。

说明：第（1）问用判定，第（2）问用性质，两问的依据方向相反，这正是综合题最常见的结构：先用角证平行，再用平行求角。

2 【基础】已知 ∠1 与 ∠2 是同位角，∠2 与 ∠3 是邻补角，∠1 = 70°，∠3 = 110°。判断两条被截线是否平行，并写出推理过程。
答案与解析

∵ ∠2 与 ∠3 是邻补角，∴ ∠2 + ∠3 = 180°（邻补角互补），∴ ∠2 = 180° − 110° = 70°。

∵ ∠1 = 70°，∴ ∠1 = ∠2。

∵ ∠1 与 ∠2 是同位角，且 ∠1 = ∠2，∴ 两条被截线平行（同位角相等，两直线平行）。

答：两条被截线平行。

说明：题目没有直接给出“同位角相等”，先用邻补角把 ∠2 算出来，这是综合题中常用的“转化”手法。条件不对口时，先用对顶角、邻补角把角搬到需要的位置。

3 【提升】已知 ∠1 与 ∠2 是同旁内角。（1）若 ∠1 = ∠2，能否判定两条被截线平行？（2）若 ∠1 = 90°，能否判定？（3）若 ∠1 = 65°、∠2 = 115°，能否判定？请分别说明理由。
答案与解析

（1）不一定能。判定平行需要同旁内角互补，而 ∠1 = ∠2 只说明两个角相等。只有当 ∠1 = ∠2 = 90° 时，它们的和才是 180°，才能判定平行；若 ∠1 = ∠2 = 70°，和为 140°，不能判定。

（2）能。∵ ∠1 = 90°，∠2 = 90°，∴ ∠1 + ∠2 = 180°，∴ 两条被截线平行（同旁内角互补，两直线平行）。

（3）能。∵ 65° + 115° = 180°，且 ∠1 与 ∠2 是同旁内角，∴ 两条被截线平行（同旁内角互补，两直线平行）。

说明：同旁内角这一组关系最容易被记混。“相等”不是判定的条件，“互补”才是。遇到“同旁内角相等”的说法，先算一算它们的和是不是 180°。

4 【提升】AB∥CD，点 E 在 AB 与 CD 之间，∠B = 45°，∠D = 35°。（1）求 ∠BED 的度数；（2）若 ∠BED = 90°，∠B = 40°，求 ∠D 的度数。
答案与解析

（1）过点 E 作 EF∥AB。∵ EF∥AB，AB∥CD，∴ EF∥CD（平行于同一条直线的两条直线平行）。

∵ AB∥EF，∴ ∠BEF = ∠B = 45°（两直线平行，内错角相等）。

∵ EF∥CD，∴ ∠DEF = ∠D = 35°（两直线平行，内错角相等）。

∴ ∠BED = ∠BEF + ∠DEF = 45° + 35° = 80°。

（2）同样过点 E 作 EF∥AB，得 ∠BEF = ∠B = 40°，∴ ∠DEF = ∠BED − ∠BEF = 90° − 40° = 50°，∴ ∠D = ∠DEF = 50°。

答：∠BED = 80°；∠D = 50°。

5 【拓展】AB∥CD，点 E 在 AB 与 CD 之间，∠B = α，∠D = β。（1）用含 α、β 的式子表示 ∠BED，并说明理由；（2）当 ∠BED = 100°、β = 40° 时，求 α；（3）若 ∠B = ∠D，且 ∠BED = 80°，求 ∠B 的度数。
答案与解析

（1）∠BED = α + β。理由：过点 E 作 EF∥AB，则 EF∥CD；∵ AB∥EF，∴ ∠BEF = α（两直线平行，内错角相等）；∵ EF∥CD，∴ ∠DEF = β（两直线平行，内错角相等）；∴ ∠BED = ∠BEF + ∠DEF = α + β。

（2）由（1）得 100° = α + 40°，∴ α = 60°。

（3）由（1）得 ∠BED = ∠B + ∠D = 2∠B = 80°，∴ ∠B = 40°。

答：∠BED = α + β；α = 60°；∠B = 40°。

说明：把具体的数换成字母，结论的形式不变，这说明拐点问题的规律与角的大小无关，只与图形的位置关系有关。这也提醒我们，做过的题要总结“套路”，而不是记住某一道题的答案。

一、本章知识结构

一章学完，脑子里往往是一堆散落的珠子：对顶角相等、邻补角互补、垂线段最短、同位角相等两直线平行、两直线平行内错角相等……单独看每一条都记得，合起来却说不清它们之间的关系。复习的第一件事，就是找一根线把这些珠子串起来。这根线就是“同一平面内两条直线的位置关系”。

沿着这根线往下问，问题就一个一个出来了：两条直线有几种位置关系？相交时，围绕交点会产生哪些角，这些角有什么数量关系？相交里最特殊的情形是什么？平行时，又该怎样判断、怎样利用？把这些问题按顺序排好，就得到如图 15 所示的知识结构图。请先不要急着往下读，自己盯着这张图看两分钟，试着用一句完整的话把整张图讲一遍，再对照后面的解读检查自己漏了什么。

先看“相交”这一支。两条直线相交于一点，围绕这个交点产生四个角，它们两两组成对顶角或邻补角：对顶角相等，邻补角互补。这两条结论是整支的“根”，后面很多计算都要用到它们。当四个角中有一个是直角时，相交就变成了特殊情况——垂直，于是又有了垂线、垂足、垂直的符号表示，以及两个基本事实：“在同一平面内，过一点有且只有一条直线与已知直线垂直”“垂线段最短”。由“垂线段最短”再往下走一步，就得到点到直线的距离：它是垂线段的长度，是一个数量，而不是那条线段本身。

再看“平行”这一支。研究平行，第一步不是画线，而是“读图”：两条直线被第三条直线所截，得到八个角，按位置分成同位角、内错角、同旁内角三类，这就是“三线八角”。只有先能准确叫出两个角的名字，才谈得上比较它们的大小。名字认准了，判定就顺理成章：同位角相等、内错角相等、同旁内角互补，都能推出两直线平行；此外，平行公理告诉我们“过直线外一点，有且只有一条直线与这条直线平行”，它的推论告诉我们“平行于同一条直线的两条直线平行”。把判定中的箭头反过来，就得到三条性质。

两支之间并不是各管各的。判定与性质方向相反，却常常连着用：先用判定得到一组平行线，再用性质得到新的角相等，又用这组角相等去判定另一组直线平行，这就是“角 → 线 → 角”的链条，拐点问题正是这条链条最典型的应用。图 15 底部那条黄色提示写的也是这件事：判定是“角 → 线”，性质是“线 → 角”。方向一旦写反，整道题的推理就站不住了。

要点：本章只有一条主线——两条直线的位置关系。相交这一支围绕“角”展开，落点是垂直与距离；平行这一支围绕“三线八角”展开，落点是判定与性质。判定与性质的条件和结论正好互换，这是全章最容易出错、也最需要反复核对的地方。

三、五种思想方法

数学思想方法不是额外的知识，而是“怎么想”的经验。本章至少有五种方法反复出现，它们比某一条结论更耐用，因为换了题目也照样能用。

1. 数形结合：让图形语言、符号语言、文字语言互相翻译。本章的每一个结论都有三种“说法”。以“两直线平行，内错角相等”为例：文字语言是这一句话，图形语言是图上那个“Z”字形的两个角，符号语言是“∵a∥b，∴∠1 = ∠2”。做题时的顺序通常是：先在图上把已知的角标出来（图形语言），再把标出的关系写成式子（符号语言），最后用一句话说明依据（文字语言）。三种语言能自由转换，图就不是“装饰”，而是推理的一部分。反过来，看到“∠1 = ∠2”这样一行式子，脑子里要立刻浮现出那两个角在图上的位置，否则很容易把同位角当成内错角。

2. 转化：把“线”的问题变成“角”的问题。本章最核心的一次转化，是在“角的关系”和“线的关系”之间来回走。要证两条直线平行，就去证一对同位角相等、内错角相等或同旁内角互补；已知两条直线平行，就去用角相等或互补。除了这条主线，转化还以很多小形式出现：用对顶角把远处的角“搬”到眼前，用邻补角把 130° 化成 50°，用平行线把分散的角凑到同一个顶点。可以说，本章的每一道证明题，都是一次或几次转化的组合；遇到卡住的地方，就问自己一句：“这个角还能和哪个角拉上关系？”

3. 分类讨论：先定标准，再逐类说清。本章有一道很典型的分类题：如果两个角的两边分别平行，这两个角有什么关系？答案不是唯一的，要分两种情形。当两个角的两组边方向都相同（或都相反）时，这两个角相等；当一组边方向相同、另一组边方向相反时，这两个角互补。画图时先画一个角，再把它的两边分别平移，就能把两种情形都画出来。分类讨论的关键是“不重不漏”：先确定分类标准（这里是“边的方向相同还是相反”），再逐类讨论，最后把结论合起来写。本章里“拐点在平行线之间还是之外”“截线不同导致角的名称不同”，也都需要这样处理。

4. 方程思想：把角设成未知数。当题目里出现“一个角与另一个角的倍数关系”时，用方程往往比一步步推更省力。例如：一个角的补角是它的余角的 4 倍，求这个角。设这个角为 x°，那么它的补角是 (180 − x)°，余角是 (90 − x)°。由题意得 180 − x = 4(90 − x)，去括号得 180 − x = 360 − 4x，移项合并得 3x = 180，所以 x = 60。检验：这个角是 60°，补角 120°，余角 30°，120 = 4 × 30，符合题意。列方程的关键，是把“补角”“余角”正确地翻译成含 x 的式子，并且始终盯住“是哪个角的补角、哪个角的余角”。

5. 从特殊到一般：从一道题看出一类题。在“两条平行线之间有一个拐点”的基本图形中，如果 ∠B = 30°、∠D = 40°，那么 ∠BED = 70°；把 30°、40° 换成一般的 m°、n°，同样的辅助线、同样的推理，就得到 ∠BED = m° + n°。这就是从特殊到一般：先在一个具体图形上把道理走通，再把数字换成字母，看看结论的形式有没有变化。这样做的好处是，你记住的不再是一个 70°，而是一条能反复使用的规律；反过来，一般结论也能帮你检验特殊情形，如果代入具体数字算出来不对，那一定是推理中某一步出了问题。

方法归纳：复习一章时，先画结构图（把知识串起来），再列对照表（把易混的分开），最后提炼思想方法（把经验留下来）。这三步做完，知识才真正从“学过”变成“会用”。

1 【回顾】对顶角、邻补角、余角、补角之间有什么联系与区别？
答案与解析

这四种关系可以分成两类：对顶角、邻补角说的是“位置”，余角、补角说的是“数量”。

对顶角：两条直线相交，两个角有公共顶点，且两边分别互为反向延长线，没有公共边，这样的两个角叫做对顶角。邻补角：两个角有公共顶点，有一条公共边，另一边互为反向延长线。它们都必须由两条相交直线产生，离开那个交点就无从谈起。

余角、补角则只看度数：两个角的和是 90°，就说它们互为余角；和是 180°，就说它们互为补角。这两个角画在哪里、隔多远，都没有关系。

联系有三条：① 邻补角一定互补，但互补的两个角不一定是邻补角；② 对顶角相等，并且一对对顶角的邻补角也分别相等；③ 同一个角的补角比它的余角大 90°，因为 (180° − x°) − (90° − x°) = 90°。

区别可以这样记：说“对顶”“邻补”，先找那个交点，看两条边是不是在一条直线上；说“互余”“互补”，只算度数，不问位置。判断时先看“边”，再看“顶点”，最后才谈度数。

2 【回顾】判定两条直线平行有哪些方法？它们的共同点是什么？
答案与解析

常用的判定方法有四种：① 同位角相等，两直线平行；② 内错角相等，两直线平行；③ 同旁内角互补，两直线平行；④ 平行于同一条直线的两条直线平行，这是平行公理的推论。

此外还有两条常用的。一是在同一平面内，垂直于同一条直线的两条直线平行，它的道理可以用“同位角都是 90°”来说明，也可以看成推论的一种特殊情形。二是平行的定义：在同一平面内没有公共点的两条直线互相平行。定义当然是对的，只是“没有公共点”没法直接量出来，所以证题时我们更愿意用前面几种由角来判断的方法。

共同点有两个。第一，它们都是把“线的位置”交给“角的大小”来判断，都是“由角定线”：只要找到一对有关系的角，就能断定两条直线的位置。第二，它们都离不开“第三条直线”——必须先有一条截线，把两条待判定的直线连起来，才谈得上同位角、内错角、同旁内角。

所以证平行的套路是固定的：先在图中找出与这两条直线都相交的那条截线，再找一对同位角、内错角或同旁内角，把“证平行”转化成“证两个角相等或互补”。如果图上没有现成的角，就用对顶角、邻补角去转化，或者添一条辅助线把角造出来。

3 【回顾】平行线的判定与性质有什么区别？怎样避免用反？
答案与解析

判定与性质的条件和结论正好互换。判定是“已知角的关系，推出两直线平行”，方向是角 → 线；性质是“已知两直线平行，推出角的关系”，方向是线 → 角。三条判定、三条性质，一一对应，只是箭头方向相反。

避免用反，可以按三步检查。第一步，看题目的“已知”里有没有“平行”这两个字：有平行，多半要用性质；没有平行、而要证明平行，只能用判定。第二步，把推理写成“∵……∴……”的格式，读一遍“∵”后面的内容，看它是不是题目给出的条件；如果不是，说明这一步用反了。第三步，把依据写完整：判定写“同位角相等，两直线平行”，性质写“两直线平行，同位角相等”，两句话的先后顺序不能颠倒。

还要注意一点：判定与性质经常连着用，中间要有“过渡”。比如先用判定得到 a∥b，再用性质由 a∥b 得到 ∠1 = ∠2，最后又用 ∠1 = ∠2 去判定另一组直线平行。这时候每一步的依据都要单独写清楚，不能因为前面出现过“平行”两个字，后面就一路写“两直线平行”。

4 【回顾】遇到“拐点”问题，为什么要过拐点作平行线？
答案与解析

因为拐点处的角，不是两条直线被第三条直线所截得到的“三线八角”中的角。判定和性质都只对同位角、内错角、同旁内角说话，而拐点处的角哪一类都不是，直接套结论一定会出错。

过拐点作一条与已知直线平行的辅助线以后，这个角被拆成两个角，而这两个角分别与已知的两个角构成内错角（或同旁内角），于是“拐点角”就变成了两个“能算的角”的和或差。这就是作辅助线的作用：把不能用结论的角，转化成能用结论的角。

作辅助线要注意三点。① 用虚线画，并写清作法，例如“过点 E 作 EF∥AB”。② 说明理由时要补一句：“∵AB∥CD，EF∥AB，∴EF∥CD（平行于同一条直线的两条直线平行）”，这一步不能省，否则后面的推理就没有依据。③ 拆角时要看清辅助线落在角的内部还是外部，是加还是减要由图形决定，不能想当然。

五、综合例题

下面两道例题分别代表本章的两类综合题：一道是“判定与性质交替使用”的计算题，一道是“拐点”题。请先按题意画出草图，自己写一遍推理，再对照解答检查每一步的依据。

例 1 先由线得角，再由角定线

已知直线 AB∥CD，直线 EF 与 AB、CD 分别相交于点 E、F，直线 GH 与 AB、CD 分别相交于点 G、H。点 E、G 都在 AB 上，点 F、H 都在 CD 上，点 E 在点 G 的左侧，点 F 在点 H 的左侧，EF 与 GH 都向右下方倾斜。若 ∠1 = ∠BEF = 50°，∠2 = ∠DHG = 130°，请回答：

（1）EF 与 GH 平行吗？说明理由。

（2）求 ∠EFD 与 ∠CHG 的度数。

解

（1）EF∥GH。理由如下：

∵ ∠DHG 与 ∠CHG 是邻补角，∠DHG = 130°，

∴ ∠CHG = 180° − 130° = 50°（邻补角互补）。

∵ AB∥CD，∠BGH 与 ∠CHG 是内错角，

∴ ∠BGH = ∠CHG = 50°（两直线平行，内错角相等）。

∵ ∠BEF = 50°，∠BGH = 50°，

∴ ∠BEF = ∠BGH。

又 ∠BEF 与 ∠BGH 是直线 EF、GH 被直线 AB 所截得到的同位角，

∴ EF∥GH（同位角相等，两直线平行）。

（2）∵ AB∥CD，∠BEF 与 ∠EFD 是同旁内角，

∴ ∠EFD = 180° − ∠BEF = 180° − 50° = 130°（两直线平行，同旁内角互补）。

由（1）已得 ∠CHG = 50°。

答：EF∥GH；∠EFD = 130°，∠CHG = 50°。

变式：其他条件不变，若把 ∠2 = 130° 改为 ∠2 = 100°（即 ∠DHG = 100°），EF 与 GH 还平行吗？请说明理由。答：不平行。因为 ∠CHG = 180° − 100° = 80°，由 AB∥CD 得 ∠BGH = ∠CHG = 80°，而 ∠BEF = 50°，∠BEF 与 ∠BGH 不相等，所以 EF 与 GH 不平行。可见“两直线平行”这个结论，必须由角的关系推出来，不能凭图形“看着像”就下结论。

例 2 过拐点作平行线，把折角拆开

已知 AB∥CD，AB 在上、CD 在下。点 B 在 AB 上，点 C、D 都在 CD 上，且点 D 在点 C 的右侧；点 E、F 都在两条平行线之间。顺次连接 B、E、F、C 得到一条折线，已知 ∠ABE = 40°，∠BEF = 100°，∠EFC = 110°，求 ∠DCF 的度数。

解

过点 E 在 ∠BEF 的内部作 EM∥AB，过点 F 在 ∠EFC 的内部作 FN∥AB（辅助线用虚线画）。

∵ AB∥CD，EM∥AB，FN∥AB，

∴ EM∥CD，FN∥CD（平行于同一条直线的两条直线平行），且 EM∥FN。

∵ AB∥EM，BE 是截线，

∴ ∠BEM = ∠ABE = 40°（两直线平行，内错角相等）。

∴ ∠MEF = ∠BEF − ∠BEM = 100° − 40° = 60°。

∵ EM∥FN，EF 是截线，

∴ ∠EFN = ∠MEF = 60°（两直线平行，内错角相等）。

∴ ∠NFC = ∠EFC − ∠EFN = 110° − 60° = 50°。

∵ FN∥CD，FC 是截线，

∴ ∠DCF = ∠NFC = 50°（两直线平行，内错角相等）。

答：∠DCF = 50°。

变式：若把 ∠ABE = 40° 改为 ∠ABE = 55°，其余条件不变，求 ∠DCF 的度数。答：同理可得 ∠MEF = 100° − 55° = 45°，∠EFN = 45°，∠NFC = 110° − 45° = 65°，所以 ∠DCF = 65°。把两次的结果放在一起看，会发现 ∠ABE + ∠EFC = ∠BEF + ∠DCF：40° + 110° = 100° + 50°，55° + 110° = 100° + 65°。这类图形中，两个“外角”之和等于两个“拐角”之和，这就是从特殊到一般得到的规律。

提示：例 2 的辅助线有两条，画的时候要注意它们的位置：EM 落在 ∠BEF 的内部，FN 落在 ∠EFC 的内部。位置画对了，拆角时就是“大角减小角”；位置画错了，结论就会差出很多。做完题后不妨把辅助线擦掉，重新画一次，看看自己是不是真的理解了“为什么要这样作”。

  • 相交这一支：对顶角（相等）、邻补角（互补）、垂线（AB⊥CD 于点 O）、垂线段最短、点到直线的距离（垂线段的长度）。

  • 常用方法：过拐点作平行线、设角列方程、分类讨论、从特殊到一般；写推理时先看“∵”后面是角还是线，方向就不会反。

一、知识技能（第 1—6 题）

这一组题限时 15 分钟完成，只要求算得对、说得清。做完后逐题核对：数字对不对，依据写没写，角的位置有没有认错。

1 【基础】直线 AB、CD 相交于点 O，∠AOD = 3∠AOC。（1）求 ∠AOC 与 ∠AOD 的度数；（2）写出 ∠AOC 的对顶角和邻补角；（3）若 OE 平分 ∠BOD，求 ∠AOE 的度数。
答案与解析

（1）∵ ∠AOC 与 ∠AOD 有公共顶点 O，有一条公共边 OA，另一边 OC 与 OD 互为反向延长线，∴ ∠AOC 与 ∠AOD 是邻补角，∴ ∠AOC + ∠AOD = 180°。又 ∠AOD = 3∠AOC，∴ ∠AOC + 3∠AOC = 180°，即 4∠AOC = 180°，∴ ∠AOC = 45°，∠AOD = 3 × 45° = 135°。

（2）∠AOC 的对顶角是 ∠BOD。因为 ∠AOC 的两边 OA、OC 与 ∠BOD 的两边 OB、OD 分别互为反向延长线，符合对顶角的定义。∠AOC 的邻补角有两个：∠AOD 与 ∠BOC。

（3）∵ ∠BOD 与 ∠AOC 是对顶角，∴ ∠BOD = ∠AOC = 45°（对顶角相等）。∵ OE 平分 ∠BOD，∴ ∠BOE = 1/2 × 45° = 22.5°。∵ A、O、B 三点在同一条直线上，∴ ∠AOB = 180°（平角），∴ ∠AOE = ∠AOB − ∠BOE = 180° − 22.5° = 157.5°。

检验：∠AOE 是一个钝角，画出来看确实大于 90°，与 157.5° 相符；再用 ∠AOD + ∠DOE 验算，∠DOE = 22.5°，135° + 22.5° = 157.5°，结果一致。

2 【基础】（1）一个角的补角比它的余角的 2 倍还多 30°，求这个角；（2）若 ∠α 与 ∠β 互余，求 ∠α 的补角与 ∠β 的补角的和；（3）若一个角的余角是 25°，求它的补角。
答案与解析

（1）设这个角为 x°，则它的补角为 (180 − x)°，余角为 (90 − x)°。由题意得 180 − x = 2(90 − x) + 30，去括号得 180 − x = 180 − 2x + 30，移项合并得 x = 30。所以这个角是 30°。检验：补角为 150°，余角为 60°，2 × 60° + 30° = 150°，与补角相等，符合题意。

（2）∵ ∠α 与 ∠β 互余，∴ ∠α + ∠β = 90°。∠α 的补角为 (180° − ∠α)，∠β 的补角为 (180° − ∠β)，它们的和为 360° − (∠α + ∠β) = 360° − 90° = 270°。也可以这样想：两个角互余，它们的补角之和比两个平角少 90°，即 270°。

（3）这个角的余角是 25°，所以这个角是 90° − 25° = 65°，它的补角是 180° − 65° = 115°。也可以直接用结论：同一个角的补角比它的余角大 90°，所以补角为 25° + 90° = 115°，两种算法结果相同。

3 【基础】点 P 是直线 l 外一点，PA⊥l 于点 A，PA = 4 cm。B、C 是 l 上异于 A 的两点，PB = 5 cm，PC = 6 cm。（1）求点 P 到直线 l 的距离；（2）比较 PA、PB、PC 的大小，并说明依据；（3）若点 Q 在 l 上，且 PQ = 4 cm，Q 与 A 有怎样的位置关系？
答案与解析

（1）点 P 到直线 l 的距离是 4 cm。理由：点到直线的距离是这点到直线的垂线段的长度。∵ PA⊥l 于点 A，∴ PA 就是点 P 到 l 的垂线段，它的长度 4 cm 就是所求的距离。注意距离是一个数量，不能说“距离是 PA”或“距离是垂线段”。

（2）PA < PB < PC。依据是“垂线段最短”：从直线外一点向直线引的所有线段中，垂线段最短。这里 PA 是垂线段，PB、PC 都是斜线段，所以 PA 最短；又已知 PB = 5 cm，PC = 6 cm，故 4 cm < 5 cm < 6 cm，即 PA < PB < PC。这个结论与 B、C 在 A 的哪一侧无关，只要它们不是垂足，对应的线段就比垂线段长。

（3）Q 与 A 重合。理由：假如 Q 与 A 不重合，那么 PQ 就不是垂线段而是斜线段，由“垂线段最短”应有 PQ > PA = 4 cm，这与已知 PQ = 4 cm 矛盾。所以 Q 只能与 A 重合。这条推理说明：过点 P 且长度为 4 cm 的、端点在 l 上的线段只有一条，就是垂线段 PA 本身。

4 【基础】直线 a、b 被直线 c 所截，得到 8 个角。已知 ∠1 在 c 的左侧、a 的上方；∠2 在 c 的左侧、b 的上方；∠3 在 c 的左侧、a 与 b 之间；∠4 在 c 的右侧、a 与 b 之间；∠5 在 c 的左侧、a 与 b 之间。（1）∠1 与 ∠2 是什么角？（2）∠3 与 ∠4 是什么角？（3）∠3 与 ∠5 是什么角？（4）若 ∠1 = ∠2，能否判定 a∥b？
答案与解析

（1）∠1 与 ∠2 是同位角。理由：两个角都在截线 c 的同一侧（左侧），并且分别在各自被截线的同方（都在上方），符合“截线同侧、被截线同方”。

（2）∠3 与 ∠4 是内错角。理由：两个角都在两条被截线之间，一个在 c 的左侧、一个在 c 的右侧，符合“截线两侧、被截线之间”。

（3）∠3 与 ∠5 是同旁内角。理由：两个角都在两条被截线之间，又都在截线 c 的左侧，符合“截线同侧、被截线之间”。

（4）能。∠1 与 ∠2 是直线 a、b 被直线 c 所截得的同位角，已知 ∠1 = ∠2，即同位角相等，由“同位角相等，两直线平行”可得 a∥b。这一步用的是判定，方向是“由角推线”。

提醒：本题的判断完全依赖位置，与角的大小无关。如果把 ∠2 的位置改成“c 的左侧、b 的下方”，它与 ∠1 就只是“同侧而不同方”，既不是同位角，也不能用来判定平行。所以做题时一定要先把两个角的位置写清楚。

5 【提升】直线 AB、CD 被直线 EF 所截，∠1 与 ∠2 是内错角，∠2 与 ∠3 是邻补角。已知 ∠1 = 68°，∠3 = 112°。（1）求 ∠2，并判断 AB 与 CD 是否平行；（2）若 ∠4 与 ∠1 是同旁内角，求 ∠4。
答案与解析

（1）∵ ∠2 与 ∠3 是邻补角，∴ ∠2 + ∠3 = 180°（邻补角互补），∴ ∠2 = 180° − 112° = 68°。又已知 ∠1 = 68°，∴ ∠1 = ∠2。∵ ∠1 与 ∠2 是直线 AB、CD 被直线 EF 所截得到的内错角，∴ AB∥CD（内错角相等，两直线平行）。

（2）∵ AB∥CD，∠4 与 ∠1 是同旁内角，∴ ∠1 + ∠4 = 180°（两直线平行，同旁内角互补），∴ ∠4 = 180° − 68° = 112°。

思路回看：第（1）问的关键是“转化”。题目给的是 ∠3，要用的却是 ∠1 与 ∠2，于是先用邻补角把 ∠3 换成 ∠2，条件才对得上号。第（2）问则反过来，先用判定得到 AB∥CD，再用性质求角。一道题里判定和性质各用一次，方向正好相反，这正是本章最重要的套路。

6 【提升】AB∥CD，直线 EF 分别交 AB、CD 于点 G、H，A、C 在 EF 的左侧，B、D 在 EF 的右侧。已知 ∠BGH = 65°。（1）求 ∠DHG；（2）求 ∠CHG；（3）求 ∠AGH。
答案与解析

（1）∵ AB∥CD，∠BGH 与 ∠DHG 是直线 AB、CD 被 EF 所截得到的同旁内角，∴ ∠BGH + ∠DHG = 180°（两直线平行，同旁内角互补），∴ ∠DHG = 180° − 65° = 115°。

（2）∵ G、H 都在直线 EF 上，点 H 处 HC 与 HD 互为反向延长线，∴ ∠CHG 与 ∠DHG 是邻补角，∴ ∠CHG = 180° − 115° = 65°。也可以这样算：∠BGH 与 ∠CHG 是内错角，由 AB∥CD 得 ∠CHG = ∠BGH = 65°，两种算法结果一致，这本身就是一次自我检验。

（3）∵ A、G、B 在同一条直线上，∴ ∠AGH 与 ∠BGH 是邻补角，∴ ∠AGH = 180° − 65° = 115°。也可以由 ∠AGH 与 ∠CHG 是同旁内角求得：180° − 65° = 115°。

小结：两条平行线被一条截线所截，8 个角其实只有两种大小——65° 与 115°。四个锐角（或四个钝角）彼此相等，锐角与钝角互为邻补角、和为 180°。把这个“两种大小”的结论记牢，以后算这类题可以先写出答案再补依据。

二、数学理解（第 7—12 题）

这一组题多数不算数，只问“对不对”“为什么”。做错了不要紧，要紧的是把错因说清楚：是定义记混了，还是漏了前提，还是把判定与性质用反了。

7 【基础】下列说法中正确的是（　　）　A．相等的两个角是对顶角　B．互补的两个角一定是邻补角　C．在同一平面内，过一点有且只有一条直线与已知直线垂直　D．两条直线被第三条直线所截，同位角一定相等
答案与解析

答案：C。

A 错。对顶角一定相等，但相等的两个角不一定是对顶角。例如一个角的平分线分出的两个角相等，它们有公共顶点、有一条公共边，是邻补角而不是对顶角；再如两条平行线被截线所截得的一对同位角也相等，它们根本没有公共顶点。判断对顶角要看“两边是否分别互为反向延长线”，不能只看大小。

B 错。互补只说明两个角的和为 180°，并不要求它们有公共顶点、有公共边。把两个 90° 的角画在纸的两头，它们互补，却不是邻补角。邻补角必须同时满足“有公共顶点、一条公共边、另一边互为反向延长线”。

C 对。这是垂线的基本事实：在同一平面内，过一点有且只有一条直线与已知直线垂直。注意“在同一平面内”和“有且只有”都不能丢。

D 错。少了“两直线平行”这个前提。两条直线被第三条直线所截，同位角只是位置相同，大小可以相差很多；只有这两条直线平行时，同位角才相等。这是本章最容易出错的一句话：把“性质”的结论当成了“定义”。

8 【基础】判断下列说法是否正确，错的请改正：（1）不相交的两条直线叫做平行线；（2）点到直线的距离是过这点向已知直线所作的垂线段；（3）两条直线被第三条直线所截，同旁内角互补；（4）在同一平面内，如果 a⊥b，b⊥c，那么 a∥c；（5）如果两条直线都与第三条直线平行，那么这两条直线也互相平行。
答案与解析

（1）错。缺了前提“在同一平面内”。改正：在同一平面内，不相交的两条直线叫做平行线。在空间中，两条直线不相交还可能异面，它们并不平行。

（2）错。距离是一个数量，不是图形。改正：点到直线的距离是过这点向已知直线所作的垂线段的长度。垂线段是“线”，长度是“数”，两者不能混为一谈。

（3）错。缺了“两直线平行”这个条件。改正：两条平行线被第三条直线所截，同旁内角互补。若两直线不平行，同旁内角只是和为某个不确定的度数，谈不上互补。

（4）对。在同一平面内，a⊥b 说明 a 与 b 的夹角是 90°，b⊥c 说明 c 与 b 的夹角也是 90°；a、c 与 b 相交成的同位角都是 90°，相等，所以 a∥c。这就是“垂直于同一条直线的两条直线平行”。

（5）对。这是平行公理的推论：平行于同一条直线的两条直线互相平行。它的道理可以用反证说明：如果这两条直线不平行，它们就会相交于一点，那么过这点就有两条直线与第三条直线平行，与平行公理“过直线外一点有且只有一条直线与已知直线平行”矛盾。

9 【提升】比较下面两句话：① ∵ ∠1 = ∠2（∠1 与 ∠2 是内错角），∴ a∥b；② ∵ a∥b，∴ ∠1 = ∠2（∠1 与 ∠2 是内错角）。（1）分别指出两句话的条件、结论和依据，并说明哪一句是判定、哪一句是性质；（2）把 ① 的条件与结论互换，得到的是不是同一句话？这说明判定与性质之间有什么关系？（3）有同学把 ② 写成“∵ a∥b，∴ ∠1 + ∠2 = 180°（内错角相等）”，错在哪里？
答案与解析

（1）① 的条件是“∠1 = ∠2”，结论是“a∥b”，依据是“内错角相等，两直线平行”，它是判定。② 的条件是“a∥b”，结论是“∠1 = ∠2”，依据是“两直线平行，内错角相等”，它是性质。

（2）把 ① 的条件与结论互换，正好得到 ②。所以判定与性质是一对“互逆”的命题：判定回答“怎样的角的关系能保证两直线平行”，性质回答“两直线平行能得到哪些角的关系”。正因为互逆，书写时才不能颠倒：先有平行才能用性质，先有角的关系才能用判定。

（3）错在两处。第一，依据与结论不配套：内错角相等只能推出“∠1 = ∠2”，不能推出“∠1 + ∠2 = 180°”；能推出两角互补的是“两直线平行，同旁内角互补”，前提是这两个角为同旁内角。第二，把角的位置说错了：题目已说明 ∠1 与 ∠2 是内错角，内错角在平行时相等，不是互补。正确的写法是“∵ a∥b，∴ ∠1 = ∠2（两直线平行，内错角相等）”。

再补一句：如果题目给的是“∠1 与 ∠2 是同旁内角”，那么平行时的结论才是 ∠1 + ∠2 = 180°。所以写依据之前，先确认这两个角到底是同位角、内错角还是同旁内角——位置决定结论，这一步不能省。

10 【提升】完成下列“三种语言”的互译：（1）用符号语言表示“直线 AB 与 CD 相交于点 O，∠AOC 是直角”；（2）用文字语言叙述“∵ AB∥CD，∠1 与 ∠2 是同旁内角，∴ ∠1 + ∠2 = 180°”；（3）用符号语言表示“点 P 到直线 l 的距离是 3 cm”，并指出它是哪条线段的长度；（4）用符号写出“∠1 与 ∠2 是对顶角，且 ∠1 = 50°”的推理过程。
答案与解析

（1）AB⊥CD 于点 O，且 ∠AOC = ∠BOC = ∠AOD = ∠BOD = 90°。其中“AB⊥CD 于点 O”是符号语言，“∠AOC = 90°”是它的数量表达，两句话说的是同一件事。

（2）两条平行线 AB、CD 被第三条直线所截，截得的一对同旁内角 ∠1 与 ∠2 互补，即它们的和为 180°。换成推理格式就是：因为 AB∥CD，所以 ∠1 + ∠2 = 180°，依据是“两直线平行，同旁内角互补”。

（3）过点 P 作 PA⊥l 于点 A，则 PA = 3 cm。这里的 3 cm 是垂线段 PA 的长度，不是垂线段 PA 本身，也不是点 P 与 l 上任意一点所连线段的长度。符号语言可以写成“PA⊥l 于点 A，PA = 3 cm，即点 P 到 l 的距离为 3 cm”。

（4）∵ ∠1 与 ∠2 是对顶角，∴ ∠1 = ∠2（对顶角相等）。又 ∠1 = 50°，∴ ∠2 = 50°。这条推理只用对顶角的性质，与两条直线是否平行毫无关系，所以不需要任何平行条件。

互译练习的价值在于：图形看得懂、符号写得对、文字说得清，三者能随时转换，做证明题时才不会“看图说话”却写不出依据。

11 【提升】用三角板和直尺过直线 a 外一点 P 画 a 的平行线。（1）写出画法；（2）说明画出的直线与 a 平行的道理；（3）如果推三角板时手一歪，三角板与直尺的夹角变了，画出的直线还与 a 平行吗？为什么？
答案与解析

（1）画法分四步。一贴：把三角板的一条直角边贴在直线 a 上；二靠：把直尺紧靠在三角板的另一条边上，直尺不动；三推：沿着直尺推动三角板，直到贴 a 的那条边经过点 P；四画：沿这条边画出直线 b，则 b 就是所求的平行线。

（2）道理：推动三角板的过程中，三角板只是沿直尺平移，它与直尺的夹角始终不变。把直尺所在的那条边看成截线，三角板贴 a 的边与画出的 b 看成两条被截线，那么 a、b 与截线所成的同位角始终相等。由“同位角相等，两直线平行”可知 b∥a。这就是“推平行线”的全部道理：平移不改变角度，角度不变就保证平行。

（3）不平行。因为手一歪，三角板发生了转动而不只是平移，它与直尺的夹角就改变了，画出的直线与 a 被截线所截得的同位角不再相等。假如画出的直线与 a 平行，那么由“两直线平行，同位角相等”应有这两个同位角相等，与实际画出的角不相等矛盾，所以它们不平行，延长后必在某处相交。可见画平行线的关键动作是“推”，不是“转”。

还可以用平行公理检查：过点 P 与 a 平行的直线有且只有一条，如果画出的 b 不平行于 a，那它就一定不是那条唯一的平行线，必须重画。

12 【提升】直线 AB、CD 被直线 EF 所截，AB∥CD，∠1 与 ∠2 是对顶角，∠2 = 70°，∠1 与 ∠3 是同旁内角，∠4 与 ∠1 是内错角。（1）求 ∠1 与 ∠3；（2）有同学这样写：“因为 ∠1 与 ∠2 是对顶角，所以 ∠1 = ∠2；又因为 ∠1 与 ∠3 是同旁内角，所以 ∠1 + ∠3 = 180°。”这两句话的依据分别是什么？第二句少了什么条件？（3）求 ∠4。
答案与解析

（1）∵ ∠1 与 ∠2 是对顶角，∴ ∠1 = ∠2 = 70°（对顶角相等）。∵ AB∥CD，∠1 与 ∠3 是同旁内角，∴ ∠1 + ∠3 = 180°（两直线平行，同旁内角互补），∴ ∠3 = 180° − 70° = 110°。

（2）第一句的依据是“对顶角相等”，这条性质只与两条直线相交有关，不需要任何平行条件，所以写法完全正确。第二句的依据应当是“两直线平行，同旁内角互补”，而这位同学只写了“同旁内角”就下了“互补”的结论，漏掉了“两直线平行”这个前提。同旁内角只有在两条被截线平行时才互补；如果不平行，同旁内角的和可以是任何度数。正确写法是：“∵ AB∥CD，∴ ∠1 + ∠3 = 180°（两直线平行，同旁内角互补）”。

（3）∵ AB∥CD，∠4 与 ∠1 是内错角，∴ ∠4 = ∠1 = 70°（两直线平行，内错角相等）。

这道题把三条依据放在一起用：对顶角相等（与平行无关）、同旁内角互补（需要平行）、内错角相等（需要平行）。做题时给每一句话配一条依据，配不上的地方，往往就是漏掉的前提。

三、问题解决（第 13—17 题）

这一组题要把判定与性质连起来用，还要会看图、会作辅助线。每题做完请检查三件事：辅助线是否用虚线、是否写明了作法；每一步的依据是否与角的名称对应；最后是否写了“答”。

13 【提升】AB∥CD，直线 EF 分别交 AB、CD 于点 G、H，A、C 在 EF 的左侧，B、D 在 EF 的右侧，∠BGH = 70°。（1）求 ∠DHG；（2）作 ∠BGH 的平分线 GM，交 CD 于点 M（M 在 C、D 之间），求 ∠GMC 与 ∠GMD。
答案与解析

（1）∵ AB∥CD，∠BGH 与 ∠DHG 是同旁内角，∴ ∠BGH + ∠DHG = 180°（两直线平行，同旁内角互补），∴ ∠DHG = 180° − 70° = 110°。

（2）∵ GM 平分 ∠BGH，∴ ∠BGM = 1/2 ∠BGH = 1/2 × 70° = 35°。∵ AB∥CD，∠BGM 与 ∠GMC 是内错角，∴ ∠GMC = ∠BGM = 35°（两直线平行，内错角相等）。又 M 在 C、D 之间，∴ C、M、D 在同一条直线上，∠GMC 与 ∠GMD 是邻补角，∴ ∠GMD = 180° − 35° = 145°。

检验：∠GMD 是钝角，GM 斜向右下、MD 水平向右，夹角确实是钝角，与 145° 相符；再换一种算法核对：∵ AB∥CD，∠BGM 与 ∠GMD 是同旁内角，∴ ∠BGM + ∠GMD = 180°，得 ∠GMD = 180° − 35° = 145°，与上面一致。

方法提示：遇到角平分线，先把大角除以 2 得到小角，再判断这个小角与哪个角是同位角、内错角或同旁内角。角平分线只改变角的大小，不改变角的位置，所以位置关系仍按原来的三条线去认。

14 【提升】AB∥CD，直线 EF 分别交 AB、CD 于点 G、H，A、C 在 EF 的左侧，B、D 在 EF 的右侧。∠AGH 与 ∠CHG 是同旁内角，且 ∠AGH = (2x − 30)°，∠CHG = x°。（1）求 x 与这两个角的度数；（2）若 ∠AGH 与 ∠DHG 是内错角，求 ∠DHG。
答案与解析

（1）∵ AB∥CD，∠AGH 与 ∠CHG 是同旁内角，∴ ∠AGH + ∠CHG = 180°（两直线平行，同旁内角互补）。代入得 (2x − 30) + x = 180，即 3x − 30 = 180，3x = 210，x = 70。所以 ∠CHG = 70°，∠AGH = 2 × 70° − 30° = 110°。

检验：110° + 70° = 180°，两角互补；且 110° 与 70° 都是正数、都小于 180°，符合角的度数的实际意义。若算出的角出现负数或大于 180°，说明方程或图形用错了，必须回头检查。

（2）∵ AB∥CD，∠AGH 与 ∠DHG 是内错角，∴ ∠DHG = ∠AGH = 110°（两直线平行，内错角相等）。也可以由邻补角求：∠DHG 与 ∠CHG 是邻补角，∠DHG = 180° − 70° = 110°，两种算法结果一致。

本题用的是方程思想：把角设成含 x 的式子，用“同旁内角互补”列方程，解出 x 再回代。列方程的依据必须写清楚，否则即使算对了也拿不到推理分。

15 【提升】已知 a∥b，∠1 与 ∠2 是直线 a、b 被直线 c 所截得到的内错角，∠2 与 ∠3 是直线 b、d 被直线 c 所截得到的同位角，∠1 = 65°。（1）求 ∠2；（2）若 ∠3 = 65°，判断 b 与 d 的位置关系，并说明理由；（3）若 ∠3 = 115°，b 与 d 还平行吗？说明理由。
答案与解析

（1）∵ a∥b，∠1 与 ∠2 是内错角，∴ ∠1 = ∠2（两直线平行，内错角相等），∴ ∠2 = 65°。这一步用的是性质，方向是“由线推角”。

（2）b∥d。理由：∠2 与 ∠3 是直线 b、d 被 c 所截得的同位角，且 ∠2 = 65°，∠3 = 65°，∴ ∠2 = ∠3，即同位角相等，∴ b∥d（同位角相等，两直线平行）。这一步用的是判定，方向是“由角推线”。

（3）不平行。理由：假如 b∥d，那么由“两直线平行，同位角相等”应有 ∠2 = ∠3，但 ∠2 = 65°，∠3 = 115°，65° ≠ 115°，矛盾。所以 b 与 d 不平行。也可以这样看：65° 与 115° 的和恰好是 180°，说明 ∠2 与 ∠3 互补，它们不是一对相等的同位角，而是“同旁内角互补”的那一类关系，用在同位角上自然不成立。

整道题的链条是：先用性质把 a∥b 换成 ∠1 = ∠2，再用判定把 ∠2 = ∠3 换成 b∥d。判定与性质一进一出，交替使用，这就是“综合推理”的样子。

16 【提升】如图 16，AB∥CD，直线 EF 分别交 AB、CD 于点 G、H，点 P 在两条平行线之间，且在 EF 的左侧。（1）若 ∠AGP = 40°，∠CHP = 30°，求 ∠GPH；（2）若 ∠GPH = 90°，∠AGP = 55°，求 ∠CHP；（3）写出 ∠GPH 与 ∠AGP、∠CHP 之间的关系式。
答案与解析

（1）过点 P 作 PQ∥AB（虚线，Q 在 EF 上），∵ AB∥CD，∴ PQ∥CD（平行于同一条直线的两条直线互相平行）。∵ PQ∥AB，∠AGP 与 ∠GPQ 是内错角，∴ ∠GPQ = ∠AGP = 40°（两直线平行，内错角相等）。∵ PQ∥CD，∠CHP 与 ∠HPQ 是内错角，∴ ∠HPQ = ∠CHP = 30°。∴ ∠GPH = ∠GPQ + ∠HPQ = 40° + 30° = 70°。

（2）由（1）的推理可以看出，不论度数是多少，只要辅助线 PQ 落在 ∠GPH 内部，就总有 ∠GPH = ∠AGP + ∠CHP。于是 90° = 55° + ∠CHP，∴ ∠CHP = 35°。如果要求写完整过程，就照（1）的样子再作一次 PQ，把 90° 拆成两个内错角，再相减。

（3）∠GPH = ∠AGP + ∠CHP。这个式子说明：两条平行线之间的一个拐点，把两侧的两个角“收”成了中间的大角。图 16 中，过 P 的辅助线 PQ 把 ∠GPH 拆成上下两块，上面一块与 ∠AGP 相等，下面一块与 ∠CHP 相等，所以大角等于两角之和。

作辅助线时要注意两点：一是辅助线必须与已知的平行线平行，这样才能用“两直线平行，内错角相等”；二是辅助线画虚线，并在解答里写一句“过点 P 作 PQ∥AB”，否则推理没有依据。另外，PQ 是射线，Q 取在哪个位置不影响结论，只要在 ∠GPH 的内部即可。

17 【提升】一段公路在 B 处第一次拐弯，到 C 处第二次拐弯，拐弯前后的两段公路 AB 与 CD 平行（即两次拐弯后公路仍沿原来的方向前进）。已知 ∠ABC = 140°。（1）求第二次拐弯处的 ∠BCD；（2）说明你的依据；（3）若实际测量得到 ∠BCD = 45°，能否断定 AB∥CD？为什么？
答案与解析

（1）∠BCD = 140°。

（2）∵ AB∥CD，BC 是截线，点 A 与点 D 分别在 BC 的两侧（公路两次拐弯后仍沿原来的方向前进），∴ ∠ABC 与 ∠BCD 是两条平行线被 BC 所截得到的内错角，∴ ∠BCD = ∠ABC = 140°（两直线平行，内错角相等）。用“拐弯”的话说：第一次从 AB 方向拐了 180° − 140° = 40°，第二次必须向相反方向再拐 40°，公路才回到原来的方向；两次拐弯的“转角”都是 40°，而两次的“拐角”（两段路之间的角）都是 140°。

（3）不能断定 AB∥CD。理由：如果 AB∥CD，那么由“两直线平行，内错角相等”应有 ∠BCD = ∠ABC = 140°；现在 ∠BCD = 45°，45° ≠ 140°，与平行的性质矛盾，所以 AB 与 CD 不平行，它们延长后会在某处相交。要使公路恢复原来的方向，第二次拐弯处的拐角应当是 140°，或者说第二次应再拐 40°。

这道题的现实意义是：工程上检验两段路是否平行，只要量一对内错角，看它们是否相等；量一对同位角，看它们是否相等；或者量一对同旁内角，看它们的和是不是 180°。三种量法对应三条判定，选哪一种取决于现场方便量哪一对角。

四、联系拓广（第 18—21 题）

这一组题难度最大，允许慢慢想。共同点是“题目没有直接给出可用的角”，需要自己作辅助线或设未知数，把条件转化成能用判定、性质处理的形式。

18 【拓展】AB∥CD，A、C 在左侧，B、D 在右侧，点 E 在两条平行线之间，且在点 B、D 的左侧。∠ABE = 40°，∠CDE = 30°，求 ∠BED。
答案与解析

作法：过点 E 作 EF∥AB，F 在点 E 的右侧（辅助线画虚线）。∵ AB∥CD，EF∥AB，∴ EF∥CD（平行于同一条直线的两条直线互相平行）。

推理：∵ EF∥AB，∠ABE 与 ∠BEF 是内错角，∴ ∠BEF = ∠ABE = 40°（两直线平行，内错角相等）。∵ EF∥CD，∠CDE 与 ∠DEF 是内错角，∴ ∠DEF = ∠CDE = 30°（两直线平行，内错角相等）。∴ ∠BED = ∠BEF + ∠DEF = 40° + 30° = 70°。

答：∠BED = 70°。

为什么一定要作这条辅助线？因为 ∠BED 的两条边 BE、DE 分别与 AB、CD 相交，∠BED 本身既不是同位角，也不是内错角或同旁内角，直接算不出来。作 EF∥AB 之后，一个角被拆成两个角，每个角都能与已知角配上“内错角”的关系，问题就解决了。这正是拐点问题的通用办法：过拐点作平行线，把大角拆成两个可算的角。

变式检验：若 ∠BED = 75°，∠ABE = 45°，则 ∠CDE = 75° − 45° = 30°；若 ∠BED = 60°，∠ABE = 40°，则 ∠CDE = 20°。可见只要拐点在两条平行线之间，就恒有 ∠BED = ∠ABE + ∠CDE，与具体度数无关。

19 【拓展】AB∥CD，A、C 在左侧，B、D 在右侧，点 E、F 依次在两条平行线之间，顺次连接 B、E、F、D 得到折线 B—E—F—D。已知 ∠ABE = 45°，∠BEF = 135°，∠EFD = 130°，求 ∠FDC。
答案与解析

作法：过点 E 作 EG∥AB，过点 F 作 FH∥AB，G、H 都在各自点的右侧（辅助线画虚线）。∵ AB∥CD，∴ EG∥CD，FH∥CD。

推理：∵ EG∥AB，∠ABE 与 ∠BEG 是内错角，∴ ∠BEG = ∠ABE = 45°（两直线平行，内错角相等）。∴ ∠GEF = ∠BEF − ∠BEG = 135° − 45° = 90°。

∵ EG∥FH，∠GEF 与 ∠EFH 是同旁内角，∴ ∠GEF + ∠EFH = 180°（两直线平行，同旁内角互补），∴ ∠EFH = 180° − 90° = 90°。

∴ ∠HFD = ∠EFD − ∠EFH = 130° − 90° = 40°。∵ FH∥CD，∠HFD 与 ∠FDC 是同旁内角，∴ ∠HFD + ∠FDC = 180°，∴ ∠FDC = 180° − 40° = 140°。

答：∠FDC = 140°。

与第 18 题比较：只有一个拐点时，辅助线把大角“拆成两块相加”；有两个拐点时，中间那一块要先算出来，再传给下一个拐点。传的过程可能用内错角相等，也可能用同旁内角互补，要看辅助线落在角的哪一侧——这正是多折点问题比单拐点难的地方。建议画图时把每条辅助线与折线的交点都标上字母，一步一步写，不要跳步。

20 【拓展】AB∥CD，直线 EF 分别交 AB、CD 于点 G、H，A、C 在 EF 的左侧，B、D 在 EF 的右侧。∠AGH 与 ∠CHG 是同旁内角，∠AGH = (3x − 15)°，∠CHG = (2x + 35)°。（1）求 x 和这两个角；（2）若把 ∠CHG 改为 (2x − 45)°，其余条件不变，x 是多少？两个角各是多少？（3）若这两角改为内错角（AB∥CD 不变），且仍为 (3x − 15)° 与 (2x + 35)°，求 x。
答案与解析

（1）∵ AB∥CD，∠AGH 与 ∠CHG 是同旁内角，∴ ∠AGH + ∠CHG = 180°。代入得 (3x − 15) + (2x + 35) = 180，即 5x + 20 = 180，5x = 160，x = 32。∴ ∠AGH = 3 × 32° − 15° = 81°，∠CHG = 2 × 32° + 35° = 99°。检验：81° + 99° = 180°，且两角都是正数、小于 180°，符合要求。

（2）同样由同旁内角互补得 (3x − 15) + (2x − 45) = 180，即 5x − 60 = 180，5x = 240，x = 48。∴ ∠AGH = 3 × 48° − 15° = 129°，∠CHG = 2 × 48° − 45° = 51°。检验：129° + 51° = 180°，两角仍是一钝一锐，位置关系仍是同旁内角，合理。

（3）∵ AB∥CD，∠AGH 与 ∠CHG 是内错角，∴ ∠AGH = ∠CHG（两直线平行，内错角相等）。∴ 3x − 15 = 2x + 35，解得 x = 50。此时 ∠AGH = 3 × 50° − 15° = 135°，∠CHG = 2 × 50° + 35° = 135°，两角相等，符合内错角相等的结论。

三点提醒。第一，列方程的依据随角的位置而变：同旁内角列“和等于 180°”，内错角、同位角列“相等”。第二，解完必须检验角的度数是否在 0° 与 180° 之间，出现负数或超范围的答案要舍弃，并回头检查方程。第三，第（3）问中 x = 50 与第（1）问的 32 不同，说明同一组式子在不同位置关系下会得到不同的方程，千万不要把上一问的 x 直接拿来用。

21 【拓展】直线 l 与直线 AB、CD 分别交于点 G、H，E 是 l 上位于 G 上方的一点，F 是 l 上位于 H 下方的一点，∠BGH = 70°。（1）请再给出一个角的大小，使 AB∥CD，至少写出三种不同的方案，并指出每种方案用的是哪一条判定；（2）若只知道 ∠BGH = 70°，能否判定 AB∥CD？为什么？
答案与解析

（1）方案一：给出 ∠DHF = 70°。∠BGH 与 ∠DHF 是同位角（都在 l 的右侧、都在各自被截线的下方），同位角相等，所以 AB∥CD，依据是“同位角相等，两直线平行”。

方案二：给出 ∠CHG = 70°。∠BGH 与 ∠CHG 是内错角（都在两条被截线之间，分居 l 的两侧），内错角相等，所以 AB∥CD，依据是“内错角相等，两直线平行”。

方案三：给出 ∠DHG = 110°。∠BGH 与 ∠DHG 是同旁内角（都在两条被截线之间，都在 l 的右侧），同旁内角互补，70° + 110° = 180°，所以 AB∥CD，依据是“同旁内角互补，两直线平行”。

还可以给出 ∠FHC = 110°：∠FHC 与 ∠CHG 是邻补角（HC 是公共边，HG 与 HF 互为反向延长线），所以 ∠CHG = 180° − 110° = 70°，再按方案二的判定即可。判断标准只有一条：给出的角能不能通过邻补角、对顶角转化成“一对同位角相等”“一对内错角相等”或“一对同旁内角互补”。

（2）不能。∠BGH 只是 8 个角中的一个，一个角的大小由两条直线的倾斜程度共同决定，与“这两条直线是否平行”没有必然联系。把 CD 绕点 H 稍稍转动，∠BGH 的度数可以保持不变，但 AB 与 CD 已经不平行了。要判定平行，必须知道一对角之间的关系，而不是一个角的度数。

这道题说明：判定的三句话，本质上都是“一对角的关系”。做题时先在图里找出所有能与已知角配成对角的角，再决定补充哪一个条件，就不会乱。

易错：（1）丢掉“在同一平面内”，把异面直线也当成平行线。（2）把“点到直线的距离”说成垂线段，把数说成线。（3）认为同位角、内错角一定相等，忘了“两直线平行”这个前提。（4）判定与性质用反：明明是“已知平行求角”，却写“∵ ∠1 = ∠2，∴ a∥b”。（5）作辅助线不作说明、不画虚线，或作了平行线却忘了写“平行于同一条直线的两条直线互相平行”。（6）拐点问题中把辅助线作在角的外侧，导致 ∠BED 被算成两角之差而不是两角之和，画图时务必看清辅助线是否落在角内。

  • 第二遍只做错题，并把每道错题的“依据”重新写一遍，写不出依据的说明概念没掌握，回看对应的课时。
